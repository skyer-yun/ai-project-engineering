## 四、Handoff 产物链验证

```
N1-N3 (pre-sales)
  │ 需求分析报告 + 技术方案 + 竞品分析（可选）
  ▼ QG1
N4 (product)
  │ PRD (12部分) + 原型 Demo
  ▼ QG2
N5-N6 (dev)
  │ 架构设计 + 详细设计 + API 文档 + 数据模型
  ▼ QG3
N7-N9 (dev)
  │ 源代码 + 代码审查报告 + 集成报告
  ▼ (同 QG3)
N10-N12 (testing)
  │ 测试用例 + 测试报告 + 缺陷清单（已闭环）
  ▼ QG4
N13-N15 (delivery)
  │ 部署文档 + 验收报告 + 培训材料 + 运维文档
  ▼ QG5
N16 (project)
  项目总结 + 知识沉淀 + 度量分析
```

每个 Handoff 验证：
1. 产出物是否在上游技能的 skill.md Output 节定义
2. 产出物是否在下游技能的 skill.md Input/Dependencies 节引用
3. QG 检查清单是否覆盖该 Handoff 的关键质量指标
