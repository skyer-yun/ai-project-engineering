# 待建技能清单与优先级

## Phase 1：核心技能（7 个）

### 1. solution-architect

| 项目 | 说明 |
|------|------|
| 用途 | 技术方案自动生成，根据需求分析报告输出标准 11 章技术方案 |
| 输入 | 需求分析报告、行业背景、技术约束 |
| 输出 | 技术方案文档（.docx）、架构图（Mermaid/PlantUML） |
| 所属智能体 | pre-sales-copilot |
| 检测路径 | `~/.claude/skills/solution-architect/skill.md` |
| 降级策略 | 使用 technical-proposal-writer 的基础方案能力 |
| 依赖 | technical-proposal-writer（核心）、docx（核心）、web-access（增强） |

### 2. competitive-analyzer

| 项目 | 说明 |
|------|------|
| 用途 | 竞品分析报告生成，5 维度对比矩阵 + SWOT 分析 |
| 输入 | 竞品名称列表、产品定位、目标市场 |
| 输出 | 竞品分析报告（含对比矩阵、SWOT、策略建议） |
| 所属智能体 | pre-sales-copilot |
| 检测路径 | `~/.claude/skills/competitive-analyzer/skill.md` |
| 降级策略 | 使用 web-access 手动搜索 + 模板引导 |
| 依赖 | web-access（核心）、brainstorming（增强） |

### 3. architecture-designer

| 项目 | 说明 |
|------|------|
| 用途 | 系统架构设计，根据 PRD 生成架构方案 |
| 输入 | PRD、技术约束、性能要求 |
| 输出 | 架构设计文档（含架构图、部署图、技术选型） |
| 所属智能体 | dev-copilot |
| 检测路径 | `~/.claude/skills/architecture-designer/skill.md` |
| 降级策略 | 手动引导架构设计过程，提供架构模板 |
| 依赖 | brainstorming（增强）、web-access（增强） |

### 4. detailed-designer

| 项目 | 说明 |
|------|------|
| 用途 | 详细设计文档生成，接口定义 + 数据模型 + 时序图 |
| 输入 | 架构设计文档、PRD |
| 输出 | 详细设计文档（含接口文档、ER 图、时序图） |
| 所属智能体 | dev-copilot |
| 检测路径 | `~/.claude/skills/detailed-designer/skill.md` |
| 降级策略 | 提供详细设计模板 + 手动引导 |
| 依赖 | architecture-designer（核心） |

### 5. test-case-generator

| 项目 | 说明 |
|------|------|
| 用途 | 测试用例自动生成，根据 PRD/详细设计输出测试用例集 |
| 输入 | PRD、详细设计文档、验收标准 |
| 输出 | 测试用例文档（按功能模块组织） |
| 所属智能体 | testing-copilot |
| 检测路径 | `~/.claude/skills/test-case-generator/skill.md` |
| 降级策略 | 提供测试用例模板 + 边界值/等价类划分引导 |
| 依赖 | 无核心依赖 |

### 6. quality-gate

| 项目 | 说明 |
|------|------|
| 用途 | 质量门禁检查，自动验证阶段产物是否满足质量标准 |
| 输入 | 阶段产物、质量标准定义 |
| 输出 | 质量检查报告（通过/不通过 + 具体问题清单） |
| 所属智能体 | project-copilot（通用） |
| 检测路径 | `~/.claude/skills/quality-gate/skill.md` |
| 降级策略 | 提供质量检查清单模板，手动逐项检查 |
| 依赖 | 无核心依赖 |

### 7. gantt-visualizer

| 项目 | 说明 |
|------|------|
| 用途 | 甘特图可视化，根据 WBS 生成可交互甘特图 |
| 输入 | WBS、任务依赖关系、资源分配 |
| 输出 | HTML 甘特图（可交互、可导出图片） |
| 所属智能体 | project-copilot |
| 检测路径 | `~/.claude/skills/gantt-visualizer/skill.md` |
| 降级策略 | 输出 Mermaid 甘特图语法 |
| 依赖 | 无核心依赖 |

## 实施建议

1. **Phase 1 优先级排序**：quality-gate > solution-architect > test-case-generator > gantt-visualizer > architecture-designer > detailed-designer > competitive-analyzer
2. **先通用后专用**：quality-gate 被多个智能体依赖，优先实现
3. **复用现有技能**：solution-architect 可基于 technical-proposal-writer 扩展
4. **渐进式交付**：每个技能先实现核心路径，再补充降级和边界处理
