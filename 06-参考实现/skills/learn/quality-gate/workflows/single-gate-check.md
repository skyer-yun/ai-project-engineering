# Single Gate Check Workflow

> 单个门禁检查流程

## Stage 1: 定位门禁 & 查找产物

```
1. 确定门禁 ID（QG-D/S/B/Ship）
2. 根据门禁定义，列出需要的产物清单
3. 扫描项目目录查找产物文件
4. 标记每个产物的存在状态
```

## Stage 3: 汇总判定

### 判定规则

```
IF 所有阻塞项通过 AND 警告项 <= 2：
  → 判定：PASS
  → 可进入下一阶段

IF 存在 1+ 阻塞项不通过：
  → 判定：FAIL
  → 列出阻塞项 + 修复建议
  → 不可进入下一阶段

IF 所有阻塞项通过 BUT 警告项 > 2：
  → 判定：PASS WITH WARNINGS
  → 列出警告项 + 建议修复
  → 可进入下一阶段，但建议先处理警告
```

### 报告格式

```markdown
# 质量门禁报告：QG{N} - {门禁名称}

## 基本信息
- 检查时间：{日期时间}
- 项目：{项目名}
- 门禁位置：N{X} → N{Y}
- 总体判定：**PASS / FAIL / PASS WITH WARNINGS**

## 检查结果

| # | 检查项 | 状态 | 备注 |
|---|--------|------|------|
| 1 | {检查项} | PASS/FAIL/WARNING/N/A | {说明} |

## 阻塞项（如有）

| # | 检查项 | 问题描述 | 修复建议 | 责任方 |
|---|--------|---------|---------|--------|

## 警告项（如有）

| # | 检查项 | 问题描述 | 建议操作 |
|---|--------|---------|---------|

## 结论

{总结判定 + 下一步行动}
```
