# 触发规则

## 门禁触发

| 关键词 | 门禁 |
|--------|------|
| QG-需求 / 项目规划完成度 / 售前转产品 | QG-需求 |
| QG-设计 / 设计就绪 / 产品转开发 | QG-设计 |
| QG-开发 / 提测 / 开发转测试 | QG-开发 |
| QG-交付 / 发布就绪 / 测试转交付 | QG-交付 |
| QG-交付 / 交付确认 / 交付转收尾 | QG-交付 |
| 全量 / 全部门禁 / 整体检查 | full-scan |
| 报告 / 门禁报告 | gate-report |

## 匹配规则

```
1. QG{N} 精确匹配 → 执行对应门禁
2. 阶段关键词 → 推断门禁 ID
3. 无法匹配 → 询问用户指定门禁
```
