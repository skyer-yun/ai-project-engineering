# knowledge-compiler 依赖配置

## 核心依赖

| 依赖 | 类型 | 版本要求 | 用途 | 缺失影响 |
|------|------|----------|------|----------|
| 07-project-copilot | 技能 | >=1.0 | 项目上下文、全过程产物索引 | 降级为独立模式 |

## 增强依赖

| 依赖 | 类型 | 版本要求 | 用途 | 缺失影响 |
|------|------|----------|------|----------|
| docx | 技能 | >=1.0 | 经验总结/模板 Word 文档输出 | 仅支持 Markdown 输出 |

## 依赖检测流程

```
1. 检测 07-project-copilot
   - 读取 ~/.claude/skills/07-project-copilot/skill.md
   - 存在 → 加载项目上下文和产物索引
   - 不存在 → 标记为独立模式

2. 检测 docx
   - 读取 ~/.claude/skills/docx/skill.md
   - 存在 → 启用 .docx 输出
   - 不存在 → 仅 Markdown
```

## 降级策略

| 场景 | 降级方案 |
|------|----------|
| 07-project-copilot 缺失 | 独立模式，需要用户手动提供项目产物清单 |
| docx 缺失 | 输出 Markdown 格式，用户可自行转换 |
| 项目产物不完整 | 基于已有产物进行部分沉淀，标记缺失部分 |
