# Triggers - gantt-visualizer

## 触发关键词

### 主要触发词
- 甘特图
- 排期表
- 进度图
- Gantt
- Gantt chart
- 项目进度可视化
- 时间线图
- 任务排期

### 辅助触发词
- 画个甘特图
- 生成进度表
- WBS转甘特图
- 项目时间线
- 里程碑图
- 进度跟踪图

## 触发规则

1. **精确匹配**：关键词直接触发甘特图生成流程
2. **上下文推断**：当对话中已存在 WBS/任务列表数据时，"可视化"/"画图"可触发
3. **组合触发**：WBS + 可视化/图/表格 组合触发
4. **避免误触发**：纯 WBS 创建不自动触发，需明确要求可视化

## 关键词权重

| 关键词 | 权重 | 说明 |
|--------|------|------|
| 甘特图 | 1.0 | 直接触发 |
| Gantt | 1.0 | 直接触发 |
| 排期表 | 0.9 | 高概率触发 |
| 进度图 | 0.9 | 高概率触发 |
| 时间线 | 0.7 | 需要上下文确认 |
| 进度可视化 | 0.8 | 高概率触发 |
| WBS转图 | 0.9 | 高概率触发 |
