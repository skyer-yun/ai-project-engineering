# 看板生成工作流

## 步骤 1：数据收集

**目标**：从各项目数据源采集状态数据。

**采集内容**：
- 项目基本信息（名称/负责人/阶段/起止日期）
- 进度数据（完成率/里程碑达成/关键路径状态）
- 质量数据（缺陷数/测试覆盖率）
- 资源数据（人员配置/利用率/成本消耗）
- 风险数据（风险等级/关键风险项）

**输出**：各项目的标准化数据快照

---

## 步骤 2：指标聚合

**目标**：统一计算各项目健康分数和关键指标。

**计算规则**：
1. **健康分数**（0-100）= 进度 30% + 质量 25% + 资源 25% + 风险 20%
2. **总体状态**：绿（>=80）/ 黄（60-79）/ 红（<60）/ 灰（未开始）
3. **汇总统计**：项目总数/各状态数/平均健康分/延期项目数

**输出**：聚合指标数据集

---

## 步骤 3：可视化设计

**目标**：确定看板布局和展示方式。

**布局层次**：
1. **顶部汇总栏**：项目总数/状态分布/平均健康分/需关注项数
2. **项目卡片网格**：每个项目一张卡片，展示关键指标和状态色
3. **展开详情区**：点击卡片展开任务列表和里程碑进度

**交互设计**：
- 卡片点击展开/收起详情
- 按状态/负责人/阶段筛选
- 项目名称搜索

**输出**：看板设计规格

---

## 步骤 4：HTML 生成

**目标**：基于设计生成完整 HTML 看板。

**技术要求**：
- 单文件 HTML，CSS/JS 全部内联
- 响应式布局（桌面 1920px+ / 平板 768px+）
- 无外部依赖，本地直接打开可用
- 支持浏览器打印和 PDF 导出

**输出**：完整 HTML 文件

---

## 步骤 5：导出

**目标**：将看板文件保存到指定位置。

**输出位置**：`项目文档/项目总览看板-{日期}.html`

**附加操作**：
- 提示用户可在浏览器中打开查看
- 可选：截图保存为 PNG/PDF
