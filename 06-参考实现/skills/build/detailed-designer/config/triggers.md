# Triggers - detailed-designer

## 触发关键词

### 主要触发词
- 详细设计
- 接口设计
- 数据模型
- 时序图
- 状态机

### 辅助触发词
- 数据库设计
- API设计
- DDL
- ER图
- 详细设计文档
- 详细设计说明书
- 概要设计（等同详细设计）
- 接口文档
- 接口规范

## 触发规则

1. **精确匹配**：关键词直接触发详细设计流程
2. **上下文推断**：已有架构设计文档时，"细化"/"详细设计"可触发
3. **组合触发**：架构文档 + 详细设计/接口设计 组合触发
4. **避免误触发**：纯架构讨论不触发（由 architecture-designer 处理）

## 与其他技能的边界

| 关键词 | 所属技能 | 判断依据 |
|--------|----------|----------|
| 详细设计 | detailed-designer | 从架构到可实施的设计细化 |
| 架构设计 | architecture-designer | 从 PRD 到系统架构 |
| 接口文档 | detailed-designer | 接口级别的详细定义 |
| 数据模型 | detailed-designer | 具体的表结构和 ER 图 |

## 关键词权重

| 关键词 | 权重 | 说明 |
|--------|------|------|
| 详细设计 | 1.0 | 直接触发 |
| 接口设计 | 0.9 | 高概率触发 |
| 数据模型 | 0.9 | 高概率触发 |
| 时序图 | 0.8 | 可能只是画图需求 |
| 状态机 | 0.8 | 可能只是画图需求 |
| DDL | 0.7 | 可能只需要建表脚本 |
| ER图 | 0.7 | 可能只需要数据模型 |
