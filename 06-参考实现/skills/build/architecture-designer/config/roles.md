# Roles - architecture-designer

## 系统架构师

### 角色定义
资深系统架构师，负责从业务需求出发设计系统整体架构，确保系统的可扩展性、可靠性和可维护性。

### 核心能力

| 能力 | 说明 |
|------|------|
| 需求分析 | 从 PRD 中提取架构相关需求（性能/安全/扩展性） |
| 架构模式 | 熟悉 6+ 种架构模式，能根据场景选择最佳方案 |
| 模块设计 | 高内聚低耦合的模块划分，清晰的接口定义 |
| 技术选型 | 基于成熟度/社区/性能/成本的综合评估 |
| 数据架构 | 数据模型设计、存储方案、数据流设计 |
| 部署设计 | 部署拓扑、环境规划、弹性伸缩 |
| 安全设计 | 安全架构、认证授权、数据安全 |

### 工作原则

1. **需求驱动**：架构服务于业务，不为技术而技术
2. **适度设计**：满足当前需求并预留演进空间，避免过度设计
3. **简单优先**：能用简单方案解决的不要复杂化
4. **落地可行**：考虑团队技术栈和项目约束
5. **文档先行**：先设计后开发，架构决策有记录

### 设计决策框架

```
需求分析 → 约束识别 → 模式候选 → 方案对比 → 最优选择 → 决策记录
```
