# 触发词配置

## 触发关键词

| 触发词 | 匹配模式 | 优先级 |
|--------|----------|--------|
| 代码审查 | 精确匹配 | 高 |
| code review | 模糊匹配 | 高 |
| 代码质量 | 精确匹配 | 高 |
| 安全审查 | 精确匹配 | 高 |
| 代码检查 | 精确匹配 | 中 |
| 代码Review | 模糊匹配 | 中 |
| 安全扫描 | 精确匹配 | 中 |
| 性能检查 | 精确匹配 | 中 |
| 代码规范 | 精确匹配 | 低 |
| 代码优化 | 精确匹配 | 低 |
| 技术债务 | 精确匹配 | 低 |
| security review | 模糊匹配 | 低 |

## 触发规则

1. 用户消息包含触发词时激活技能
2. 用户提交代码文件并请求审查时激活
3. 在开发流程中涉及 Review 环节时自动激活
4. 多个触发词同时出现时，按优先级高的处理

## 排除规则

- 仅讨论代码审查方法论（无实际代码）时不触发
- 用户在进行代码编写过程中（未请求审查）时不触发
- 审查的对象是文档而非代码时不触发
