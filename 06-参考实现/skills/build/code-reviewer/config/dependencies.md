# 依赖配置

## 依赖列表

### 核心依赖

| 技能名称 | 路径 | 用途 | 缺失影响 |
|----------|------|------|----------|
| 04-dev-copilot | `~/.claude/skills/04-dev-copilot/` | 研发助手，提供架构设计和接口文档上下文 | 无法获取架构上下文，审查局限于代码层面 |

### 增强依赖

| 技能名称 | 路径 | 用途 | 缺失影响 |
|----------|------|------|----------|
| requesting-code-review | `~/.claude/skills/requesting-code-review/` | 标准化的代码审查提交流程 | 跳过标准提交流程，直接进入审查 |

## 依赖检测

### 检测方法
1. 检查技能目录是否存在（支持多个可能的路径）
2. 检查 skill.md 文件是否存在且可读
3. 解析 skill.md 的 name 和 version 字段

### 检测时机
- 技能启动时
- 需要获取架构上下文时

### 版本兼容
| 依赖技能 | 最低版本 | 推荐版本 |
|----------|----------|----------|
| 04-dev-copilot | v1.0 | 最新 |
| requesting-code-review | v1.0 | 最新 |

## 降级策略

| 场景 | 策略 |
|------|------|
| 04-dev-copilot 缺失 | 独立审查模式，不参考架构设计文档 |
| requesting-code-review 缺失 | 跳过标准提交流程，直接进入审查 |
| 所有依赖缺失 | 纯代码审查模式，基于代码本身进行分析 |
