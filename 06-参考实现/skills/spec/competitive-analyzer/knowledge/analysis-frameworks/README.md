# 分析框架参考（Analysis Frameworks）

## 概述

本目录描述竞品分析使用的核心框架：5维度对比矩阵和SWOT分析。

---

## 5维度对比矩阵

### 框架说明

5维度对比矩阵从5个关键维度对竞品进行系统化对比，确保分析的全面性。

### 维度定义

| 维度 | 分析目标 | 关键指标 |
|------|----------|----------|
| 功能对比 | 功能覆盖和差异化 | 功能清单/覆盖度/独特功能 |
| 技术对比 | 技术能力和架构水平 | 架构/性能/安全/集成/部署 |
| 价格对比 | 定价策略和性价比 | 定价模式/价格/隐性成本 |
| 用户体验 | 产品易用性和满意度 | 界面/操作/评价/学习成本 |
| 市场定位 | 市场地位和品牌 | 目标客户/份额/品牌/渠道 |

### 使用方法

1. 为每个维度建立对比表格
2. 使用统一评分标准（5分制或等级制）
3. 标注数据来源和时效
4. 综合各维度给出整体评价

### 评分标准

| 等级 | 说明 | 评分 |
|------|------|------|
| 领先 | 明显优于竞品 | 5 |
| 良好 | 略优于平均水平 | 4 |
| 相当 | 与竞品持平 | 3 |
| 不足 | 略低于平均水平 | 2 |
| 落后 | 明显弱于竞品 | 1 |

## SWOT 分析框架

### 框架说明

SWOT 分析从内部（优势/劣势）和外部（机会/威胁）两个层面进行战略分析。

### 四要素定义

| 要素 | 方向 | 说明 |
|------|------|------|
| S - Strengths | 内部有利 | 组织内部的优势因素 |
| W - Weaknesses | 内部不利 | 组织内部的劣势因素 |
| O - Opportunities | 外部有利 | 外部环境中的有利因素 |
| T - Threats | 外部不利 | 外部环境中的不利因素 |

### 分析步骤

1. **内部扫描**：从5维度对比中提取我方优势和劣势
2. **外部扫描**：分析市场趋势、竞争格局、客户需求变化
3. **矩阵构建**：将因素填入SWOT矩阵
4. **交叉分析**：S+O/W+O/S+T/W+T 四种交叉策略
5. **策略输出**：基于交叉分析给出可执行建议

### 交叉策略

| 交叉 | 策略类型 | 思路 |
|------|----------|------|
| S+O | SO策略（增长） | 用优势抓住机会 |
| W+O | WO策略（转型） | 补短板利用机会 |
| S+T | ST策略（防御） | 用优势抵御威胁 |
| W+T | WT策略（生存） | 补短板规避威胁 |

---

## 组合使用

5维度矩阵和 SWOT 分析组合使用：

```
5维度矩阵 → 客观数据对比
    ↓
SWOT分析 → 战略层面解读
    ↓
策略建议 → 可执行的竞争方案
```

5维度矩阵提供数据基础，SWOT提供战略视角，策略建议是最终产出。
