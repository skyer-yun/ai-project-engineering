# Triggers - competitive-analyzer

## 触发关键词

### 主要触发词
- 竞品分析
- 竞品调研
- 对比分析
- SWOT

### 辅助触发词
- 竞争对手分析
- 竞品对比
- 市场分析
- 竞品报告
- 产品对比
- 行业分析
- 竞争格局
- 市场调研
- 对手调研
- 竞品信息收集

## 触发规则

1. **精确匹配**：关键词直接触发竞品分析流程
2. **上下文推断**：提到具体产品名 + "对比"/"比较"/"分析"可触发
3. **组合触发**：产品名 + 竞品/对手/对比 组合触发
4. **避免误触发**：纯技术选型对比不触发（非竞品场景）

## 与其他技能的边界

| 关键词 | 所属技能 | 判断依据 |
|--------|----------|----------|
| 竞品分析 | competitive-analyzer | 市场竞争视角的对比 |
| 技术选型 | architecture-designer | 技术方案视角的对比 |
| 行业分析 | competitive-analyzer | 行业竞争格局分析 |
| 市场调研 | competitive-analyzer | 市场层面的调研 |
