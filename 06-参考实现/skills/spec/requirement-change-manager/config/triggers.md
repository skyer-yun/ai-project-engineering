# 触发词配置

## 触发关键词

| 触发词 | 匹配模式 | 优先级 |
|--------|----------|--------|
| 需求变更 | 精确匹配 | 高 |
| 变更管理 | 精确匹配 | 高 |
| 变更影响分析 | 精确匹配 | 高 |
| 需求调整 | 精确匹配 | 中 |
| 功能变更 | 精确匹配 | 中 |
| 需求修改 | 精确匹配 | 中 |
| 变更评审 | 精确匹配 | 中 |
| change request | 模糊匹配 | 低 |
| 变更申请 | 精确匹配 | 低 |

## 触发规则

1. 用户消息包含触发词时激活技能
2. 多个触发词同时出现时，按优先级高的处理
3. 在项目管理上下文中提及"变更"时自动激活
4. 与 write-a-prd 联动时，PRD 修改场景自动触发

## 排除规则

- 仅讨论"变更"概念（无实际变更操作）时不触发
- "变更"指人员变更、组织变更时不触发
- 已在变更流程中执行子步骤时不重复触发
