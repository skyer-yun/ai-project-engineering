# 依赖配置

## 依赖列表

### 核心依赖

| 技能名称 | 路径 | 用途 | 缺失影响 |
|----------|------|------|----------|
| product-copilot | `~/.claude/skills/product-copilot/` | 多技能编排层，调用 PRD/项目管理能力 | 无法联动 PRD 更新和项目管理 |

### 增强依赖

| 技能名称 | 路径 | 用途 | 缺失影响 |
|----------|------|------|----------|
| write-a-prd | `~/.claude/skills/write-a-prd/` | PRD 文档结构化更新 | 变更后 PRD 需手动更新 |
| docx | `~/.claude/skills/docx/` | 变更报告输出为 Word 格式 | 仅能输出 Markdown 格式 |

## 依赖检测

### 检测方法
1. 检查技能目录是否存在
2. 检查 skill.md 文件是否存在且可读
3. 解析 skill.md 的 name 和 version 字段

### 检测时机
- 技能启动时
- 每次调用协作角色前

### 版本兼容
| 依赖技能 | 最低版本 | 推荐版本 |
|----------|----------|----------|
| product-copilot | v1.0 | v1.1+ |
| write-a-prd | v1.0 | 最新 |
| docx | v1.0 | 最新 |

## 降级策略

| 场景 | 策略 |
|------|------|
| product-copilot 缺失 | 仅执行变更分析，不联动 PRD/项目管理 |
| write-a-prd 缺失 | PRD 更新改为手动指导模式 |
| docx 缺失 | 报告输出为 Markdown 格式 |
| 所有增强依赖缺失 | 纯分析模式，输出文本报告 |
