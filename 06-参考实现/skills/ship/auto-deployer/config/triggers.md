| 触发词 | 匹配模式 | 优先级 |
|--------|----------|--------|
| 部署方案 | 精确匹配 | 高 |
| CI/CD | 精确匹配 | 高 |
| Docker | 精确匹配 | 高 |
| K8s | 精确匹配 | 高 |
| Kubernetes | 精确匹配 | 高 |
| 自动化部署 | 精确匹配 | 高 |
| Dockerfile | 模糊匹配 | 中 |
| 容器化 | 精确匹配 | 中 |
| 部署文档 | 精确匹配 | 中 |
| 流水线 | 精确匹配 | 中 |
| Jenkins | 精确匹配 | 中 |
| GitHub Actions | 模糊匹配 | 中 |
| 蓝绿部署 | 精确匹配 | 低 |
| 金丝雀 | 精确匹配 | 低 |
| 滚动更新 | 精确匹配 | 低 |
| 回滚方案 | 精确匹配 | 低 |
| deploy | 模糊匹配 | 低 |

## 触发规则

1. 用户消息包含触发词时激活技能
2. 多个触发词同时出现时，按优先级高的处理
3. 在项目交付阶段提及"部署"时自动激活
4. 与 06-delivery-copilot 联动时，部署环节自动触发

## 排除规则
- 仅讨论部署概念（无实际部署需求）时不触发
- "部署"指代码部署到本地开发环境时不触发
- 已在部署流程中执行子步骤时不重复触发
