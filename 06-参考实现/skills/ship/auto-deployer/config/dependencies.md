# 依赖配置

## 依赖列表

### 核心依赖

| 技能名称 | 路径 | 用途 | 缺失影响 |
|----------|------|------|----------|
| 06-delivery-copilot | `~/.claude/skills/06-delivery-copilot/` | 交付智能体，提供部署上下文和验收标准 | 无法获取交付上下文，基于用户描述独立工作 |

### 增强依赖

| 技能名称 | 路径 | 用途 | 缺失影响 |
|----------|------|------|----------|
| docx | `~/.claude/skills/docx/` | 部署方案输出为 Word 格式 | 仅能输出 Markdown 格式 |

## 依赖检测

### 检测方法
1. 检查技能目录是否存在（支持多个可能的路径）
2. 检查 skill.md 文件是否存在且可读
3. 解析 skill.md 的 name 和 version 字段

### 检测时机
- 技能启动时
- 需要获取交付上下文时

### 版本兼容
| 依赖技能 | 最低版本 | 推荐版本 |
|----------|----------|----------|
| 06-delivery-copilot | v1.0 | 最新 |
| docx | v1.0 | 最新 |

## 降级策略

| 场景 | 策略 |
|------|------|
| 06-delivery-copilot 缺失 | 独立模式，基于用户描述生成部署方案 |
| docx 缺失 | 部署文档以 Markdown 格式输出 |
| 所有依赖缺失 | 纯模板模式，提供标准模板供用户修改 |
