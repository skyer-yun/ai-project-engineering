# performance-tester 依赖配置

## 核心依赖

| 依赖 | 类型 | 版本要求 | 用途 | 缺失影响 |
|------|------|----------|------|----------|
| 05-testing-copilot | 技能 | >=1.0 | 测试策略上下文、用例管理 | 降级为独立模式 |

## 增强依赖

| 依赖 | 类型 | 版本要求 | 用途 | 缺失影响 |
|------|------|----------|------|----------|
| docx | 技能 | >=1.0 | Word 文档输出 | 仅支持 Markdown 输出 |

## 外部工具（可选）

| 工具 | 用途 | 检查方式 |
|------|------|----------|
| JMeter | 压测脚本执行 | 检查 jmeter 命令是否可用 |
| Gatling | 压测脚本执行 | 检查 gatling 命令是否可用 |
| Locust | 压测脚本执行 | 检查 locust 命令是否可用 |

## 依赖检测流程

```
1. 检测 05-testing-copilot
   - 读取 ~/.claude/skills/05-testing-copilot/skill.md
   - 存在 → 加载测试策略上下文
   - 不存在 → 标记为独立模式

2. 检测 docx
   - 读取 ~/.claude/skills/docx/skill.md
   - 存在 → 启用 .docx 输出
   - 不存在 → 仅 Markdown

3. 检测外部工具（非必须）
   - which jmeter / gatling / locust
   - 可用 → 告知用户可直接执行脚本
   - 不可用 → 提示安装方式
```

## 降级策略

| 场景 | 降级方案 |
|------|----------|
| 05-testing-copilot 缺失 | 独立模式运行，无测试策略上下文，需要用户手动提供测试范围 |
| docx 缺失 | 输出 Markdown 格式，用户可自行转换 |
| 外部工具缺失 | 仅生成脚本模板，不提供执行指导 |
