# 培训材料生成工作流

## 工作流概览

```
Phase 1: 需求分析 → Phase 2: 方案设计 → Phase 3: 手册编写 → Phase 4: 课件设计 → Phase 5: 题库生成
```

## Phase 1: 需求分析

### 输入
- 产品功能说明书 / PRD 文档
- 目标受众描述（角色、技术水平、业务背景）
- 培训时间要求

### 活动
1. **明确培训受众**
   - 管理层：关注业务价值、数据报表、审批流程
   - 业务操作人员：关注日常操作、数据录入、流程处理
   - 系统管理员：关注系统配置、权限管理、数据维护
   - IT 运维人员：关注部署架构、故障排查、监控告警

2. **确定培训目标**
   - 知识目标：了解系统的整体架构和核心功能
   - 技能目标：能够独立完成日常业务操作
   - 态度目标：认可系统的价值，积极配合使用

3. **分析功能模块**
   - 核心功能清单（必训内容）
   - 扩展功能清单（选训内容）
   - 管理功能清单（管理员专用）
   - 各功能的操作频率和复杂度

4. **确认培训条件**
   - 培训时间（总时长 / 每次时长）
   - 培训形式（线上 / 线下 / 混合）
   - 培训环境（是否有练习环境）
   - 培训人数和分组

### 输出
- 培训需求分析报告
- 受众画像表
- 功能模块优先级清单

### 检查点
- [ ] 受众角色和背景已明确
- [ ] 培训目标已量化
- [ ] 功能模块已分类和排序
- [ ] 培训条件已确认

## Phase 2: 方案设计

### 输入
- Phase 1 需求分析结果

### 活动
1. **设计培训计划**
   - 培训阶段划分（基础培训 → 专项培训 → 实操演练）
   - 每阶段时长分配
   - 培训日程安排
   - 讲师安排（如有多个讲师）

2. **确定培训形式**
   - 讲授式：系统概述、架构介绍、业务价值
   - 演示式：核心功能操作演示
   - 实操式：学员上机练习
   - 讨论式：场景讨论、问题答疑
   - 考核式：笔试 + 实操考核

3. **设计内容模块**
   - 模块编号 + 模块名称 + 时长 + 形式 + 对应功能
   - 模块之间的依赖关系
   - 每个模块的学习目标

4. **设计考核方案**
   - 考核形式（选择题/判断题/实操题）
   - 考核内容覆盖度
   - 通过标准（如正确率 >= 80%）
   - 补考机制

### 输出
- 培训方案文档（含计划、形式、考核方案）
- 培训日程表
- 内容模块清单

### 检查点
- [ ] 培训计划时间合理
- [ ] 内容模块覆盖所有核心功能
- [ ] 考核方案可执行
- [ ] 受众层次与内容深度匹配

## Phase 3: 手册编写

### 输入
- Phase 2 的培训方案和功能模块清单

### 活动
1. **编写系统简介**
   - 系统定位与价值
   - 核心功能概览（功能架构图占位）
   - 用户角色与权限说明
   - 系统访问方式（URL/账号/客户端）

2. **编写快速入门**
   - 登录流程（含截图占位）
   - 首页导航说明
   - 首次使用引导（修改密码/完善信息/常用设置）
   - 一个完整的业务流程示例（端到端）

3. **编写功能说明**
   - 按功能模块组织章节
   - 每个功能包含：
     - 功能概述（一句话说明功能用途）
     - 操作步骤（编号步骤 + 截图占位）
     - 字段说明（表格形式：字段名/类型/是否必填/说明）
     - 注意事项（边界条件/常见错误）
     - 业务场景示例

4. **编写FAQ**
   - 常见问题分类（登录类/操作类/数据类/权限类）
   - 每个问题：问题描述 + 原因分析 + 解决步骤
   - 至少覆盖 10 个常见问题
   - 联系支持方式

5. **编写术语表**
   - 系统专有名词解释
   - 业务术语解释
   - 缩写对照表

### 输出
- 操作手册文档（.docx 或 Markdown）
- 术语表
- FAQ 文档

### 检查点
- [ ] 操作步骤编号清晰
- [ ] 截图位置有占位符标注
- [ ] 字段说明表格完整
- [ ] FAQ 覆盖常见问题
- [ ] 术语表完整

## Phase 4: 课件设计

### 输入
- Phase 2 的培训方案
- Phase 3 的操作手册内容

### 活动
1. **设计培训PPT大纲**
   - 管理层版本（5-10页）：业务价值 + 核心功能演示 + ROI
   - 操作人员版本（20-40页）：系统介绍 + 功能操作 + 实操演练
   - 管理员版本（15-30页）：系统配置 + 权限管理 + 维护操作

2. **每页PPT内容设计**
   - 标题 + 核心要点（不超过5条）
   - 配图位置标注（截图/示意图/流程图）
   - 讲师备注（扩展说明/演示提示/互动问题）

3. **设计互动环节**
   - 操作演示点（在哪些功能处需要现场演示）
   - 练习任务（学员上机操作的具体任务）
   - 讨论话题（场景讨论问题）
   - 问答环节安排

4. **设计课后资料**
   - 快速参考卡片（常用操作速查）
   - 视频教程清单（如有录屏资源）
   - 常见问题速查

### 输出
- 培训PPT大纲（Markdown 或 .pptx）
- 互动环节清单
- 课后资料清单

### 检查点
- [ ] PPT大纲适配目标受众
- [ ] 每页内容不超过5个要点
- [ ] 互动环节设计合理
- [ ] 讲师备注完整

## Phase 5: 题库生成

### 输入
- Phase 2 的功能模块清单
- Phase 3 的操作手册内容

### 活动
1. **生成选择题**
   - 每个核心功能模块 3-5 题
   - 题目覆盖：功能定位、操作路径、字段含义、业务规则
   - 4 个选项，1 个正确答案
   - 附答案解析

2. **生成判断题**
   - 每个核心功能模块 2-3 题
   - 题目覆盖：常见误区、操作规范、业务规则
   - 附正确答案和解析

3. **生成实操题**
   - 每个核心功能模块 1-2 题
   - 题目描述具体业务场景
   - 给出操作步骤要求
   - 给出预期结果
   - 评分标准（步骤分 + 结果分）

4. **组卷规则**
   - 题目数量：选择题 20-30 题 + 判断题 10-15 题 + 实操题 3-5 题
   - 题目难度分布：基础 60% + 中等 30% + 进阶 10%
   - 功能模块覆盖：每个核心模块至少 3 题
   - 通过标准：总分 >= 80 分

### 输出
- 考核题库文档
- 标准试卷（含评分标准）
- 答案与解析

### 检查点
- [ ] 题目覆盖所有核心功能模块
- [ ] 题目难度分布合理
- [ ] 答案解析完整
- [ ] 实操题可执行
- [ ] 评分标准明确
