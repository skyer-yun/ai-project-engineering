# 测试执行工作流

> 覆盖阶段：交付·测试执行（测试执行）
> 对应角色：测试工程师

---

## 适用场景

当测试用例已就绪，需要执行测试并输出测试报告时使用。

- 功能测试执行
- 回归测试执行
- 冒烟测试执行
- 验收测试支持
- 发版前质量确认

## 前置条件

```
必须：
  [x] 测试用例已评审通过并基线化
  [x] 测试环境已搭建完成
  [x] 代码已冻结（feature freeze）

建议：
  [ ] 测试数据已准备
  [ ] 自动化脚本已就绪（如需）
  [ ] 缺陷跟踪系统已配置
```

## 阶段

### Stage 1: 环境准备

- **输入**：测试计划 + 测试用例集 + 环境需求
- **动作**：
  1. 确认测试环境状态
     - 服务器/数据库/中间件已部署
     - 配置项已按测试需求调整
     - 网络连通性已验证
  2. 准备测试数据
     - 基础数据（用户/角色/权限/配置）
     - 业务数据（订单/合同/流程实例）
     - 边界数据（极值/空值/特殊字符）
  3. 确认冒烟测试通过
     - 核心功能可正常访问
     - 主流程可正常操作
     - 无阻塞性问题
  4. 分配用例执行任务
- **输出**：
  - 环境就绪确认单
  - 测试数据清单
  - 冒烟测试结果
  - 用例执行分配表

### Stage 2: 测试执行

- **输入**：测试用例集 + 测试环境 + 测试数据
- **动作**：
  1. 按优先级顺序执行用例（P0 → P1 → P2 → P3）
  2. 记录测试结果
     - Pass：预期与实际一致
     - Fail：记录缺陷（进入缺陷管理流程）
     - Block：前置条件不满足，标注阻塞原因
     - Skip：本轮不执行，标注原因
  3. 实时更新执行进度
  4. 发现缺陷时：
     - 立即记录（调用 defect-management-workflow Stage 1）
     - 标注关联用例
     - 评估是否阻塞后续测试
  5. 每日汇总执行情况
- **输出**：
  - 测试执行记录
  - 缺陷清单（实时更新）
  - 每日进度报告
- **进度跟踪指标**：

  ```
  用例执行率 = 已执行用例数 / 总用例数 × 100%
  用例通过率 = 通过用例数 / 已执行用例数 × 100%
  缺陷发现率 = 本轮新发现缺陷数 / 已执行用例数
  缺陷修复率 = 已修复缺陷数 / 总缺陷数 × 100%
  ```

### Stage 3: 报告输出

- **输入**：测试执行记录 + 缺陷清单
- **动作**：
  1. 统计测试结果
     - 用例执行统计（总数/通过/失败/阻塞/跳过）
     - 缺陷统计（总数/P0/P1/P2/P3 分布）
     - 覆盖率统计（功能点/模块/需求）
  2. 分析测试质量
     - 缺陷密度（缺陷数/功能点数）
     - 缺陷趋势（每日新增/修复/累计）
     - 遗留风险评估
  3. 给出测试结论
     - All Pass：所有用例通过，无 P0/P1 缺陷
     - 条件通过：存在非阻塞问题，建议修复后上线
     - 不通过：存在 P0/P1 未关闭缺陷
  4. 输出测试报告
- **输出**：测试报告
  - 测试概述（范围/环境/时间/人员）
  - 执行统计（用例/缺陷/覆盖率）
  - 缺陷分析（分布/趋势/根因）
  - 测试结论与建议
  - 遗留问题清单
  - 附录（详细执行记录）
- **技能调用**：`docx`（如已安装）或 Markdown

## 准入准出标准

### 准入标准

```
进入测试执行前需确认：
  [ ] 代码已冻结，无未经审批的变更
  [ ] 冒烟测试全部通过
  [ ] 测试环境与生产环境配置一致（或差异已记录）
  [ ] 测试数据已准备完成
  [ ] 所有 P0 用例已分配到执行人
```

### 准出标准

```
测试执行完成需满足：
  [ ] 用例执行率 100%（P0/P1 必须全部执行）
  [ ] P0 缺陷清零（0 Open）
  [ ] P1 缺陷清零（0 Open）
  [ ] P2 缺陷修复率 >= 80%（或已确认下版本修复）
  [ ] 无阻塞性问题
  [ ] 性能指标达标（如有性能测试要求）
```

```
├── 缺陷清单.md（或 .xlsx）

```

## 降级策略

| 缺失资源 | 降级行为 |
|----------|----------|
| 自动化环境未就绪 | 全手动执行 |
| docx 未安装 | 输出 Markdown 格式报告 |
| xlsx 未安装 | 缺陷清单输出 Markdown 表格 |
| 缺陷跟踪系统未配置 | 使用 Markdown 表格跟踪 |
