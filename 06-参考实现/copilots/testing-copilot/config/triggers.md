# 意图触发映射

> 本文件为意图识别的**兜底参考**。优先使用 LLM 语义理解判断意图，仅在置信度不足时查阅此文件进行关键词匹配。

## 工作流触发

| 关键词 | 工作流 | 优先级 |
|--------|--------|--------|
| 测试策略 / 测试计划 / 测试范围 / 测试方案 | test-strategy-workflow | 高 |
| 测试用例 / 用例设计 / 写用例 / 等价类 / 边界值 | test-case-workflow | 高 |
| 测试执行 / 跑测试 / 回归测试 / 冒烟测试 | test-execution-workflow | 高 |
| 缺陷 / Bug / 问题 / 修复 / 验证 / 回归 | defect-management-workflow | 高 |

## 测试类型识别

| 关键词 | 测试类型 | 角色切换 |
|--------|---------|---------|
| 功能测试 / 黑盒 / 业务逻辑 | 功能测试 | 测试设计师 |
| 性能 / 压力 / 负载 / 并发 / QPS / TPS | 性能测试 | 性能工程师 |
| 安全 / 渗透 / 漏洞 / OWASP / XSS / SQL注入 | 安全测试 | 安全工程师 |
| 兼容性 / 浏览器 / 多端 / 响应式 | 兼容性测试 | 测试工程师 |
| 接口 / API / 接口测试 / Postman | 接口测试 | 测试工程师 |
| 自动化 / 脚本 / CI/CD / Selenium | 自动化测试 | 自动化工程师 |

## 缺陷操作识别

| 关键词 | 操作 | 紧急度 |
|--------|------|--------|
| 崩溃 / 死机 / 数据丢失 / 无法启动 | P0 致命缺陷 | 立即 |
| 核心功能不能用 / 严重错误 / 性能崩溃 | P1 严重缺陷 | 紧急 |
| 功能异常 / 显示错误 / 体验问题 | P2 一般缺陷 | 正常 |
| 文案错误 / 样式问题 / 优化建议 | P3 轻微缺陷 | 低 |

## 角色自动切换

| 场景关键词 | 默认角色 | 关注点偏移 |
|-----------|---------|-----------|
| 策略 / 计划 / 范围 / 排期 | 测试经理 | 测试规划、资源分配 |
| 用例 / 设计方法 / 等价类 / 覆盖率 | 测试设计师 | 用例质量、方法选择 |
| 自动化 / 脚本 / 框架 / 持续集成 | 自动化工程师 | 自动化覆盖率 |
| 性能 / 压力 / 负载 / 容量 | 性能工程师 | 性能指标、瓶颈 |
| 安全 / 渗透 / 漏洞 / OWASP | 安全工程师 | 安全风险 |

## 组合场景识别

| 场景 | 工作流组合 | 顺序 |
|------|-----------|------|
| 完整测试流程 | test-strategy → test-case → test-execution | 策略→用例→执行 |
| 测试+缺陷管理 | test-execution → defect-management | 执行→缺陷闭环 |
| 开发完了开始测试 | test-strategy → test-case → test-execution | 全流程 |
| 只写用例 | test-case-workflow | 单工作流 |
| 只报Bug | defect-management-workflow | 单工作流 |

## 匹配规则

```
1. 精确匹配 → 直接触发对应工作流
2. 包含匹配 → 按优先级匹配第一个命中项
3. 多关键词 → 取最高优先级
4. 无法匹配 → 使用日常模式 + 询问用户意图

优先级：工作流触发 > 测试类型识别 > 角色切换 > 日常工作流
```
