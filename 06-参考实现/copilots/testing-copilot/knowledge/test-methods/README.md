# 测试方法速查

> 按测试类型提供方法速查 + 设计决策树，供工作流引用

---

## 1. 功能测试

### 定义
验证软件功能是否符合需求规格说明书的要求。

### 核心方法

| 方法 | 适用场景 | 关键产出 | 难度 |
|------|---------|---------|------|
| 等价类划分 | 输入域测试 | 有效/无效等价类 | 低 |
| 边界值分析 | 数值/日期/长度边界 | 边界+次边界值 | 低 |
| 场景法 | 业务流程 | 正向+异常场景 | 中 |
| 判定表 | 多条件组合 | 条件组合矩阵 | 中 |
| 正交实验 | 多因素多水平 | 最少组合覆盖 | 高 |
| 状态迁移 | 状态流转 | 状态转换矩阵 | 中 |
| 错误推测 | 经验补充 | 异常场景补充 | 中 |
| 探索性测试 | 未知风险 | 缺陷发现 | 高 |

### 覆盖率标准

```
P0 功能：100% 用例覆盖（每条需求至少 1 条用例）
P1 功能：>= 95% 用例覆盖
P2 功能：>= 80% 用例覆盖
P3 功能：>= 60% 用例覆盖或抽样测试
```

## 2. 边界值测试

### 适用场景
- 数值范围（年龄 1-150、金额 0.01-99999.99）
- 字符串长度（密码 6-20、用户名 2-50）
- 日期范围（开始日期 <= 结束日期）
- 数组/列表长度（最少 1 项、最多 100 项）
- 分页参数（页码 >= 1、每页 10-100）

### 边界值选取规则

```
闭区间 [a, b]：
  测试点：a-1, a, a+1, b-1, b, b+1

开区间 (a, b)：
  测试点：a, a+1, a+2, b-2, b-1, b

半开半闭 [a, b)：
  测试点：a-1, a, a+1, b-2, b-1, b

特殊值：
  0、负数、极大值、极小值、NaN、null、undefined、空字符串
```

### 常见边界值清单

```
数值类型：0, 1, -1, 最大值, 最小值, 最大值+1, 最小值-1
字符串类型：空串, 1字符, 最大长度-1, 最大长度, 最大长度+1
日期类型：当天, 昨天, 明天, 最小日期, 最大日期, 2月29日
集合类型：空集, 1个元素, 最大-1个, 最大个, 最大+1个
```

## 3. 性能测试

### 测试类型

| 类型 | 目的 | 指标 | 持续时间 |
|------|------|------|---------|
| 基准测试 | 建立性能基线 | RT/QPS/资源 | 5-10min |
| 负载测试 | 验证正常负载表现 | RT/QPS/资源 | 30-60min |
| 压力测试 | 发现性能瓶颈 | RT/QPS/错误率/资源 | 30-60min |
| 稳定性测试 | 验证长时间运行 | 内存泄漏/性能退化 | 2-24h |
| 容量测试 | 确定最大承载 | 最大QPS/最大并发 | 30-60min |
| 并发测试 | 验证并发处理 | RT/QPS/数据一致性 | 10-30min |

### 性能指标标准（参考值）

```
响应时间(RT)：
  P50 < 200ms（一般接口）
  P90 < 500ms（一般接口）
  P99 < 1000ms（一般接口）
  P50 < 1s（页面加载）
  P99 < 3s（页面加载）

吞吐量(QPS/TPS)：
  根据业务峰值评估
  建议：日常的 3-5 倍作为测试目标

错误率：
  < 0.1%（一般接口）
  < 1%（高并发场景）

资源利用率：
  CPU < 70%（平均）
  内存 < 80%（无持续增长趋势）
  IO < 70%
  网络 < 50%
```

### 性能测试流程

```
1. 确定测试场景（哪些接口/页面需要测试）
2. 设定性能目标（QPS/RT/并发数）
3. 准备测试数据（数据量与生产相当）
4. 编写性能脚本（JMeter/k6/Locust）
5. 执行测试（逐步加压 → 持续 → 降压）
6. 收集指标（RT/QPS/错误率/资源）
7. 分析瓶颈（CPU/内存/IO/网络/数据库/代码）
8. 输出报告（指标 + 瓶颈 + 优化建议）
```

## 4. 安全测试

### 测试类型

| 类型 | 目的 | 方法 | 工具 |
|------|------|------|------|
| 漏洞扫描 | 发现已知漏洞 | 自动扫描 | OWASP ZAP/Burp Suite |
| 渗透测试 | 模拟攻击 | 手工+工具 | Burp Suite/SQLMap |
| 权限测试 | 验证访问控制 | 水平/越权测试 | 手工 |
| 输入验证 | 防注入/XSS | 注入测试 | 手工+工具 |
| 数据安全 | 敏感数据保护 | 抓包/审计 | Wireshark |
| 配置审计 | 安全配置检查 | 检查清单 | 手工 |

### OWASP Top 10（2021）

```
A01:2021 - 失效的访问控制
A02:2021 - 加密机制失败
A03:2021 - 注入攻击
A04:2021 - 不安全的设计
A05:2021 - 安全配置错误
A06:2021 - 脆弱和过时的组件
A07:2021 - 身份识别和认证失败
A08:2021 - 软件和数据完整性失败
A09:2021 - 安全日志和监控失败
A10:2021 - 服务端请求伪造(SSRF)
```

### 安全测试检查清单

```
认证与授权：
  [ ] 登录接口有防暴力破解机制
  [ ] 密码加密存储（bcrypt/argon2）
  [ ] Session/Token 有过期机制
  [ ] 水平越权：用户A不能访问用户B的资源
  [ ] 垂直越权：普通用户不能访问管理接口

输入验证：
  [ ] SQL 注入测试（' OR 1=1 --）
  [ ] XSS 测试（<script>alert(1)</script>）
  [ ] 命令注入测试（; ls -la）
  [ ] 路径穿越测试（../../etc/passwd）
  [ ] 文件上传测试（.php/.jsp/.exe）

数据安全：
  [ ] 敏感数据传输使用 HTTPS
  [ ] 敏感数据不记录到日志
  [ ] API 响应不泄露内部信息
  [ ] 个人信息脱敏显示

配置安全：
  [ ] 关闭调试模式
  [ ] 移除默认账户/密码
  [ ] CORS 配置正确
  [ ] HTTP 安全头已设置
```

## 5. 兼容性测试

### 测试维度

| 维度 | 覆盖范围 | 优先级 |
|------|---------|--------|
| 浏览器 | Chrome/Firefox/Safari/Edge | P0 |
| 操作系统 | Windows/macOS/iOS/Android | P1 |
| 分辨率 | 1920x1080/1366x768/375x667/414x896 | P1 |
| 设备 | PC/平板/手机 | P1 |

### 浏览器兼容性矩阵

```
必测（P0）：
  Chrome（最新版 + 前两个版本）
  Firefox（最新版）
  Safari（最新版，macOS/iOS）
  Edge（最新版）

建议测（P1）：
  Chrome Android
  Safari iOS
  微信内置浏览器

可选测（P2）：
  IE 11（如有遗留用户）
  Samsung Internet
  UC 浏览器
```

### 响应式断点

```
移动端：320px - 480px
平板竖屏：481px - 768px
平板横屏：769px - 1024px
桌面端：1025px - 1440px
大屏：1441px+
```

## 6. 测试方法选择决策树

```
开始
  ↓
什么类型的测试？
  │
  ├─ 功能测试 →
  │    ├─ 有输入域？ → 等价类划分 + 边界值分析
  │    ├─ 有业务流程？ → 场景法
  │    ├─ 有多条件组合？ → 判定表
  │    ├─ 有状态流转？ → 状态迁移
  │    ├─ 有多因素配置？ → 正交实验
  │    └─ 其他 → 错误推测 + 探索性测试
  │
  ├─ 性能测试 →
  │    ├─ 建立基线 → 基准测试
  │    ├─ 验证负载 → 负载测试
  │    ├─ 找瓶颈 → 压力测试
  │    ├─ 长时间运行 → 稳定性测试
  │    └─ 确定上限 → 容量测试
  │
  ├─ 安全测试 →
  │    ├─ 自动扫描 → 漏洞扫描
  │    ├─ 模拟攻击 → 渗透测试
  │    ├─ 权限检查 → 权限测试
  │    └─ 输入验证 → 注入测试
  │
  └─ 兼容性测试 →
       ├─ 多浏览器 → 浏览器矩阵
       ├─ 多设备 → 设备矩阵
       ├─ 多分辨率 → 断点测试
       └─ 多系统 → 系统矩阵
```
