# 验收管理工作流

> 覆盖阶段：交付·验收（验收测试）
> 对应角色：验收经理

---

## 适用场景

当系统已部署完成，需要按验收标准进行验收测试并获得客户确认时使用。

- 客户验收测试（UAT）
- 内部验收评审
- 阶段性验收（里程碑验收）
- 最终验收签收

## 前置条件

```
必须：
  [x] 系统已部署到验收环境
  [x] PRD Part 11 验收标准已确认
  [x] 测试报告已通过（All Pass）

建议：
  [ ] 客户方验收人员已确定
  [ ] 验收账号/数据已准备
  [ ] 验收场地/设备已安排
```

## 阶段

### Stage 1: 验收准备

- **输入**：PRD Part 11 验收标准 + 测试报告 + 部署确认
- **动作**：
  1. 确认验收标准
     - 逐条梳理 PRD Part 11 中的验收标准
     - 将验收标准转化为可执行的验收用例
     - 标注每条标准的验证方式（演示/操作/文档/数据）
     - 与客户确认验收标准的理解一致
  2. 准备验收环境
     - 确认验收环境与生产环境一致性
     - 准备验收测试数据
     - 配置验收专用账号和权限
     - 确认网络/设备/浏览器等基础条件
  3. 制定验收计划
     - 验收时间安排
     - 验收人员分工
     - 验收流程说明
     - 问题处理机制
- **输出**：验收计划
  ```
  验收计划：

  一、验收标准（共 {N} 条）
    功能验收：{N} 条
    性能验收：{N} 条
    安全验收：{N} 条
    兼容性验收：{N} 条
    文档验收：{N} 条

  二、验收人员
    客户方：{姓名}（{角色}）、{姓名}（{角色}）
    我方：{姓名}（产品）、{姓名}（技术）、{姓名}（测试）

  三、验收时间
    {开始日期} ~ {结束日期}，共 {N} 个工作日

  四、验收流程
    1. 验收宣讲（30min）：系统介绍 + 操作演示
    2. 功能验收（2天）：按验收标准逐项操作验证
    3. 性能验收（0.5天）：核心场景性能测试
    4. 文档验收（0.5天）：交付文档评审
    5. 问题汇总（0.5天）：遗留项确认 + 验收结论
    6. 签字确认（0.5天）：验收报告签署

  五、验收数据
    验收账号：{列表}
    测试数据：{说明}
  ```

### Stage 2: 验收测试

- **输入**：验收计划 + 验收标准 + PRD 文档
- **动作**：
  1. 验收宣讲
     - 系统整体介绍（架构/功能/亮点）
     - 核心流程演示
     - 验收标准说明
     - 操作注意事项
  2. 逐项验证（按 PRD Part 11 验收标准）
     - 功能验收：逐条操作验证
     - 性能验收：核心场景性能指标确认
     - 安全验收：安全功能验证
     - 兼容性验收：多环境验证
     - 文档验收：交付文档评审
  3. 记录验收结果
     - 每条标准标注：通过/不通过/待确认
     - 不通过项记录具体问题
     - 待确认项标注待确认原因
  4. 问题处理
     - 发现问题立即评估影响
     - 可现场修复 → 修复后重新验证
     - 不可现场修复 → 记录为遗留项
- **输出**：验收测试记录
  ```
  | 序号 | 验收标准 | 验证方式 | 验收结果 | 备注 |
  |------|---------|---------|---------|------|
  | 1 | 用户可通过手机号登录 | 操作 | 通过 | — |
  | 2 | 登录接口响应时间 < 500ms | 测试 | 通过 | P99 = 320ms |
  | 3 | 支持Chrome/Firefox/Safari | 操作 | 通过 | 已验证最新版 |
  | 4 | 用户密码加密存储 | 文档 | 通过 | 使用 bcrypt |
  | 5 | 提供完整用户手册 | 文档 | 通过 | 48页，含截图 |
  ```

### Stage 3: 报告输出

- **输入**：验收测试记录 + 问题清单
- **动作**：
  1. 统计验收结果
     - 通过率（通过项/总项）
     - 不通过项清单
     - 遗留项清单
  2. 编写验收报告
     - 验收概述（范围/时间/人员）
     - 验收结果统计
     - 逐项验收记录
     - 遗留问题及处理计划
     - 验收结论
  3. 获取签字确认
     - 客户方签字
     - 我方签字
     - 日期确认
  4. 遗留项处理
     - 约定修复时间
     - 约定验证方式
     - 约定二次验收（如需）
- **输出**：验收报告
  - 验收概述
  - 验收统计
  - 逐项记录
  - 遗留问题
  - 验收结论
  - 签字确认页

## 验收结论模板

```
验收结论：[通过 / 条件通过 / 不通过]

验收统计：
  总验收项：{N} 条
  通过：{N} 条 ({%})
  不通过：{N} 条 ({%})
  待确认：{N} 条 ({%})

遗留问题：
  | 序号 | 问题描述 | 影响 | 计划完成时间 |
  |------|---------|------|------------|

验收意见：
  客户方：{意见}     签字：______ 日期：______
  我方：{意见}       签字：______ 日期：______
```

## 产物归档

```
项目文档/交付管理/
├── 验收计划.md
├── 验收测试记录.md（或 .xlsx）
├── 验收报告.md（或 .docx）
└── 遗留问题清单.md
```

## 降级策略

| 缺失资源 | 降级行为 |
|----------|----------|
| acceptance-manager 未安装 | 使用内置验收流程模板 |
| PRD Part 11 不完整 | 基于功能清单 + 客户口头确认补充验收标准 |
| docx/xlsx 未安装 | 输出 Markdown 格式 |
| 客户无法现场验收 | 远程视频验收 + 屏幕录制 + 电子签章 |

## 验收标准来源优先级

```
1. PRD Part 11 验收标准（最高优先级）
2. 合同附件验收条款
3. 客户书面/邮件确认的标准
4. 行业通用标准
5. 客户口头要求（需书面确认后生效）
```
