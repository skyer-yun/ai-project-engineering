# 意图触发映射

> 本文件为意图识别的**兜底参考**。优先使用 LLM 语义理解判断意图，仅在置信度不足时查阅此文件。

## 工作流触发

| 关键词 | 工作流 | 优先级 |
|--------|--------|--------|
| 部署 / 上线 / 发布 / 环境 / 部署方案 / 上线方案 | deployment-workflow | 高 |
| 验收 / UAT / 确认 / 签收 / 验收测试 / 验收报告 | acceptance-workflow | 高 |
| 用户手册 / 运维手册 / 培训 / 交付文档 / 文档包 | delivery-doc-workflow | 高 |

## 任务类型识别

| 关键词 | 任务类型 | 角色切换 |
|--------|---------|---------|
| Docker / 容器 / 镜像 / docker-compose | 容器化部署 | 部署工程师 |
| K8s / Kubernetes / Helm / 集群 | K8s 部署 | 部署工程师 |
| 云服务 / 阿里云 / 腾讯云 / AWS | 云部署 | 部署工程师 |
| 私有化 / 内网 / 离线 / 本地化 | 私有化部署 | 部署工程师 |
| 灰度 / 金丝雀 / 蓝绿 / 滚动 | 发布策略 | 部署工程师 |
| 回滚 / 版本回退 / 降级 | 回滚操作 | 部署工程师 |
| 监控 / 告警 / 巡检 / 应急 | 运维支持 | 运维工程师 |
| 培训 / 演示 / Demo培训 / 用户培训 | 培训支持 | 文档工程师 |

## 角色自动切换

| 场景关键词 | 默认角色 | 关注点偏移 |
|-----------|---------|-----------|
| 部署 / 上线 / 发布 / 环境 | 部署工程师 | 部署方案、环境配置 |
| 验收 / UAT / 签收 | 验收经理 | 验收标准、客户确认 |
| 手册 / 文档 / 操作说明 | 文档工程师 | 文档质量、用户友好 |
| 运维 / 监控 / 应急 | 运维工程师 | 运维流程、监控指标 |

## 组合场景识别

| 场景 | 工作流组合 | 顺序 |
|------|-----------|------|
| 完整交付流程 | deployment → acceptance → delivery-doc | 部署→验收→文档 |
| 只部署 | deployment-workflow | 单工作流 |
| 只做验收 | acceptance-workflow | 单工作流 |
| 只写文档 | delivery-doc-workflow | 单工作流 |
| 测试通过了开始交付 | deployment → acceptance → delivery-doc | 全流程 |

## 匹配规则

```
1. 精确匹配 → 直接触发对应工作流
2. 包含匹配 → 按优先级匹配第一个命中项
3. 多关键词 → 取最高优先级
4. 无法匹配 → 使用日常模式 + 询问用户意图

优先级：工作流触发 > 任务类型识别 > 角色切换 > 日常工作流
```
