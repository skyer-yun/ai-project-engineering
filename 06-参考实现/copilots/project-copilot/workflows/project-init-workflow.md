# 项目启动工作流

> 覆盖阶段：N1（项目启动）
> 对应角色：规划师

---

## 适用场景

当新项目需要启动时使用，完成从信息收集到项目初始化的全过程。

- 新项目立项
- 项目阶段复盘后重新启动
- 子项目/迭代启动

## 前置条件

```
必须：
  [x] 用户提出项目需求或意图

建议：
  [ ] 有初步的项目背景信息
  [ ] 知道项目类型（产品开发/售前投标/迭代/自由）
```

## 阶段

### Stage 1: 信息收集

- **输入**：用户口头/书面描述 + 已有项目资料
- **动作**：
  1. 收集项目基本信息
     - 项目名称
     - 项目背景与目标
     - 客户/业务方
     - 预期交付时间
     - 预算约束（如有）
  2. 收集范围信息
     - 核心功能/交付物
     - 不在范围内的事项
     - 关键约束条件
  3. 识别干系人
     - 项目发起人
     - 客户方关键决策人
     - 团队成员及角色
     - 其他相关方
  4. 收集约束条件
     - 时间约束
     - 资源约束
     - 技术约束
     - 合规要求
- **输出**：项目基本信息表
  ```
  项目名称：{名称}
  项目背景：{描述}
  项目目标：{SMART 目标}
  客户/业务方：{名称}
  预期交付：{日期}
  预算：{金额或"待定"}
  核心范围：{列表}
  排除范围：{列表}
  关键约束：{列表}
  干系人：{列表}
  ```

### Stage 2: 类型判断

- **输入**：项目基本信息表
- **动作**：
  1. 根据项目特征判断类型（参考 `knowledge/project-types/README.md`）

     | 类型 | 判断条件 | 典型场景 |
     |------|---------|---------|
     | [A] 产品开发 | 有明确需求，需从零构建 | 新产品、新系统 |
     | [B] 售前/投标 | 有招标文件或客户明确需求 | 投标项目、竞标 |
     | [C] 迭代优化 | 基于已有系统进行改进 | 版本升级、功能优化 |
     | [D] 自由规划 | 无明确前置文档 | 灵活启动、内部项目 |

  2. 确定项目阶段路线
     - [A] 产品开发：N1→N2→N3→...→N16（完整流程）
     - [B] 售前/投标：N1→N3→N4→...→N16（快速需求确认）
     - [C] 迭代优化：N1→N2→N8→...→N16（跳过产品设计）
     - [D] 自由规划：根据实际情况灵活编排
  3. 确定涉及的智能体
     - 全流程：pre-sales + product + dev + testing + delivery
     - 部分流程：根据阶段路线选择
- **输出**：项目类型确认
  ```
  项目类型：[A/B/C/D] {类型名称}
  阶段路线：N{x}→N{y}→...
  涉及智能体：{列表}
  项目特征：{关键特征描述}
  ```

### Stage 3: 初始化

- **输入**：项目基本信息表 + 项目类型确认
- **动作**：
  1. 创建项目文档框架
     ```
     项目文档/{客户名}-{项目名}/
     ├── 01-售前文档/
     ├── 02-产品文档/
     ├── 03-开发文档/
     ├── 04-测试文档/
     ├── 05-交付文档/
     └── 06-项目管理/
         ├── 项目章程.md
         ├── 项目计划.md
         ├── WBS.md
         ├── 甘特图.mmd
         ├── 风险登记册.md
         └── 周报/
     ```
  2. 编写项目章程（草案）
     - 项目概述
     - 项目目标（SMART）
     - 项目范围
     - 里程碑（初步）
     - 干系人登记表
     - 项目组织架构
     - 初始风险清单
  3. 确定角色分配
     - 项目经理
     - 产品负责人
     - 技术负责人
     - 测试负责人
     - 交付负责人
  4. 设定初步里程碑
- **输出**：
  - 项目文档框架
  - 项目章程（草案）
  - 干系人登记表
  - 初步里程碑

## 项目启动检查清单

```
启动完成需确认：
  [ ] 项目名称已确认
  [ ] 项目目标已明确（SMART）
  [ ] 项目范围已初步定义
  [ ] 项目类型已判断
  [ ] 阶段路线已确定
  [ ] 干系人已识别
  [ ] 角色分工已明确
  [ ] 项目文档框架已创建
  [ ] 初步里程碑已设定
  [ ] 项目章程已编写（草案）
```

## 降级策略

| 缺失资源 | 降级行为 |
|----------|----------|
| 信息不完整 | 标注待确认项，使用占位符继续 |
| 无前置文档 | 标注为 [D] 自由规划类型，灵活编排 |
| xlsx/docx 未安装 | 输出 Markdown 格式 |
