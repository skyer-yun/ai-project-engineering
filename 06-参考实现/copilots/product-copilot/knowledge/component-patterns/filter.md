# 筛选器交互模式

> 适用场景：列表页搜索区、数据查询面板、报表条件筛选、后台管理筛选

## 筛选区域结构

### 标准布局
```
┌──────────────────────────────────────────────────────┐
│  筛选条件区                                          │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌────────┐  │
│  │ 关键词   │ │ 状态     │ │ 日期范围 │ │ 类型   │  │
│  │ [______] │ │ [____▼]  │ │ [____]   │ │ [___▼] │  │
│  └──────────┘ └──────────┘ └──────────┘ └────────┘  │
│                                                      │
│  [S 查询]  [R 重置]            [展开更多 v]        │
└──────────────────────────────────────────────────────┘
```

### 展开后（更多条件）
```
┌──────────────────────────────────────────────────────┐
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌────────┐  │
│  │ 关键词   │ │ 状态     │ │ 日期范围 │ │ 类型   │  │
│  └──────────┘ └──────────┘ └──────────┘ └────────┘  │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐             │
│  │ 创建人   │ │ 部门     │ │ 优先级   │             │
│  └──────────┘ └──────────┘ └──────────┘             │
│                                                      │
│  [S 查询]  [R 重置]            [收起 ^]            │
└──────────────────────────────────────────────────────┘
```

### 折叠模式规则
```
条件 ≤ 3 个：全部展示，不显示展开/收起按钮
条件 4-6 个：默认展示前 3 个，可展开
条件 > 6 个：默认展示前 3 个，展开后显示全部
展开/收起状态：记录用户偏好，刷新后保持
```

## 筛选类型速查

| 类型 | 组件 | 适用数据 | 示例 |
|------|------|---------|------|
| 文本输入 | Input | 模糊搜索字段 | 名称、编号、描述 |
| 下拉选择 | Select | 枚举值 | 状态、类型、分类 |
| 日期选择 | DatePicker | 日期字段 | 创建时间、截止日期 |
| 日期范围 | RangePicker | 时间区间 | 开始-结束日期 |
| 数字范围 | InputNumber × 2 | 数值区间 | 金额范围、年龄范围 |
| 级联选择 | Cascader | 树形数据 | 省市区、组织架构 |
| 多选标签 | Select(multiple) | 多值枚举 | 标签、角色 |
| 开关 | Switch | 布尔值 | 是否过期、是否有效 |
| 树选择 | TreeSelect | 层级数据 | 部门、分类 |

## 交互行为

### 查询流程
```
页面加载 → 自动查询第一页（携带默认筛选条件）
  ↓
用户修改筛选条件 → 手动点击"查询"按钮
  ↓
查询请求发出 → loading 状态 → 数据更新
  ↓
切换分页 → 保持筛选条件不变，仅切换页码
  ↓
排序 → 保持筛选条件不变，切换排序字段
  ↓
重置 → 清空所有筛选条件，恢复默认，自动查询
```

### 交互时序
| 交互 | 触发方式 | 行为 | 防抖 |
|------|---------|------|------|
| 查询 | 点击"查询"按钮 | 发送筛选请求 | 无 |
| 重置 | 点击"重置"按钮 | 清空所有字段 + 自动查询 | 无 |
| 回车查询 | 输入框按 Enter | 等同点击"查询" | 无 |
| 联动筛选 | 选择上级字段 | 清空下级字段 + 刷新选项 | 无 |
| 实时搜索 | 输入框输入 | 下拉匹配建议 | 300ms |

### 联动规则
```
常见联动场景：
  1. 选择省份 → 城市列表刷新 → 区县列表清空
  2. 选择部门 → 人员列表刷新
  3. 选择类型 → 子类型列表刷新
  4. 切换日期粒度 → 日期选择器格式变化

实现要点：
  - 上级变更时，清空所有下级已选值
  - 下级选项加载时显示 loading
  - 无选项时显示"暂无数据"
```

### 状态管理
| 状态 | 表现 | 说明 |
|------|------|------|
| 初始态 | 默认值填充 | 页码=1，其他字段为空或预设默认值 |
| 查询中 | 表格 loading + 筛选区禁用 | 防止重复提交 |
| 查询成功 | 数据展示 + 结果计数 | "共 XX 条" |
| 查询失败 | 错误提示 + 重试按钮 | 筛选条件保留 |
| 无结果 | 空状态占位 | "暂无匹配数据" |

## 设计规范

### 布局
```
标签宽度：80-100px（右对齐）
输入框宽度：200-240px（Select/DatePicker）
输入框宽度：280-320px（RangePicker）
间距：字段间 16px，行间 16-24px
按钮区：左对齐，与最后一个字段同行或独立一行
```

### 按钮样式
```
查询按钮：主色（Primary），左对齐
重置按钮：默认（Default），紧跟查询按钮
展开/收起：文字链接样式（Link），右对齐
按钮间距：8-12px
```

### 响应式
```
≥ 1200px：每行 4 个筛选字段
≥ 992px： 每行 3 个筛选字段
≥ 768px： 每行 2 个筛选字段
< 768px： 每行 1 个筛选字段，查询/重置按钮全宽
```

## PRD 描述模板

### Part 7 筛选器功能描述示例
```
功能名称：订单列表筛选区
组件类型：filter

筛选字段：
| 字段 | 组件 | 默认值 | 说明 |
|------|------|--------|------|
| 订单编号 | Input | - | 精确匹配 |
| 客户名称 | Select(远程搜索) | - | 模糊搜索，防抖 300ms |
| 订单状态 | Select(多选) | 全部 | 待付款/已付款/已发货/已完成/已取消 |
| 下单时间 | RangePicker | 近30天 | 日期范围 |
| 金额范围 | InputNumber × 2 | - | 最小值-最大值 |

交互行为：
  1. 页面加载自动查询近30天订单
  2. 修改条件后点击"查询"刷新列表
  3. "重置"清空所有条件，恢复近30天默认
  4. 客户名称支持拼音首字母搜索
  5. 切换分页/排序时保持筛选条件

业务规则：
  BR-001：日期范围不超过1年，超出时提示"时间范围不能超过1年"
  BR-002：金额最小值不能大于最大值
  BR-003：筛选条件序列化到URL参数，刷新页面后恢复

异常处理：
  E-001：客户名称搜索接口超时 → 显示"搜索失败，请重试"
  E-002：筛选结果超过10000条 → 提示"建议缩小筛选范围"
  E-003：导出时携带当前筛选条件
```

## 标注内容模板
```
目标选择器：.filter-section 或 [data-filter-id="xxx"]
内容结构：
  1. 筛选字段清单（组件类型 + 默认值 + 校验规则）
  2. 查询/重置交互流程
  3. 联动关系（字段间依赖）
  4. 业务规则（编号 BR-XXX）
  5. 异常处理（编号 E-XXX）
  6. 折叠/展开阈值与默认展示数量
```
