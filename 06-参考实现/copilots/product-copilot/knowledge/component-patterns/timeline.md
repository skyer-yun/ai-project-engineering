# 时间线交互模式

> 适用场景：操作记录、审批历史、状态变更日志、工单跟踪、版本记录

## 布局类型

### 左侧时间线（标准）
```
    时间线轴（左侧）
    │
    ●── 2026-05-18 14:30
    │   张三 提交了审批申请
    │   [附件: 需求文档.pdf]
    │
    ●── 2026-05-18 10:15
    │   李四 添加了评论
    │   "建议增加数据导出功能"
    │
    ●── 2026-05-17 16:00
    │   系统 自动变更状态
    │   草稿 → 待审核
    │
    ○── (等待中) 审批节点
        王五 · 部门经理
```

### 交替时间线
```
    2026-05-18 14:30  ──●──  张三提交审批
                            附件: 需求文档.pdf

    李四添加评论  ──●──  2026-05-18 10:15
    "建议增加数据导出功能"

    系统变更状态  ──●──  2026-05-17 16:00
    草稿 → 待审核
```

### 水平时间线（流程步骤）
```
  ●────────●────────●────────○
  提交申请   审批中    已通过   发布
  05-17     05-18    进行中   待定
```

## 节点类型

### 信息节点（蓝色 ●）
```
用途：纯信息记录
内容：时间 + 操作人 + 动作描述
示例：张三 修改了截止日期为 2026-06-30
```

### 操作节点（绿色 ●）
```
用途：用户主动操作
内容：时间 + 操作人 + 操作类型 + 详情
示例：张三 上传了文件 [需求文档.pdf]
可展开：点击显示操作详情/附件预览
```

### 状态节点（橙色 ●）
```
用途：状态变更
内容：时间 + 操作人/系统 + 旧状态 → 新状态
视觉：状态标签颜色变化
示例：系统 状态变更 [草稿] → [待审核]
```

### 警告节点（红色 ●）
```
用途：异常/驳回/超时
内容：时间 + 原因描述
视觉：红色图标 + 红色文字
示例：王五 驳回了申请，原因：预算超出
```

### 待处理节点（灰色 ○）
```
用途：尚未发生的未来步骤
内容：预期操作 + 负责人
视觉：灰色虚线圆 + 灰色文字
示例：(等待中) 王五 · 部门经理审批
```

## 内容字段模板

### 操作记录
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 时间 | datetime | 是 | YYYY-MM-DD HH:mm |
| 操作人 | string | 是 | 姓名 + 头像 |
| 操作类型 | enum | 是 | 创建/编辑/删除/提交/审批/评论/上传/状态变更 |
| 描述 | text | 是 | 操作描述（一段话） |
| 变更详情 | object | 否 | 字段级变更记录（旧值 → 新值） |
| 附件 | array | 否 | 附件文件列表 |
| 评论内容 | text | 否 | 评论/审批意见 |

### 变更详情结构
```
变更详情格式：
  修改了以下字段：
  · 截止日期：2026-05-30 → 2026-06-30
  · 优先级：P2 → P1
  · 负责人：张三 → 李四

新增字段：
  + 关联需求：REQ-001

删除字段：
  - 临时备注
```

## 交互行为

### 基础交互
| 交互 | 行为 | 说明 |
|------|------|------|
| 展开详情 | 点击节点展开完整变更详情 | 默认收起，只显示摘要 |
| 附件预览 | 点击附件名预览/下载 | 图片直接预览，其他下载 |
| 操作人信息 | 悬浮/点击显示操作人名片 | 头像 + 姓名 + 部门 + 联系方式 |
| 加载更多 | 底部"加载更多"按钮 | 懒加载历史记录 |

### 筛选与搜索
```
筛选维度：
  - 操作类型：全部/创建/编辑/状态变更/评论/审批
  - 操作人：选择特定人员
  - 时间范围：今日/近7天/近30天/自定义

搜索：
  - 搜索操作描述内容
  - 高亮匹配关键词
```

### 实时更新
```
WebSocket 推送：
  新操作发生时 → 时间线顶部插入新节点（动画滑入）
  状态变更时 → 更新对应节点的状态标签
  不刷新页面
```

## 设计规范

### 尺寸
| 属性 | 值 | 说明 |
|------|---|------|
| 时间线宽度 | 2px | 轴线 |
| 节点圆点 | 8px（标准）/ 12px（当前步骤） | 圆形 |
| 左侧留白 | 20px | 时间线到左边缘 |
| 内容区左边距 | 32px | 时间线到内容文字 |
| 节点间距 | 16-20px | 两个节点之间的距离 |

### 颜色
```
节点颜色：
  信息节点：#1677FF（蓝色）
  操作节点：#52C41A（绿色）
  状态节点：#FAAD14（橙色）
  警告节点：#FF4D4F（红色）
  待处理：  #D9D9D9（灰色）
  时间线轴：#E8E8E8（浅灰）
```

### 时间格式
```
今天：     14:30（仅显示时间）
昨天：     昨天 14:30
7天内：    2天前 / 3天前
本年内：   05-15 14:30
跨年：     2025-12-20 14:30
```

## PRD 描述模板

```
功能名称：订单跟踪时间线
组件类型：timeline

节点类型：
  - 状态节点：订单状态变更（下单→付款→发货→签收）
  - 操作节点：物流操作记录
  - 警告节点：异常事件（超时/退货/拦截）

内容字段：
  - 时间、操作人/系统、操作描述
  - 物流节点额外：地点、快递员、联系方式
  - 异常节点额外：异常原因、处理方式

交互：
  1. 默认显示最近 10 条，底部"查看更早记录"
  2. 点击物流节点展开详情（地图定位可选）
  3. 实时推送新物流动态，顶部动画插入

业务规则：
  BR-001：签收状态节点显示绿色勾选图标
  BR-002：超过72小时无更新，自动添加"物流异常"警告节点
  BR-003：退换货流程独立时间线，可切换查看
```
