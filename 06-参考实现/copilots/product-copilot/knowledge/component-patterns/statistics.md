# 统计卡片交互模式

> 适用场景：Dashboard 概览、KPI 展示、数据大屏、首页统计

## 卡片类型

### 基础指标卡片
```
┌──────────────────────────┐
│  [chart] 总订单数              │
│                          │
│  12,846                  │
│  ↑ 12.5% 较昨日          │
└──────────────────────────┘
```

### 带趋势图卡片
```
┌──────────────────────────────────┐
│  [money] 销售额                       │
│  ¥ 1,286,500     ↗ +18.3%       │
│  ╱╲    ╱╲                        │
│ ╱  ╲╱╱  ╲╱╲                      │
│╱          ╲                       │
│  近7天趋势（迷你折线图）          │
└──────────────────────────────────┘
```

### 对比卡片
```
┌──────────────────────────────────┐
│  [users] 活跃用户                     │
│  ┌────────────┬────────────┐     │
│  │  本月       │  上月       │     │
│  │  3,256     │  2,890     │     │
│  │  ↑ 12.6%   │            │     │
│  └────────────┴────────────┘     │
└──────────────────────────────────┘
```

### 进度指标卡片
```
┌──────────────────────────────────┐
│  [target] 月度目标                     │
│  ¥ 1,286,500 / ¥ 2,000,000      │
│  ████████████░░░░░░░ 64.3%       │
│  距目标还差 ¥ 713,500            │
└──────────────────────────────────┘
```

### 多指标组合卡片
```
┌──────────────────────────────────────────┐
│  [trend] 今日概览                   [详情 →]  │
│──────────────────────────────────────────│
│  访客数        订单数        转化率       │
│  2,456        186          7.6%         │
│  ↑ 8.2%       ↑ 3.1%       ↓ 0.5%      │
└──────────────────────────────────────────┘
```

## 卡片结构字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 图标 | icon/svg | 否 | 左上角指标图标，主题色背景圆 |
| 标题 | string | 是 | 指标名称 |
| 数值 | number | 是 | 主指标值 |
| 单位 | string | 否 | ¥ / % / 人 / 件 |
| 趋势方向 | enum | 否 | up / down / flat |
| 趋势值 | string | 否 | "+12.5%" / "-3.2%" |
| 对比描述 | string | 否 | "较昨日" / "较上月" / "同比去年" |
| 迷你图 | chart | 否 | 近7天/30天迷你趋势图 |
| 链接 | url | 否 | 点击跳转详情页 |

## 趋势指标规范

### 趋势颜色
| 趋势 | 颜色 | 图标 | 说明 |
|------|------|------|------|
| 上升（正向） | #52C41A (绿) | ↑ | 收入、用户、订单增长 |
| 下降（正向） | #52C41A (绿) | ↓ | 退单率、投诉率下降 |
| 上升（负向） | #FF4D4F (红) | ↑ | 成本、错误率、流失率上升 |
| 下降（负向） | #FF4D4F (红) | ↓ | 收入、用户数下降 |
| 持平 | #8C8C8C (灰) | → | 变化幅度 < 0.1% |

### 数值格式化
| 类型 | 格式 | 示例 |
|------|------|------|
| 整数 | 千分位分隔 | 12,846 |
| 小数 | 保留2位 + 千分位 | 1,286.50 |
| 百分比 | 保留1-2位 + % | 64.3% |
| 货币 | ¥ + 千分位 | ¥ 1,286,500 |
| 大数 | 自动转换单位 | 1.28万 / 128.6万 / 1.29亿 |
| 时间 | 小时:分钟 | 2h 30m |

### 数值动画
```
Count-up 效果：
  触发：卡片进入可视区域（IntersectionObserver）
  时长：1000-1500ms
  缓动：ease-out（先快后慢）
  起始值：0 → 目标值
  大数格式化：动画结束后应用千分位
```

## 交互行为

### 基础交互
| 交互 | 行为 | 说明 |
|------|------|------|
| 悬浮 | 阴影加深 + 轻微上浮 | hover 反馈 |
| 点击 | 跳转详情页 / 展开详情 | 有链接时才可点击 |
| 时间切换 | 今日/昨日/本周/本月/自定义 | 右上角下拉选择 |
| 刷新 | 右上角刷新按钮 | 手动刷新数据 |

### 时间维度
```
可选维度（右上角下拉）：
  - 今日
  - 昨日
  - 本周
  - 本月
  - 上月
  - 自定义范围

默认：今日
切换后：所有卡片同步切换时间维度
```

### 加载与错误
| 状态 | 展示 | 说明 |
|------|------|------|
| 加载中 | 骨架屏（卡片轮廓 + 数字区域闪烁） | 数据请求中 |
| 正常 | 数值 + 趋势 + 迷你图 | 数据加载完成 |
| 无数据 | "--" 占位 | 无数据时显示占位符 |
| 错误 | 错误图标 + "加载失败" + 重试按钮 | 接口异常 |

### 响应式布局
```
卡片网格：
  ≥ 1600px：4 列
  ≥ 1200px：4 列
  ≥ 992px：  2 列
  ≥ 768px：  2 列
  < 768px：  1 列

卡片间距：16-24px（gutter）
```

## 设计规范

### 尺寸
| 卡片类型 | 宽度 | 高度 | 内边距 |
|----------|------|------|--------|
| 基础指标 | 响应式 | 120-140px | 20-24px |
| 带趋势图 | 响应式 | 160-180px | 20-24px |
| 对比卡片 | 响应式 | 160-180px | 20-24px |
| 进度卡片 | 响应式 | 140-160px | 20-24px |
| 多指标组合 | 2x 宽度 | 160-180px | 20-24px |

### 样式
```
背景：#FFFFFF
圆角：8-12px
阴影：0 1px 4px rgba(0,0,0,.06)
悬浮阴影：0 4px 12px rgba(0,0,0,.1)
数值字号：28-36px，加粗
标题字号：14px，#8C8C8C
趋势字号：12-13px
```

### 图标容器
```
尺寸：40×40px / 48×48px
圆角：8px（圆角矩形）
背景色：主色 10% 透明度（如 #E6F4FF）
图标颜色：主色（如 #1677FF）
```

## PRD 描述模板

### Part 7 统计卡片功能描述示例
```
功能名称：首页统计概览
组件类型：statistics（统计卡片组）

卡片列表：
| 卡片 | 指标 | 单位 | 趋势对比 | 迷你图 |
|------|------|------|---------|--------|
| 总销售额 | sum(amount) | ¥ | 较昨日 | 近7天折线 |
| 订单数 | count(id) | 件 | 较昨日 | 近7天折线 |
| 客单价 | avg(amount) | ¥ | 较昨日 | 无 |
| 转化率 | 转化/访客 | % | 较昨日 | 无 |

数值格式：
  - 销售额：¥ + 千分位，> 1万显示 X.XX万
  - 订单数：千分位整数
  - 客单价：¥ + 2位小数
  - 转化率：1位小数 + %

交互行为：
  1. 页面加载时数值 count-up 动画
  2. 点击"销售额"卡片跳转销售报表页
  3. 右上角时间维度切换（今日/本周/本月/上月）
  4. 手动刷新按钮

业务规则：
  BR-001：趋势色正向指标（销售额↑）为绿色，负向指标（退货率↑）为红色
  BR-002：销售额超过10万自动转换单位为"万"
  BR-003：无数据时显示"--"而非0
  BR-004：首次进入默认"今日"维度

异常处理：
  E-001：数据接口失败 → 显示上次缓存数据 + "数据可能非最新"
  E-002：实时数据延迟 > 5分钟 → 显示"数据更新于XX:XX"
```

## 标注内容模板
```
目标选择器：.statistics-card 或 [data-stat-id="xxx"]
内容结构：
  1. 指标清单（名称+计算公式+单位+格式化规则）
  2. 趋势对比维度（较昨日/较上月/自定义）
  3. 迷你图配置（数据范围+图表类型）
  4. 交互行为（点击跳转/时间切换）
  5. 业务规则（编号 BR-XXX）
  6. 异常处理（编号 E-XXX）
```
