# 权限管理交互模式

> 适用场景：角色管理、权限分配、数据权限、菜单权限、按钮权限

## 权限模型

### RBAC（基于角色的访问控制）— 最常用
```
用户 → 角色 → 权限
  张三 → 项目经理 → [查看项目/编辑项目/删除项目/分配任务]
  李四 → 开发人员 → [查看项目/编辑任务/更新进度]
  王五 → 访客     → [查看项目]
```

### ABAC（基于属性的访问控制）— 复杂场景
```
策略 = 主体属性 + 资源属性 + 环境属性 → 允许/拒绝
示例：
  部门=技术部 AND 级别≥P6 AND 工作日=true → 允许访问生产环境
```

## 权限粒度

| 粒度 | 说明 | 实现方式 | 示例 |
|------|------|---------|------|
| 菜单级 | 控制菜单/页面可见性 | 路由守卫 | 隐藏"系统设置"菜单 |
| 页面级 | 控制页面访问 | 路由守卫 + 403 | 无权限页面跳转403 |
| Tab级 | 控制标签页可见 | v-if | 隐藏"审批记录"Tab |
| 按钮级 | 控制操作按钮 | v-if/v-show | 隐藏"删除"按钮 |
| 字段级 | 控制字段可见/可编辑 | 条件渲染 | 身份证号脱敏/只读 |
| 数据级 | 控制数据范围 | SQL过滤 | 只看本部门数据 |

## 交互行为

### 权限树操作
| 操作 | 行为 |
|------|------|
| 勾选父节点 | 自动勾选所有子节点 |
| 取消父节点 | 自动取消所有子节点 |
| 勾选子节点 | 父节点变为半选（indeterminate） |
| 全部子节点勾选 | 父节点自动变为全选 |
| 全选 | 一键勾选所有权限 |
| 反选 | 已勾选变未勾选，反之 |

### 角色操作
```
新建角色：
  1. 输入角色名称 + 描述
  2. 选择权限（树形勾选）
  3. 保存

编辑角色：
  - 修改权限 → 保存后即时生效
  - 修改名称 → 需确认影响范围

删除角色：
  - 有成员时禁止删除，提示先转移成员
  - 系统内置角色不可删除，只能禁用

复制角色：
  - 基于现有角色快速创建新角色
  - 复制权限配置，不复制成员
```

### 权限生效机制
```
即时生效：
  修改权限 → 保存 → 服务端更新 → 前端刷新菜单/按钮

刷新策略：
  - 菜单权限：保存后自动刷新导航
  - 按钮权限：当前页面重新渲染
  - 数据权限：下次查询时生效

冲突处理：
  用户多角色时，权限取并集（拥有任一角色授予的权限即生效）
```

## PRD 描述模板

```
功能名称：角色权限管理
组件类型：permission

权限模型：RBAC

预设角色：
  - 系统管理员（全部权限，不可编辑/删除）
  - 项目经理（项目管理+任务管理+成员查看）
  - 开发人员（任务查看+编辑+进度更新）
  - 测试人员（任务查看+测试报告）
  - 访客（只读）

权限粒度：
  - 菜单级：控制导航菜单可见性
  - 按钮级：控制操作按钮显示
  - 数据级：本部门/指定部门/全部

交互：
  1. 角色列表页：增删改查+启用/禁用
  2. 权限分配：树形勾选，父子联动
  3. 成员管理：搜索添加/批量移除
  4. 修改即时生效

业务规则：
  BR-001：至少保留一个系统管理员角色
  BR-002：删除角色前必须先移除所有成员
  BR-003：用户多角色权限取并集
  BR-004：系统管理员权限不可缩减
  BR-005：权限变更记录审计日志
```
