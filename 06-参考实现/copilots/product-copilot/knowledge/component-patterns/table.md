## 列定义规范

### 列属性
| 属性 | 说明 | 示例 |
|------|------|------|
| 标题 | 列头显示文字 | "订单编号" |
| 宽度 | 固定/自适应/最小最大 | 120px / auto / min:80 max:200 |
| 对齐 | 文字对齐方式 | 数字右对齐，文字左对齐，状态居中 |
| 排序 | 是否支持排序 | 本地排序 / 远程排序 |
| 筛选 | 列头筛选 | 下拉筛选 / 自定义筛选面板 |
| 固定 | 左右固定列 | fixed: left / fixed: right |
| 省略 | 超长文本 | ellipsis: true + tooltip |

### 单元格渲染类型
| 类型 | 渲染方式 | 示例 |
|------|---------|------|
| 文本 | 直接显示，超长省略+tooltip | 名称、编号 |
| 数字 | 右对齐，千分位分隔 | 1,299.00 |
| 日期 | 格式化显示 | 2026-05-19 14:30 |
| 标签 | Tag 组件，状态色 | [待审核] [已完成] |
| 操作 | 按钮/链接组 | 编辑 删除 详情 |
| 链接 | 可点击文字，蓝色 | ORD-001（点击跳详情） |
| 进度 | Progress 组件 | ████████░░ 80% |
| 头像 | Avatar + 姓名 | (头像) 张三 |
| 图片 | 缩略图 + 预览 | 60×60 缩略图 |
| 空值 | 灰色占位符 | "--" 或 "-" |

### 操作列规范
```
按钮数量：
  1 个：直接显示按钮（查看）
  2 个：并排显示（编辑 删除）
  3+个：显示2个 + "更多"下拉（编辑 删除 ···）

操作列宽度：
  1 个按钮：80-100px
  2 个按钮：140-160px
  3+个按钮：100px（含更多下拉）

操作列固定：右侧固定（fixed: right），表格横向滚动时不丢失
```

## 交互行为

### 行选择
| 模式 | 行为 | 说明 |
|------|------|------|
| 单选 | 点击行或 Radio | 选中一行高亮，切换选中新行时取消旧行 |
| 多选 | Checkbox 列 | 表头全选/取消全选，单行勾选 |
| 批量操作 | 选中 2+ 行 | 顶部浮出批量操作栏（批量删除/导出/变更状态） |
| 翻页保持 | 翻页后保持选中 | 跨页选中状态不丢失 |

### 排序
```
单列排序（默认）：
  点击列头 → 升序 → 降序 → 取消排序（三态切换）
  排序图标：↑ (升序) / ↓ (降序) / ↕ (未排序)

多列排序：
  按住 Shift 点击多列
  优先级：最后点击的列为主排序

远程排序：
  排序字段 + 排序方向传参给接口
  表格显示 loading
```

### 分页
| 属性 | 默认值 | 说明 |
|------|--------|------|
| 每页条数 | 10 | 可选：10 / 20 / 50 / 100 |
| 总数显示 | 是 | "共 XX 条" |
| 页码按钮 | ≤7 页全显示 | >7 页显示首尾+当前±2+省略号 |
| 快速跳转 | 输入框 | 输入页码按 Enter 跳转 |
| 条数切换 | 下拉选择 | 切换后回到第一页 |

### 行内操作
```
查看详情：
  - 点击行 → 跳转详情页（新标签或当前页）
  - 或点击"查看"按钮

编辑：
  - 弹窗编辑（推荐）
  - 或行内编辑（双击单元格 → 输入框 → 回车/失焦保存）

删除：
  - 二次确认弹窗："确定删除[名称]吗？此操作不可恢复"
  - 成功后刷新列表，保持在当前页
```

### 空状态与加载
| 状态 | 展示 | 说明 |
|------|------|------|
| 首次加载 | 骨架屏（Skeleton） | 表格轮廓 + 行闪烁动画 |
| 刷新加载 | Spin 遮罩 | 半透明遮罩 + 居中旋转 |
| 无数据 | 空状态图 + 文字 + 操作按钮 | "暂无数据，点击新建" |
| 网络错误 | 错误图标 + 文字 + 重试按钮 | "加载失败，点击重试" |

## 设计规范

### 尺寸
| 属性 | 紧凑模式 | 标准模式 | 宽松模式 |
|------|---------|---------|---------|
| 表头高度 | 40px | 48px | 56px |
| 行高 | 40px | 48px | 56px |
| 单元格内边距 | 8px 12px | 12px 16px | 16px 20px |
| 字号 | 12-13px | 14px | 14-16px |

### 颜色
```
表头背景：#FAFAFA
行悬浮：#FAFAFA → #F5F5F5
选中行：#E6F4FF（浅蓝）
斑马纹：奇数行 #FFFFFF，偶数行 #FAFAFA
分割线：#F0F0F0（1px solid）
```

### 横向滚动
```
触发条件：列总宽度 > 容器宽度
滚动行为：左右滚动，首列（Checkbox/编号）和末列（操作）固定
固定列阴影：滚动时显示投影提示
```

## PRD 描述模板

### Part 7 表格功能描述示例
```
功能名称：订单管理表格
组件类型：table

列定义：
| 列名 | 字段 | 宽度 | 对齐 | 渲染 | 排序 | 固定 |
|------|------|------|------|------|------|------|
| ☐ | - | 48px | 居中 | Checkbox | - | 左 |
| 订单编号 | orderNo | 140px | 左 | 链接(跳详情) | 是 | 左 |
| 客户名称 | customer | 160px | 左 | 文本 | 否 | - |
| 订单状态 | status | 100px | 居中 | Tag(状态色) | 是 | - |
| 订单金额 | amount | 120px | 右 | 千分位 | 是 | - |
| 下单时间 | createdAt | 160px | 左 | YYYY-MM-DD HH:mm | 是 | - |
| 操作 | - | 140px | 居中 | 编辑/删除 | - | 右 |

交互行为：
  1. 页面加载查询第一页，默认按下单时间倒序
  2. 点击订单编号跳转详情页（新标签）
  3. 多选后顶部显示批量操作栏（批量导出/批量删除）
  4. 列头排序触发远程排序，显示 loading
  5. 删除操作二次确认，成功后刷新当前页

业务规则：
  BR-001：金额超过10000时显示红色
  BR-002：待审核订单操作列显示"审核"按钮，其他状态不显示
  BR-003：已完成的订单不可编辑和删除
  BR-004：分页切换后保持选中状态和筛选条件

异常处理：
  E-001：删除失败时 Toast 提示错误信息，不关闭确认弹窗
  E-002：数据量超过1000条时自动开启虚拟滚动
  E-003：接口超时显示缓存数据 + "数据可能非最新"提示
```

## 标注内容模板
```
目标选择器：.data-table 或 [data-table-id="xxx"]
内容结构：
  1. 列定义清单（字段+宽度+对齐+渲染类型+排序+固定）
  2. 行选择模式（单选/多选/批量操作）
  3. 分页配置（每页条数/总数/跳转）
  4. 操作列按钮与权限
  5. 业务规则（编号 BR-XXX）
  6. 异常处理（编号 E-XXX）
```
