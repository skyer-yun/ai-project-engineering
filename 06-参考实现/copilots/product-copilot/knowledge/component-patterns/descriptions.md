# 描述列表交互模式

> 适用场景：详情页信息展示、用户资料、订单详情、设备信息、配置查看

## 布局类型

### 水平布局（标签在左）
```
┌──────────────────────────────────────┐
│  订单编号    ORD-20260518001          │
│  下单时间    2026-05-18 14:30:00     │
│  订单状态    [待发货]                 │
│  订单金额    ¥ 1,299.00              │
│  收货地址    北京市朝阳区XX路XX号     │
│  付款方式    微信支付                 │
│  备注        请在工作日配送           │
└──────────────────────────────────────┘
标签宽度统一 120px，值宽度自适应
```

### 垂直布局（标签在上）
```
┌────────────┬────────────┬────────────┐
│  订单编号   │  下单时间   │  订单状态  │
│  ORD-001   │  05-18     │  [待发货]  │
├────────────┼────────────┼────────────┤
│  订单金额   │  付款方式   │  配送方式  │
│  ¥1,299    │  微信支付   │  快递      │
└────────────┴────────────┴────────────┘
标签在值上方，多列网格布局
```

### 响应式布局
```
≥ 768px：水平布局，标签在左
< 768px：垂直布局，标签在上
```

## 分组模式

### 卡片分组
```
┌─ 基本信息 ──────────────────────────┐
│  编号      ORD-20260518001          │
│  状态      [待发货]                 │
│  时间      2026-05-18 14:30        │
│  金额      ¥ 1,299.00              │
└─────────────────────────────────────┘

┌─ 收货信息 ──────────────────────────┐
│  收货人    张三                      │
│  电话      138****1234              │
│  地址      北京市朝阳区XX路XX号      │
└─────────────────────────────────────┘

┌─ 商品信息 ──────────────────────────┐
│  (表格或列表展示商品明细)            │
└─────────────────────────────────────┘
```

### 标签页分组
```
[基本信息] [物流信息] [支付信息] [操作记录]
  ┌─────────────────────────────────┐
  │  当前标签页的内容                │
  └─────────────────────────────────┘
```

## 字段类型与渲染

| 字段类型 | 渲染方式 | 示例 |
|----------|---------|------|
| 文本 | 普通文字 | 张三 |
| 数值 | 数字 + 单位 | 1,299.00 元 |
| 金额 | 符号 + 千分位 | ¥ 1,299.00 |
| 百分比 | 数值 + % | 85.6% |
| 日期 | YYYY-MM-DD | 2026-05-18 |
| 时间 | YYYY-MM-DD HH:mm:ss | 2026-05-18 14:30:00 |
| 状态 | 标签（带颜色） | [待发货]（蓝色） |
| 标签 | 多色标签组 | [新品] [热销] [推荐] |
| 进度 | 进度条 + 百分比 | ████████░░ 80% |
| 头像 | 头像图片 + 姓名 | [U] 张三 |
| 手机号 | 脱敏显示 | 138****1234 |
| 邮箱 | 可点击 mailto | zhangsan@example.com |
| 链接 | 可点击跳转 | 查看详情 → |
| 长文本 | 折叠展开（默认3行） | 展开/收起 |
| 图片 | 缩略图 + 点击预览 | [IMG] [IMG] [IMG] |
| 文件 | 文件名 + 下载按钮 | [doc] 报告.pdf [下载] |
| 评分 | 星级显示 | ★★★★☆ 4.0 |
| 空值 | 占位文字 | -- 或 暂无 |

## 交互行为

### 基础交互
| 交互 | 行为 | 说明 |
|------|------|------|
| 复制 | 点击字段值复制到剪贴板 | 订单号、手机号等场景 |
| 预览 | 图片/文件点击预览 | 图片放大/文件在线查看 |
| 拨号 | 手机号点击拨打（移动端） | tel: 链接 |
| 邮件 | 邮箱点击发送邮件 | mailto: 链接 |
| 跳转 | 关联ID点击跳转详情 | 订单号→订单详情 |

### 编辑模式
```
查看模式 → 点击"编辑"按钮 → 字段变为可编辑状态
  文本 → Input 输入框
  日期 → DatePicker 日期选择器
  下拉 → Select 下拉框
  多选 → Checkbox 多选组
编辑完成 → 点击"保存" → 提交修改
```

### 操作按钮
```
位置：页面右上角或描述列表底部
按钮组：
  - 编辑：切换为编辑模式
  - 删除：确认后删除（二次确认弹窗）
  - 返回：返回列表页
  - 更多：审批/导出/分享/归档等
```

## 设计规范

### 尺寸
| 属性 | 水平布局 | 垂直布局 |
|------|---------|---------|
| 标签宽度 | 100-140px | 100% |
| 行间距 | 16px | 24px（组间）/ 16px（组内） |
| 分组间距 | 24px | 24px |
| 分组标题 | 14px 加粗 | 14px 加粗 |
| 标签文字 | 14px 灰色（#8C8C8C） | 12px 灰色 |
| 值文字 | 14px 黑色（#262626） | 16px 黑色 |

### 空状态处理
```
字段无值时：
  - 显示 "--"（推荐，保持对齐）
  - 显示 "暂无"（中文语义化）
  - 不显示该行（不推荐，会破坏布局对齐）
  - 显示 "未填写" + 编辑引导（编辑场景）
```

## PRD 描述模板

```
功能名称：用户详情页
组件类型：descriptions

分组结构：
  基本信息：用户名/手机号/邮箱/注册时间/最后登录
  企业信息：公司名/职位/部门/行业/规模
  账号状态：账号状态/会员等级/余额/积分
  操作记录：(跳转标签页)

字段特殊处理：
  - 手机号：脱敏显示（138****1234），点击复制
  - 邮箱：可点击发送邮件
  - 账号状态：标签颜色（正常-绿色/冻结-红色/待验证-橙色）
  - 头像：显示头像图片，点击放大

交互：
  1. 右上角"编辑"按钮切换编辑模式
  2. 编辑模式下手机号显示完整，可修改
  3. "重置密码"操作需要二次确认

业务规则：
  BR-001：冻结状态用户，顶部显示红色提示条
  BR-002：30天未登录用户，最后登录时间显示为橙色
  BR-003：管理员可查看完整手机号，普通用户仅脱敏
```
