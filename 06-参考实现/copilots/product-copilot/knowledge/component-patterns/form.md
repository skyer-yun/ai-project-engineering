# 表单交互模式

> 适用场景：新建/编辑弹窗、设置页面、注册/登录、信息录入、审批提交

## 布局类型

### 水平布局（标签在左）

```
│              [________________________]  │
│                              [取消][提交] │
```


## 字段类型速查

| 类型 | 组件 | 适用数据 | 说明 |
|------|------|---------|------|
| 短文本 | Input | 名称、编号、标题 | 最大长度限制 |
| 长文本 | TextArea | 描述、备注、说明 | 可调整行数，显示字数统计 |
| 数字 | InputNumber | 数量、金额、排序 | 最小/最大值，步长 |
| 单选 | Radio | 性别、类型、优先级 | 选项 ≤ 5 个时使用 |
| 多选 | Checkbox | 标签、权限、特性 | 选项 ≤ 7 个时使用 |
| 下拉选择 | Select | 枚举值、关联数据 | 选项 > 5 个时使用 |
| 日期 | DatePicker | 日期字段 | 可设置不可选日期 |
| 日期范围 | RangePicker | 开始-结束 | 自动校验范围合理性 |
| 时间 | TimePicker | 时间点 | 可设置不可选时段 |
| 开关 | Switch | 布尔值 | 是否启用、是否通知 |
| 滑块 | Slider | 连续数值范围 | 0-100、价格区间 |
| 评分 | Rate | 评分/满意度 | 星级评分 |
| 上传 | Upload | 文件/图片 | 见 upload 组件模式 |
| 级联选择 | Cascader | 树形数据 | 省市区、分类 |
| 富文本 | RichText Editor | 长内容编辑 | 工具栏 + 预览 |
| 人员选择 | UserSelect | 人员/部门 | 远程搜索 + 头像 |

## 校验规则

### 校验时机
| 时机 | 触发条件 | 说明 |
|------|---------|------|
| blur | 输入框失焦 | 默认校验时机 |
| change | 值变化时 | 实时校验 |
| submit | 提交时 | 全量校验，滚动到第一个错误 |

### 校验规则表
| 规则 | 参数 | 错误提示模板 | 示例 |
|------|------|-------------|------|
| 必填 | - | "请输入{字段名}" | 项目名称不能为空 |
| 最小长度 | min | "至少输入{min}个字符" | 编号至少3位 |
| 最大长度 | max | "最多输入{max}个字符" | 描述不超过500字 |
| 固定长度 | len | "请输入{len}位{字段名}" | 手机号11位 |
| 最小值 | min | "不能小于{min}" | 数量 ≥ 1 |
| 最大值 | max | "不能大于{max}" | 折扣 ≤ 100 |
| 正则 | pattern | "请输入正确的{字段名}" | 邮箱/手机/身份证 |
| 自定义 | validator | 自定义函数返回 | 密码强度校验 |
| 异步 | async validator | "已存在" / "校验中..." | 编号查重 |

### 错误展示
```
错误提示位置：字段下方，红色文字
错误提示内容：具体原因，不含通用废话
错误输入框：红色边框 + 浅红背景
表单提交失败：滚动到第一个错误字段 + 聚焦
多个错误：同时标红所有错误字段

提交时校验：
  1. 全量校验所有字段
  2. 第一个错误字段滚动到可视区域
  3. 聚焦第一个错误字段
  4. 提交按钮恢复可用
```

## 交互行为

### 表单生命周期
```
打开（新建）：
  1. 所有字段重置为初始值/默认值
  2. 聚焦第一个输入框
  3. 清除所有校验错误状态

打开（编辑）：
  1. 加载数据，表单填充（loading 状态）
  2. 数据加载完成，聚焦第一个可编辑字段
  3. 记录初始值（用于判断是否有修改）

填写：
  - blur/change 触发校验
  - 联动字段：上级变更时清空下级
  - 自动补全：输入触发建议

提交：
  1. 全量校验
  2. 校验失败 → 滚动到错误字段
  3. 校验成功 → 按钮loading + 禁用
  4. 成功 → Toast提示 + 关闭/跳转
  5. 失败 → 弹窗内显示错误信息

关闭/取消：
  - 有未保存修改 → 二次确认
  - 无修改 → 直接关闭
```

### 联动行为
```
常见联动：
  1. 选择类型 → 动态显示/隐藏相关字段
  2. 选择上级 → 刷新下级选项
  3. 输入数量×单价 → 自动计算总金额
  4. 选择模板 → 预填表单字段
  5. 切换模式（新建/编辑）→ 字段禁用/启用

实现要点：
  - 联动变更时清空受影响的下级字段
  - 联动加载时显示 loading
  - 联动计算结果字段设为 readonly/disabled
```

### 字段状态
| 状态 | 表现 | 说明 |
|------|------|------|
| 可编辑 | 白色背景 | 默认状态 |
| 只读 | 灰色文字，无边框 | 展示不可编辑的值 |
| 禁用 | 灰色背景，不可交互 | 不可操作 |
| 隐藏 | 不占位 | 条件隐藏 |
| 加载中 | 输入框内 Spin | 远程数据加载 |

## 设计规范

### 尺寸
| 属性 | 水平布局 | 垂直布局 |
|------|---------|---------|
| 标签宽度 | 100-120px（右对齐） | 100%（左对齐） |
| 输入框宽度 | 320-480px | 100% |
| 字段间距 | 20-24px | 24-28px |
| 标签与输入间距 | 8-12px | 4-8px |

### 按钮区
```
位置：右对齐
主按钮：提交/保存（Primary）
次按钮：取消（Default）
间距：8-12px
```

### 分组分隔
```
分组标题：14-16px，加粗
分割线：1px solid #F0F0F0
分组间距：32px
分组标题与字段间距：16px
```

## PRD 描述模板

### Part 7 表单功能描述示例
```
功能名称：新建订单
组件类型：form（弹窗表单，水平布局）

表单字段：
| 字段 | 组件 | 必填 | 默认值 | 校验规则 |
|------|------|------|--------|---------|
| 订单编号 | Input | 是 | 自动生成 | 固定12位，唯一 |
| 客户名称 | Select(远程) | 是 | - | blur校验 |
| 订单类型 | Radio | 是 | 普通 | 普通/加急/预订单 |
| 订单金额 | InputNumber | 是 | 0 | > 0，精度2位 |
| 折扣 | Slider | 否 | 100 | 0-100，步长5 |
| 备注 | TextArea | 否 | - | 最多200字 |
| 附件 | Upload | 否 | - | 最多5个，单个≤10MB |

联动规则：
  - 选择"加急"→ 显示"紧急原因"字段（必填）
  - 金额 > 10000 → 显示"大额审批"提示
  - 金额变化 → 自动计算折后金额

交互：
  1. 打开时自动生成订单编号，聚焦客户名称
  2. 客户名称支持远程搜索（防抖300ms）
  3. 提交成功后关闭弹窗 + 刷新列表
  4. 未保存关闭时二次确认

业务规则：
  BR-001：加急订单必须填写紧急原因
  BR-002：订单编号格式：ORD + yyyyMMdd + 4位序号
  BR-003：折扣后金额为0时不允许提交

异常处理：
  E-001：编号生成失败 → 提示用户手动输入
  E-002：客户搜索超时 → 显示"搜索失败，请重试"
  E-003：提交失败保留表单数据，不关闭弹窗
```

## 标注内容模板
```
目标选择器：.form-container 或 [data-form-id="xxx"]
内容结构：
  1. 表单字段清单（组件类型+必填+默认值+校验规则）
  2. 布局方式（水平/垂直/分组/分步）
  3. 联动关系（字段间依赖）
  4. 校验时机与错误展示
  5. 业务规则（编号 BR-XXX）
  6. 异常处理（编号 E-XXX）
```
