## 1. 登录页（Login）

### 页面结构

```
┌──────────────────────────────────────────────┐
│                                              │
│            ┌──────────────┐                  │
│            │    LOGO      │                  │
│            │   系统名称    │                  │
│            └──────────────┘                  │
│            ┌──────────────┐                  │
│            │  账号输入框   │                  │
│            │  密码输入框   │                  │
│            │  验证码(可选) │                  │
│            │  记住密码     │                  │
│            │  [ 登录按钮 ] │                  │
│            │  忘记密码?    │                  │
│            └──────────────┘                  │
│            ┌──────────────┐                  │
│            │ 第三方登录    │                  │
│            │ □ □ □ (图标)  │                  │
│            └──────────────┘                  │
│            ┌──────────────┐                  │
│            │   底部版权    │                  │
│            └──────────────┘                  │
│                                              │
└──────────────────────────────────────────────┘
```

### 设计要点

| 要点 | 说明 |
|------|------|
| 视觉焦点 | 登录表单居中，视觉聚焦 |
| 品牌展示 | Logo + 系统名称 + 背景图（可选） |
| 安全提示 | 密码遮罩、验证码、错误提示 |
| 快捷操作 | 记住密码、自动填充 |
| 第三方登录 | 企业微信/钉钉/SSO |

### 典型组件

| 组件 | 说明 | 必选 |
|------|------|------|
| Logo + 系统名称 | 品牌标识 | 是 |
| 用户名输入框 | 带图标，支持手机号/邮箱 | 是 |
| 密码输入框 | 遮罩 + 显示/隐藏切换 | 是 |
| 验证码 | 图形验证码 / 短信验证码 | 可选 |
| 记住密码 | Checkbox + 本地存储 | 可选 |
| 登录按钮 | 主按钮，Loading 状态 | 是 |
| 忘记密码 | 链接，跳转找回页 | 可选 |
| 第三方登录 | 图标按钮组 | 可选 |
| 版权信息 | 底部居中 | 是 |

### 响应式行为

| 断点 | 布局调整 |
|------|---------|
| ≥1200px | 居中卡片，两侧背景图 |
| 768-1199px | 居中卡片，简化背景 |
| <768px | 全宽表单，无背景图，顶部 Logo |

### 交互规范

| 场景 | 行为 |
|------|------|
| 输入校验 | 失焦时校验，错误红框+提示文字 |
| 回车提交 | 密码框回车触发登录 |
| 登录中 | 按钮Loading，禁止重复点击 |
| 登录失败 | 内联错误提示（非弹窗），支持重试 |
| 登录成功 | 跳转首页/上次访问页 |
| 多次失败 | 增加验证码 / 锁定账号 |

## 2. 仪表盘（Dashboard）

### 页面结构

```
┌──────────────────────────────────────────────┐
│ 欢迎语 / 日期 / 快捷入口                      │
├──────────────────────────────────────────────┤
│ ┌────┐ ┌────┐ ┌────┐ ┌────┐                 │
│ │KPI1│ │KPI2│ │KPI3│ │KPI4│   ← 指标卡片    │
│ └────┘ └────┘ └────┘ └────┘                 │
├──────────────────────────────────────────────┤
│ ┌──────────────┐ ┌──────────────┐           │
│ │   趋势图表    │ │   分类图表    │           │
│ │   (折线图)    │ │   (饼图/柱图) │           │
│ └──────────────┘ └──────────────┘           │
├──────────────────────────────────────────────┤
│ ┌──────────────────────────────┐             │
│ │        待办/快捷操作          │             │
│ │  [待审批3] [待处理5] [提醒2]  │             │
│ └──────────────────────────────┘             │
└──────────────────────────────────────────────┘
```

### 设计要点

| 要点 | 说明 |
|------|------|
| 信息层级 | KPI > 趋势 > 明细 > 快捷操作 |
| 数据密度 | 关键数据一屏可见，不过度堆砌 |
| 可定制 | 支持用户自定义卡片布局/顺序 |
| 时效性 | 数据更新时间标注，支持手动刷新 |
| 角色化 | 不同角色看到不同内容 |

### 典型组件

| 组件 | 说明 | 必选 |
|------|------|------|
| 欢迎区 | 问候语+日期+天气（可选） | 是 |
| KPI 卡片 | 核心指标+趋势+环比 | 是 |
| 趋势图表 | 折线/面积图，时间维度 | 是 |
| 分类图表 | 饼图/柱图，分类维度 | 可选 |
| 待办列表 | 待处理事项+快捷入口 | 是 |
| 快捷操作 | 常用功能入口 | 可选 |
| 公告通知 | 系统公告轮播 | 可选 |
| 最近访问 | 最近操作记录 | 可选 |

### 响应式行为

| 断点 | 布局调整 |
|------|---------|
| ≥1200px | 4列KPI + 2列图表 + 1列待办 |
| 768-1199px | 2列KPI + 1列图表堆叠 |
| <768px | 1列堆叠，KPI 横滑 |

### 交互规范

| 场景 | 行为 |
|------|------|
| KPI 点击 | 跳转对应明细页 |
| 图表下钻 | 点击区域展开详情 |
| 时间切换 | 日/周/月/季/年切换 |
| 数据刷新 | 手动刷新按钮 + 自动刷新间隔 |
| 卡片拖拽 | 支持拖拽调整顺序（可选） |

## 3. 列表页（List / CRUD）

### 页面结构

```
┌──────────────────────────────────────────────┐
│ 面包屑 > 模块名                               │
│ 页面标题                     [新建] [导入] [导出]│
├──────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────┐ │
│ │ 筛选条件1 [▼]  筛选条件2 [▼]  [查询] [重置]│ │
│ │ 筛选条件3 [  ]  筛选条件4 [date]  [更多v]    │ │
│ └──────────────────────────────────────────┘ │
├──────────────────────────────────────────────┤
│ ☑ │ 列1 │ 列2 │ 列3 │ 列4 │ 状态 │ 操作 │   │
│───┼──────┼──────┼──────┼──────┼──────┼──────│  │
│ ☐ │ 数据 │ 数据 │ 数据 │ 数据 │ 标签 │ 操作 │  │
│ ☐ │ 数据 │ 数据 │ 数据 │ 数据 │ 标签 │ 操作 │  │
├──────────────────────────────────────────────┤
│ 共 XX 条  [< 1 2 3 ... >]  每页 [20▼] 条     │
└──────────────────────────────────────────────┘
```

### 设计要点

| 要点 | 说明 |
|------|------|
| 搜索效率 | 常用筛选前置，高级筛选折叠 |
| 信息密度 | 核心字段优先展示，次要字段可展开 |
| 操作便捷 | 单行操作+批量操作分区明确 |
| 状态可视 | 状态标签用色彩区分 |
| 数据导出 | 支持选中导出/全部导出 |

### 典型组件

| 组件 | 说明 | 必选 |
|------|------|------|
| 面包屑 | 导航路径 | 是 |
| 页面标题 | 含记录总数 | 是 |
| 筛选区 | 基础+高级筛选 | 是 |
| 操作按钮栏 | 新建/导入/导出/批量 | 是 |
| 数据表格 | 列定义+行操作 | 是 |
| 状态标签 | 色彩区分 | 是 |
| 分页器 | 页码+每页条数+总数 | 是 |
| 列设置 | 自定义列显隐/排序 | 可选 |
| 空状态 | 图标+提示+引导操作 | 是 |

### 响应式行为

| 断点 | 布局调整 |
|------|---------|
| ≥1200px | 完整表格，所有列可见 |
| 768-1199px | 隐藏次要列，保留核心列+操作 |
| <768px | 卡片列表模式，每行一张卡片 |

### 交互规范

| 场景 | 行为 |
|------|------|
| 查询 | 点击查询/回车触发，防抖 300ms |
| 重置 | 清空所有筛选条件，刷新列表 |
| 排序 | 点击列头切换升序/降序/默认 |
| 行选择 | Checkbox 多选，支持全选 |
| 行操作 | 悬浮显示/固定操作列 |
| 批量操作 | 选中后显示批量操作栏 |
| 删除 | 二次确认弹窗 |
| 翻页 | 记住选中状态 |
| 空状态 | 引导用户创建第一条数据 |

## 4. 表单页（Form）

### 页面结构

```
┌──────────────────────────────────────────────┐
│ 面包屑 > 模块名 > 新建/编辑                     │
│ 页面标题                                      │
├──────────────────────────────────────────────┤
│                                              │
│ ┌─ 基本信息 ─────────────────────────────┐   │
│ │  字段1: [          ]                    │   │
│ │  字段2: [          ]  字段3: [        ] │   │
│ │  字段4: [▼         ]                    │   │
│ └────────────────────────────────────────┘   │
│                                              │
│ ┌─ 详细信息 ─────────────────────────────┐   │
│ │  字段5: [                         ]     │   │
│ │  字段6: [□ 选项1] [□ 选项2] [□ 选项3] │   │
│ │  附件:  [点击上传]                      │   │
│ └────────────────────────────────────────┘   │
│                                              │
├──────────────────────────────────────────────┤
│                    [取消]  [保存草稿]  [提交]  │
└──────────────────────────────────────────────┘
```

### 设计要点

| 要点 | 说明 |
|------|------|
| 分组明确 | 相关字段分组，用卡片/折叠面板区隔 |
| 标签对齐 | 顶部对齐（长表单）或左对齐（短表单） |
| 即时校验 | 失焦校验，错误信息紧邻字段 |
| 进度指示 | 分步表单需步骤条 |
| 防丢失 | 离开页面时确认提示 |

### 典型组件

| 组件 | 说明 | 必选 |
|------|------|------|
| 面包屑 | 导航路径 | 是 |
| 页面标题 | 新建/编辑 + 名称 | 是 |
| 表单分组 | 卡片/折叠面板 | 是 |
| 输入框 | 文本/数字/金额 | 是 |
| 选择器 | 下拉/级联/树选择 | 按需 |
| 日期时间 | 日期/时间/日期范围 | 按需 |
| 文件上传 | 拖拽上传+预览 | 按需 |
| 富文本 | 内容编辑器 | 按需 |
| 步骤条 | 分步表单导航 | 可选 |
| 操作按钮 | 取消/保存/提交 | 是 |

### 响应式行为

| 断点 | 布局调整 |
|------|---------|
| ≥1200px | 2-3列表单布局 |
| 768-1199px | 2列表单布局 |
| <768px | 1列表单，全宽输入框 |

### 交互规范

| 场景 | 行为 |
|------|------|
| 实时校验 | 失焦触发，错误时红框+文字提示 |
| 必填标记 | 字段名后加红色星号 |
| 联动 | A 变化触发 B 的选项/显隐/校验 |
| 提交 | 校验全部通过后提交，Loading 防重复 |
| 保存草稿 | 不做必填校验，保存当前填写内容 |
| 取消 | 有变更时弹窗确认，无变更直接返回 |
| 离开提示 | 浏览器 beforeunload 拦截 |

## 5. 详情页（Detail）

### 页面结构

```
┌──────────────────────────────────────────────┐
│ [← 返回]  标题              状态标签  [操作▼] │
├──────────────────────────────────────────────┤
│ ┌─ 基本信息 ─────────────────────────────┐   │
│ │ 字段1: 值    字段2: 值   字段3: 值     │   │
│ │ 字段4: 值    字段5: 值                 │   │
│ └────────────────────────────────────────┘   │
├──────────────────────────────────────────────┤
│ [Tab1] [Tab2] [Tab3] [Tab4]                  │
├──────────────────────────────────────────────┤
│ Tab 内容区                                    │
│ ┌──────────────────────────────────────────┐ │
│ │  子信息/关联数据/操作日志/审批记录        │ │
│ └──────────────────────────────────────────┘ │
├──────────────────────────────────────────────┤
│ ┌─ 操作记录 ─────────────────────────────┐   │
│ │ ● 2026-05-18 张三 创建了记录            │   │
│ │ ● 2026-05-17 李四 审批通过              │   │
│ │ ● 2026-05-16 王五 提交审批              │   │
│ └────────────────────────────────────────┘   │
└──────────────────────────────────────────────┘
```

### 设计要点

| 要点 | 说明 |
|------|------|
| 信息层级 | 标题+状态 > 基本信息 > Tab 详情 > 操作记录 |
| 状态醒目 | 状态标签在标题行右侧，色彩区分 |
| Tab 组织 | 关联信息按类型分 Tab，减少滚动 |
| 操作便捷 | 核心操作按钮在标题行，更多操作下拉 |
| 时间轴 | 操作记录用时间轴展示，便于追溯 |

### 典型组件

| 组件 | 说明 | 必选 |
|------|------|------|
| 返回按钮 | 左上角，返回列表 | 是 |
| 标题+状态 | 主信息一目了然 | 是 |
| 信息卡片 | 描述列表展示字段 | 是 |
| 标签页 | 内容分类 | 是 |
| 关联表格 | 子表/关联数据 | 按需 |
| 时间轴 | 操作记录/审批记录 | 是 |
| 操作按钮 | 编辑/删除/审批/... | 是 |
| 更多操作 | 下拉菜单 | 可选 |

### 响应式行为

| 断点 | 布局调整 |
|------|---------|
| ≥1200px | 信息3列，Tab 内容宽裕 |
| 768-1199px | 信息2列 |
| <768px | 信息1列，Tab 横滑 |

### 交互规范

| 场景 | 行为 |
|------|------|
| 返回 | 返回列表页，保持筛选状态 |
| Tab 切换 | 无刷新切换，记住上次选中 |
| 编辑 | 跳转编辑页或就地编辑 |
| 删除 | 二次确认，提示关联影响 |
| 审批 | 展开审批面板（意见+操作） |
| 操作记录 | 分页或加载更多 |

## 6. 审批流程页（Approval）

### 页面结构

```
┌──────────────────────────────────────────────┐
│ [← 返回]  审批标题             状态标签        │
├──────────────────────────────────────────────┤
│ ┌──────────────────┐ ┌────────────────────┐ │
│ │  申请信息         │ │  流程进度           │ │
│ │  申请人: 张三     │ │  ● 已提交           │ │
│ │  申请时间: ...    │ │  ● 审批中 ← 当前    │ │
│ │  ...             │ │  ○ 待审批           │ │
│ │                  │ │  ○ 结束             │ │
│ └──────────────────┘ └────────────────────┘ │
├──────────────────────────────────────────────┤
│ ┌─ 审批表单内容 ──────────────────────────┐   │
│ │  [业务表单只读展示]                      │   │
│ └────────────────────────────────────────┘   │
├──────────────────────────────────────────────┤
│ ┌─ 审批意见 ─────────────────────────────┐   │
│ │  审批结果: ○ 同意  ○ 驳回  ○ 转办      │   │
│ │  审批意见: [                        ]   │   │
│ │  附件:     [上传]                       │   │
│ └────────────────────────────────────────┘   │
├──────────────────────────────────────────────┤
│ ┌─ 审批历史 ─────────────────────────────┐   │
│ │  ● 2026-05-18 张三 同意                 │   │
│ │    意见：xxx                            │   │
│ │  ● 2026-05-17 李四 同意                 │   │
│ │    意见：xxx                            │   │
│ └────────────────────────────────────────┘   │
├──────────────────────────────────────────────┤
│                         [暂存]  [提交审批]    │
└──────────────────────────────────────────────┘
```

### 设计要点

| 要点 | 说明 |
|------|------|
| 左右布局 | 左侧业务信息，右侧流程进度 |
| 流程可视化 | 步骤条/流程图清晰展示当前节点 |
| 意见必填 | 驳回时意见必填，同意时可选 |
| 历溯可追溯 | 完整审批历史，含意见和附件 |
| 超时提醒 | 当前节点超时高亮提示 |

### 典型组件

| 组件 | 说明 | 必选 |
|------|------|------|
| 业务表单 | 只读展示申请内容 | 是 |
| 流程图/步骤条 | 当前进度可视化 | 是 |
| 审批意见区 | 结果+意见+附件 | 是 |
| 审批历史 | 时间轴展示 | 是 |
| 操作按钮 | 提交/暂存/转办/加签 | 是 |
| 流程图（详细） | 完整流程定义可视化 | 可选 |
| 超时提醒 | 当前节点耗时/剩余时间 | 可选 |

### 响应式行为

| 断点 | 布局调整 |
|------|---------|
| ≥1200px | 左右分栏（表单+流程图） |
| 768-1199px | 流程图折叠到顶部 |
| <768px | 全部单列堆叠 |

### 交互规范

| 场景 | 行为 |
|------|------|
| 审批结果切换 | 切换同意/驳回，意见框必填状态变化 |
| 驳回 | 选择驳回到哪一步（上一步/发起人） |
| 转办 | 弹窗选择转办人 |
| 加签 | 弹窗选择加签人（前加签/后加签） |
| 提交 | 确认弹窗，防止误操作 |
| 暂存 | 保存意见，不提交，下次可继续 |

## 7. 数据分析页（Analytics）

### 页面结构

```
┌──────────────────────────────────────────────┐
│ 分析报表名称                    [导出] [订阅]  │
├──────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────┐ │
│ │ 时间: [2026-05] ▼  维度: [部门] ▼        │ │
│ │ 类型: [全部] ▼      区域: [全国] ▼        │ │
│ │ [查询] [重置]                             │ │
│ └──────────────────────────────────────────┘ │

│ ┌────┐ ┌────┐ ┌────┐ ┌────┐                 │
│ │KPI1│ │KPI2│ │KPI3│ │KPI4│   ← 汇总指标    │
```

### 设计要点

| 要点 | 说明 |
|------|------|
| 筛选前置 | 筛选条件在顶部，影响全局数据 |
| 指标先行 | KPI 汇总卡片在图表之前 |
| 图表组合 | 趋势图+结构图组合，多维度分析 |
| 明细支撑 | 图表下方接明细表格，可下钻 |
| 导出能力 | 支持导出 Excel/PDF/图片 |

### 典型组件

| 组件 | 说明 | 必选 |
|------|------|------|
| 全局筛选 | 时间/维度/类型/区域 | 是 |
| KPI 卡片 | 核心指标+环比+趋势迷你图 | 是 |
| 趋势图表 | 折线/面积图 | 是 |
| 结构图表 | 饼图/柱图/雷达图 | 是 |
| 明细表格 | 详细数据列表 | 是 |
| 导出按钮 | Excel/PDF/PNG | 是 |
| 订阅按钮 | 定时推送 | 可选 |
| 下钻面板 | 点击图表展开详情 | 可选 |

### 响应式行为

| 断点 | 布局调整 |
|------|---------|
| ≥1200px | 筛选4列 + KPI 4列 + 图表2列 + 表格 |
| 768-1199px | 筛选2列 + KPI 2列 + 图表堆叠 |
| <768px | 筛选1列 + KPI 横滑 + 图表堆叠 |

### 交互规范

| 场景 | 行为 |
|------|------|
| 筛选联动 | 条件变化→KPI+图表+表格同步刷新 |
| 图表下钻 | 点击→弹出明细/跳转明细页 |
| 图表切换 | 同一区域切换图表类型 |
| 表格排序 | 点击列头排序 |
| 导出 | 弹窗选择导出范围/格式 |
| 全屏 | 图表支持全屏查看 |

### 设计要点

| 要点 | 说明 |
|------|------|

| 分类清晰 | 设置项按功能模块分类 |
| 即时反馈 | 保存成功/失败提示 |
| 权限控制 | 不同设置项需不同权限 |

| 组件 | 说明 | 必选 |
|------|------|------|
| 侧边导航 | 设置分类菜单 | 是 |

| 表单控件 | 输入框/开关/选择器/上传 | 是 |
| 保存按钮 | 保存当前设置 | 是 |
| 重置按钮 | 恢复默认值 | 可选 |

| 用户管理 | 用户列表+角色分配 | 按需 |
| 角色权限 | 角色列表+权限树 | 按需 |
| 数据字典 | 字典管理+值维护 | 按需 |
| 操作日志 | 操作记录查询 | 按需 |

### 响应式行为

| 断点 | 布局调整 |
|------|---------|
| ≥1200px | 左侧固定导航 + 右侧内容 |
| 768-1199px | 可折叠侧边导航 + 右侧内容 |
| <768px | 顶部下拉导航 + 全宽内容 |

### 交互规范

| 场景 | 行为 |
|------|------|
| 切换分类 | 左侧导航点击，右侧内容切换 |
| 修改设置 | 修改后按钮变为可保存状态 |
| 保存 | 校验→保存→成功提示 |
| 重置 | 确认后恢复默认值 |
| 未保存提示 | 切换分类时有未保存修改时确认 |
| 敏感操作 | 关键设置需二次确认（如删除角色） |
