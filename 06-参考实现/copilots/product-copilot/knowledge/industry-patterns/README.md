# 行业需求模式速查

> 版本：1.0 | 更新：2026-05-18
> 用途：售前/产品阶段快速定位行业核心需求，辅助方案设计与 PRD 编写

## 速查索引

| 行业 | 核心关键词 | 典型技术栈 | 合规等级 |
|------|-----------|-----------|---------|
| 金融 | 风控、合规、审计 | Java/Spring/Oracle/Redis | 等保三级/国密 |
| 政务 | 流程、信创、共享 | 信创环境/国产DB | 国密/分级分类 |
| 教育 | 教学、资源共享 | 云部署/移动优先 | 等保二级 |
| 医疗 | 诊疗、病历、医保 | 微服务/HL7/FHIR | 等保三级/HIPAA |
| 电商 | 高并发、交易 | 分布式/容器化 | 等保二级 |
| 制造 | 生产、质量、IoT | MES/工业互联网 | 等保二级 |
| 物流 | 运输、仓储、调度 | GIS/实时定位 | 等保二级 |
| 房地产 | 销售、合同、交付 | CRM/合同引擎 | 等保二级 |

## 1. 金融（Finance）

### 需求优先级

| 优先级 | 需求域 | 说明 |
|--------|-------|------|
| P0 | 风控合规 | 反洗钱(AML)、KYC、交易监控、合规审计 |
| P0 | 账户与交易 | 开户/销户、转账、支付、清算结算 |
| P1 | 客户管理 | CRM、客户画像、客户生命周期 |
| P1 | 数据分析 | 经营分析、风控模型、BI 报表 |
| P2 | 营销运营 | 活动管理、精准营销、积分体系 |
| P2 | 内部管理 | 组织架构、权限、审批流 |

### 合规要求

| 要求 | 详情 |
|------|------|
| 等保三级 | 网络安全等级保护，每年测评 |
| 国密算法 | SM2/SM3/SM4，传输加密+存储加密 |
| 审计追踪 | 全操作留痕，日志保存≥5年 |
| 数据治理 | 数据分类分级、脱敏、溯源 |
| 双因素认证 | 登录、关键操作需 2FA |
| 灾备 | RPO≤5min，RTO≤30min |

### 典型模块

| 模块 | 核心页面 | 说明 |
|------|---------|------|
| 统一门户 | 仪表盘/工作台/消息中心 | 角色化工作台 |
| 账户管理 | 开户/销户/冻结/解冻 | 全生命周期 |
| 交易系统 | 下单/撤单/成交/查询 | 高并发核心 |
| 风控引擎 | 规则配置/预警/处置 | 实时风控 |
| 合规审计 | 操作日志/审计报告 | 全链路追溯 |
| 客户画像 | 标签/评分/分群 | 360度视图 |
| 报表中心 | 报表模板/生成/导出 | 监管报表 |

### 用户角色

| 角色 | 职责 | 典型操作 |
|------|------|---------|
| 客户经理 | 客户开发维护 | 开户审核、客户查询、产品推荐 |
| 风控专员 | 风险监控 | 预警处理、规则配置、风险报告 |
| 交易员 | 交易执行 | 下单、撤单、持仓管理 |
| 合规官 | 合规审查 | 审计检查、合规报告、整改跟踪 |
| 系统管理员 | 系统运维 | 用户管理、权限配置、参数设置 |
| 运营经理 | 业务运营 | 报表查看、活动配置、数据导出 |

### 页面模式偏好

| 模式 | 说明 |
|------|------|
| 工作台型 | 信息密度高，多面板布局 |
| 审批流型 | 多节点审批，历史追溯 |
| 数据表格型 | 复杂筛选、批量操作、分页 |

## 使用指南

### 如何使用本文件

1. **售前阶段**：快速定位行业核心需求优先级，辅助方案大纲设计
2. **产品阶段**：参考典型模块和用户角色，构建产品功能矩阵
3. **设计阶段**：参考页面模式偏好，指导原型设计方向
4. **技术阶段**：参考技术偏好，辅助技术选型

### 行业交叉场景

当项目涉及多行业交叉时（如金融+政务），取各行业 P0 需求的并集，合规要求取严格者。

### 与 PRD 编写联动

- P0 需求 → PRD Part 3 核心需求
- 合规要求 → PRD Part 8 非功能需求
- 典型模块 → PRD Part 7 功能点
- 用户角色 → PRD Part 2 用户角色
- 页面模式 → PRD Part 6 交互设计
