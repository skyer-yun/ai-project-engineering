| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|

```json
{
  "field1": "value1"
}
```

**响应参数**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Number | 状态码 |
| message | String | 提示信息 |
| data | Object | 业务数据 |
| data.xxx | String | 字段说明 |

**响应示例**

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

失败：
```json
{
  "code": 40001,
  "message": "参数错误：xxx 不能为空",
  "data": null
}
```

**错误码**

| 错误码 | 说明 | 处理建议 |
|--------|------|---------|
| 40001 | 参数错误 | 检查请求参数 |

| 50001 | 服务器错误 | 联系技术支持 |

**状态码对照**

| HTTP 状态码 | 含义 |
|------------|------|
| 200 | 成功 |
| 201 | 创建成功 |
| 400 | 请求参数错误 |
| 401 | 未认证 |
| 403 | 无权限 |
| 404 | 资源不存在 |

## 使用指南

### 与 write-a-prd Skill 联动

| PRD 部分 | 使用模板 | 说明 |
|---------|---------|------|
| Part 1 文档信息 | 12 部分 PRD 模板 Part 1 | 直接填入 |
| Part 7 功能点 | Part 7 子模板 | 每个功能点一个 |

| Part 9 接口 | 接口规范模板 | 每个接口一个 |
