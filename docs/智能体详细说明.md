## 统一设计规范

所有智能体遵循统一的 9 节 skill.md 结构：

1. **角色定义与能力边界** — 默认角色 + 4-5 个角色切换
2. **意图识别与路由** — LLM 语义优先 + triggers.md 兜底 + 三档置信度
3. **依赖检查** — 启动时动态检测，核心/增强分级，缺失时降级方案
4. **工作流路由** — 意图 → 工作流 → 产物，支持组合场景
5. **知识库** — domain-specific 知识 + 提示词模板
6. **记忆系统** — 偏好保留 skill memory/，项目决策合并到原生记忆
7. **核心规则** — 9 条统一规则（不与原生路由竞争、依赖先行等）
8. **启动流程** — 依赖检测 → 问候 → 等待指令
9. **错误处理** — 降级策略 + 用户引导
