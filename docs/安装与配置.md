# 安装与配置

> **方法论**：DSBL × 工具中立
> **支持平台**：Windows 10/11（Git Bash / WSL）/ macOS / Linux
> **前置**：选定的 AI 工具已安装（Claude Code / Codex / Cursor / 自研 Agent 之一）

---

## 1. 环境检查

### 1.1 选用的 AI 工具

**Claude Code**：
```bash
claude --version    # 任意版本均可，建议最新
```

**Codex / Cursor / 自研**：见 [05-适配层/](../05-适配层/) 对应指南。

### 1.2 Python 3（交接契约校验工具用）
```bash
python3 --version    # ≥ 3.8
python3 -c "import yaml" || pip install pyyaml
```

### 1.3 Bash（Windows 用户）
- **推荐**：WSL 2（Ubuntu 22.04+）—— 工具脚本原生支持
- **次选**：Git Bash —— 大部分脚本可跑，部分路径需调整
- **不推荐**：原生 CMD / PowerShell —— 不兼容

### 1.4 数据库客户端（Checkpoint 脚本用）
```bash
mysqldump --version    # MySQL 项目
pg_dump --version      # PostgreSQL 项目
```

未装可跳过——`snapshot.sh` 设 `DB_TYPE=none` 即可（只备份配置+AI 上下文）。

## 2. 标准安装（按适配方案）

### 2.1 克隆仓库

```bash
git clone <repo-url> ai-project-engineering
cd ai-project-engineering
```

### 2.2 选适配方案一键安装

```bash
# Claude Code 适配（部署 6 copilot + 18 skills 到 ~/.claude/skills/）
./install.sh --adapter claude-code

# Codex 适配（生成 AGENTS.md + .codex/ 到当前项目根）
./install.sh --adapter codex

# Cursor 适配（生成 .cursorrules + .cursor/ 到当前项目根）
./install.sh --adapter cursor

# 自定义工具适配（只部署模板 + schema + QG checklist）
./install.sh --adapter custom

# 仅产物层模板（最小化）
./install.sh --templates-only
```

**核心**：体系标准层 + 产物层模板**始终部署**（工具中立）；参考实现按 adapter 可选。

### 2.3 Claude-Code 适配验证

```bash
ls ~/.claude/skills/ | grep copilot
# 应看到 6 个：pre-sales / product / dev / testing / delivery / project-copilot
```

在 Claude Code 内触发：
```
你：售前编排。测试一下。
Claude：→ 加载 pre-sales-copilot / 进入 D-Discover 阶段 ...
```

### 2.4 工具中立性校验

```bash
./install.sh --check-neutral
# 标准层不应出现具体工具名
```

## 3. 工具脚本部署

```bash
./install.sh --tools
```

部署到 `~/bin/`：
- `aipe-snapshot` → `04-工具层/03-Checkpoint脚本/snapshot.sh`
- `aipe-rollback` → `04-工具层/03-Checkpoint脚本/rollback.sh`
- `aipe-validate-handoff` → `04-工具层/04-交接契约工具/validate-handoff.sh`

加入 PATH：
```bash
echo 'export PATH="$HOME/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

验证：
```bash
aipe-snapshot test         # 创建测试快照
aipe-rollback --list       # 列出快照
aipe-validate-handoff --help
```

## 5. 跨平台注意事项

### 5.1 Windows + Git Bash

**已知限制**：
- 中文路径在某些命令下乱码（不影响功能，只影响显示）
- `set -euo pipefail` 在 Git Bash 4.x 以下版本可能行为不一致

**建议**：
```bash
# 在 .bashrc 内设置 UTF-8
export LANG=en_US.UTF-8
export PYTHONIOENCODING=utf-8
```

### 5.2 Windows + WSL 2

**推荐配置**：
```bash
# 项目放在 WSL 文件系统内（不是 /mnt/c/）
cd ~
git clone <repo-url> ai-project-engineering
```

性能比 `/mnt/c/` 快 5-10 倍。

### 5.3 macOS

```bash
# Python 3
brew install python@3.11
pip3 install pyyaml

# 数据库客户端
brew install mysql-client postgresql-client
```

### 5.4 Linux

```bash
# Ubuntu/Debian
sudo apt install python3 python3-pyaml mysql-client postgresql-client

# CentOS/RHEL
sudo yum install python3 python3-pyyaml mysql postgresql
```

## 6. 项目级配置

### 6.1 项目文档目录结构

新项目启动时创建（按 DSBL 阶段分组）：
```
项目文档/{项目名}/
├── D-Discover/                  # 需求分析报告 / 干系人清单
├── S-Spec/                      # 技术方案 / PRD / 架构设计 / 详细设计
├── B-Build/                     # 代码工程化产物
├── S-Ship/                      # 质量标准 / 部署 / 验收
├── L-Learn/                     # 项目复盘
├── 跨阶段/                       # 项目管理产物 / 提示词规范
├── memory.md                    # 项目级 AI 记忆
└── handoff/                     # DSBL 阶段交接 YAML 链 ⭐
    ├── D-to-S.yaml
    ├── S-to-B.yaml
    ├── B-to-Ship.yaml
    └── Ship-to-L.yaml
```

### 6.2 项目级 CLAUDE.md / AGENTS.md / .cursorrules

每个项目根目录建议有体系约定文件，写入：
- 项目背景（客户/技术栈/规模）
- 团队档位（A/B/C，参考素养盘点工具）
- 强制 HITL 节点列表（L3/L4）
- 当前 Sprint 目标

详见各适配指南（[05-适配层/](../05-适配层/)）。

### 6.3 数据库连接（部署快照用）

`.env` 文件：
```bash
DB_TYPE=mysql
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=<your-password>
DB_NAME=myapp
```

`snapshot.sh` 会自动读取，不硬编码。

## 7. 升级 & 卸载

### 升级
```bash
git pull
./install.sh --adapter claude-code   # 重跑部署
```

### 卸载

```bash
# 卸载 Claude-Code 参考实现
rm -rf ~/.claude/skills/{pre-sales,product,dev,testing,delivery,project}-copilot
rm -rf ~/.claude/skills/{architecture-designer,detailed-designer,code-reviewer,...}

# 卸载 Codex 适配
rm -f AGENTS.md
rm -rf .codex/

# 卸载 Cursor 适配
rm -f .cursorrules
rm -rf .cursor/

# 卸载工具脚本
rm -f ~/bin/{aipe-snapshot,aipe-rollback,aipe-validate-handoff}
```
