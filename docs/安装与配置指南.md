# 安装与配置指南

## 系统要求

- Claude Code CLI（最新版）
- 操作系统：Windows 10+/macOS 12+/Ubuntu 20.04+
- 磁盘空间：~50MB（全部安装）

## 快速安装

### 方式一：使用安装脚本（推荐）

```bash
cd ai-project-engineering
chmod +x install.sh

# 安装全部
./install.sh all

# 只安装特定智能体（如开发智能体）
./install.sh dev

# 预览模式（不实际复制）
./install.sh --dry-run
```

### 方式二：手动安装

将文件复制到 Claude Code 的 skills 目录：

```bash
# Linux/macOS
cp -r 02-pre-sales-copilot ~/.claude/skills/
cp -r skills/pre-sales/* ~/.claude/skills/

# Windows (PowerShell)
Copy-Item -Recurse 02-pre-sales-copilot $env:USERPROFILE\.claude\skills\
Copy-Item -Recurse skills\pre-sales\* $env:USERPROFILE\.claude\skills\
```

### 验证安装

```bash
# Claude Code 中执行
/skills
# 或查看目录
ls ~/.claude/skills/
```

## 配置说明

### 触发词自定义

每个技能的触发词在 `config/triggers.md` 中定义。修改示例：

```markdown
# 原始触发词
| 写方案 | 技术方案 | 建设方案 |

# 添加自定义触发词
| 写方案 | 技术方案 | 建设方案 | 出个方案 | 写标书 |
```

### 知识库扩展

知识库位于 `knowledge/` 目录，可以：

1. **新增行业文件**：在 `industry-solutions/` 下创建新行业 `.md` 文件
2. **更新架构模板**：修改 `proposal-templates/` 下的模板文件
3. **添加项目经验**：在 `memory/` 下记录项目特定配置

### 路径适配

如果您的 Claude Code skills 目录不在默认位置，修改 `install.sh` 中的 `SKILLS_DIR` 变量：

```bash
# 默认路径
SKILLS_DIR="$HOME/.claude/skills"

# 自定义路径
SKILLS_DIR="/custom/path/to/skills"
```

## 目录结构说明

安装后的目录结构：

```
~/.claude/skills/
├── 02-pre-sales-copilot/       # 智能体（目录名可自定义）
├── 04-dev-copilot/
├── 05-testing-copilot/
├── 06-delivery-copilot/
├── 07-project-copilot/
├── solution-architect/         # 独立技能
├── competitive-analyzer/
├── architecture-designer/
├── ... (共 18 个技能)
└── [其他已有技能]
```

**重要**：智能体和技能必须平铺在 `skills/` 目录下，不支持嵌套。

## 智能体编号说明

目录名中的编号（02/04/05/06/07）是设计序号，不影响功能。可以去掉编号重命名：

```
02-pre-sales-copilot → pre-sales-copilot
04-dev-copilot → dev-copilot
```

如果重命名，需要同步更新各技能 `skill.md` 中的依赖引用。
