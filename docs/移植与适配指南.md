# 移植与适配指南

## 换电脑

### 需要迁移的内容

| 目录 | 内容 | 必须 |
|------|------|------|
| `~/.claude/skills/` | 所有技能和智能体 | 是 |
| `~/.claude/CLAUDE.md` | 全局配置指令 | 是 |
| `~/.claude/projects/` | 项目记忆文件 | 建议 |
| 源项目 `ai-project-engineering/` | 完整项目（含 docs） | 建议 |

### 迁移步骤

```bash
# 1. 打包
tar czf ai-project-skills.tar.gz -C ~/.claude skills/ CLAUDE.md
tar czf ai-project-source.tar.gz ~/Desktop/ai-project-engineering/

# 2. 在新电脑解压
mkdir -p ~/.claude
tar xzf ai-project-skills.tar.gz -C ~/.claude/
tar xzf ai-project-source.tar.gz -C ~/Desktop/

# 3. 验证
claude-code --version
ls ~/.claude/skills/
```

## 换终端（VS Code / JetBrains）

Claude Code 的 skills 目录是共享的，不同终端插件共用同一个 `~/.claude/skills/`。无需额外操作。

## 从 Claude Code 迁移到其他 AI 工具

### Codex (OpenAI)

Codex 使用 `codex.md` 或 AGENTS.md 作为配置文件，与 Claude Code 的 skill.md 格式不同。

**转换要点：**

| Claude Code | Codex | 说明 |
|------------|-------|------|
| `~/.claude/skills/{name}/skill.md` | `AGENTS.md` 或指令文件 | 结构不同 |
| YAML frontmatter | 无 | 需要提取为配置 |
| `config/triggers.md` | 无内置触发 | 需要在 system prompt 中描述 |
| `knowledge/` | 可以作为上下文引用 | 需要手动引用 |
| `workflows/` | 可以描述在指令中 | 格式需适配 |

**转换步骤：**
1. 将 skill.md 的 Role + Rules 部分合并到 system prompt
2. 将 workflows/ 内容作为流程描述嵌入
3. 将 knowledge/ 内容作为参考文档引用
4. triggers.md 的关键词可以放在 user 指令模板中

### Cursor

Cursor 使用 `.cursorrules` 文件。

**转换要点：**
- 将 skill.md 内容转换为 `.cursorrules` 格式
- 每个"智能体"对应一个 `.cursorrules` 文件
- 触发词通过 `@` 引用或关键词匹配
- 知识库文件放在项目目录下通过 `@file` 引用

### Trae (字节跳动)

Trae 基于 VS Code，支持 MCP。

**转换要点：**
- skill.md 可以转换为 Trae 的 agent 配置格式
- MCP 服务器可以复用（Figma/Lark 等）
- 知识库文件直接作为项目文件引用

## 跨平台路径注意事项

| 平台 | Skills 目录 | 路径风格 |
|------|-----------|---------|
| Windows | `C:\Users\{user}\.claude\skills\` | 反斜杠，盘符开头 |
| macOS | `/Users/{user}/.claude/skills/` | 正斜杠 |
| Linux | `/home/{user}/.claude/skills/` | 正斜杠 |

install.sh 自动检测平台并使用正确路径。

## 打包分享单个智能体

```bash
# 打包开发智能体（含 3 个技能）
./install.sh --package dev
# 输出：dev-copilot-package.zip

# 打包售前智能体（含 2 个技能）
./install.sh --package pre-sales
# 输出：pre-sales-copilot-package.zip
```

接收方解压后运行 `install.sh` 即可安装。
