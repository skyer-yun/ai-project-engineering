# 卡片列表交互模式

> 适用场景：信息展示、商品列表、项目管理、团队成员、文件管理

## 布局类型

| 布局 | 适用场景 | 列数 | 卡片宽度 |
|------|---------|------|---------|
| 网格 | 等权展示 | 3-4列 | 固定宽度，响应式收缩 |
| 瀑布流 | 内容不等高 | 3-4列 | 固定宽度，高度自适应 |
| 横向滚动 | 精选/推荐 | 可见3-4个 | 固定宽度 |
| 列表内嵌 | 混合布局 | 1列 | 100%宽度 |

## 交互行为

### 基础交互
| 交互 | 行为 | 触发方式 |
|------|------|---------|
| 悬浮 | 卡片轻微上浮 + 阴影加深 | mouse hover |
| 点击 | 进入详情页或展开详情面板 | click 卡片主体 |
| 更多操作 | 显示操作下拉菜单 | click ⋮ 按钮 |
| 选择 | 选中状态（蓝色边框/勾选标记） | click 复选框 |
| 批量操作 | 顶部浮出批量操作栏 | 选中 2+ 张卡片 |

### 排序与筛选
```
排序选项：
  - 默认（按创建时间倒序）
  - 按更新时间
  - 按名称 A-Z
  - 按优先级
  - 自定义拖拽排序

筛选维度：
  - 状态筛选（Tab 切换：全部/进行中/已完成/已归档）
  - 标签筛选（多选标签）
  - 时间范围
  - 负责人
  - 搜索关键词（匹配标题+描述）
```

### 加载与翻页
| 方式 | 适用场景 | 实现要点 |
|------|---------|---------|
| 分页器 | 数据量可控（< 200） | 标准分页组件 |
| 无限滚动 | 信息流/社交类 | 触底加载，IntersectionObserver |
| 加载更多按钮 | 中等数据量 | 点击按钮追加一页 |
| 骨架屏 | 首次加载 | 卡片轮廓 + 闪烁动画 |

### 拖拽排序
```
触发：长按卡片 300ms（移动端）/ 按住拖拽手柄（桌面端）
行为：
  1. 卡片半透明 + 阴影提升
  2. 拖拽到目标位置时显示占位符
  3. 松手插入目标位置
  4. 调用接口保存新顺序
```

## 设计规范

### 尺寸
| 卡片类型 | 宽度 | 内边距 | 圆角 | 阴影 |
|----------|------|--------|------|------|
| 标准卡片 | 响应式（最小 240px） | 16-20px | 8px | 0 1px 4px rgba(0,0,0,.08) |
| 紧凑卡片 | 固定 200px | 12px | 6px | 无阴影，边框代替 |
| 大卡片 | 100%（列表模式） | 20-24px | 12px | 0 2px 8px rgba(0,0,0,.1) |

### 响应式断点
```
≥ 1200px：4 列
≥ 992px：  3 列
≥ 768px：  2 列
< 768px：  1 列
```

### 文字截断
```css
/* 单行截断 */
.card-title {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

/* 两行截断 */
.card-desc {
  display: -webkit-box;
  -webkit-line-clamp: 2;
  -webkit-box-orient: vertical;
  overflow: hidden;
}
```

### 空状态
```
图标：[folder]（文件）/ [list]（项目）/ [users]（人员）
文字："暂无[类型]内容"
操作：[+ 新建] 按钮
```

## PRD 描述模板

```
功能名称：项目列表
组件类型：card-list（项目卡片）

数据字段：
  - 标题：项目名称
  - 描述：项目描述（两行截断）
  - 状态标签：进行中/已暂停/已完成/已归档
  - 进度条：完成百分比
  - 负责人：头像 + 姓名
  - 截止日期：YYYY-MM-DD
  - 统计：待办数/进行中数/已完成数

布局：网格 3 列，响应式 2→1

交互：
  1. 悬浮：阴影加深，显示"查看详情"提示
  2. 点击：跳转项目详情页
  3. 更多(⋮)：编辑/归档/删除/复制
  4. 排序：默认按更新时间/可切换
  5. 筛选：状态Tab + 搜索

业务规则：
  BR-001：已完成项目状态标签为绿色，进行中为蓝色
  BR-002：进度超过截止日期未完成，显示红色警示
  BR-003：卡片按更新时间倒序，置顶项目优先
```
