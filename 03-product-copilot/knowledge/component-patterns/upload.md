# 上传组件交互模式

> 适用场景：附件上传、图片上传、文件导入、头像上传、批量导入

## 上传类型

| 类型 | 展示方式 | 适用场景 |
|------|---------|---------|
| 按钮上传 | 按钮 + 文件列表 | 通用附件上传 |
| 拖拽上传 | 虚线区域 + 拖入 | 多文件/批量上传 |
| 粘贴上传 | 粘贴触发 | 截图/图片上传 |
| 头像上传 | 圆形裁剪框 | 用户头像 |
| 卡片上传 | 缩略图网格 | 图片墙/相册 |

## 结构模板

### 按钮上传
```
[+ 选择文件]                    支持 .pdf,.doc,.xlsx，单个 ≤ 10MB

已上传文件：
┌────────────────────────────────────────────┐
│ [doc] 项目需求文档.pdf    2.3MB   [+ 上传完成] │
│ [xls] 数据模板.xlsx      156KB   [+ 上传完成] │
│ [doc] 会议纪要.docx      89KB    [o 上传中 67%] │
└────────────────────────────────────────────┘
```

### 拖拽上传区域
```
┌─────────────────────────────────────┐
│                                     │
│     [folder]                           │
│     点击或拖拽文件到此区域上传       │
│                                     │
│     支持 .xlsx, .csv 格式           │
│     单个文件不超过 50MB              │
│     [下载导入模板]                   │
│                                     │
└─────────────────────────────────────┘
虚线边框，hover 时背景变色
```

### 图片上传（卡片式）
```
┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
│      │ │      │ │      │ │  ＋  │
│ 图片1 │ │ 图片2 │ │ 图片3 │ │ 上传 │
│  ×   │ │  ×   │ │  ×   │ │      │
└──────┘ └──────┘ └──────┘ └──────┘
  × = 删除按钮（hover显示）
```

### 头像上传
```
     ┌──────────┐
     │          │
     │   [U]     │   点击更换头像
     │          │   支持 JPG/PNG，≤ 2MB
     └──────────┘
      圆形裁剪框
```

## 交互行为

### 选择文件
| 方式 | 行为 |
|------|------|
| 点击按钮 | 弹出系统文件选择器 |
| 拖拽文件 | 拖入区域高亮，松开触发上传 |
| 粘贴 | Ctrl+V 粘贴剪贴板中的图片 |
| 拍照（移动端） | 调用摄像头拍照 |

### 文件校验（选择后立即校验）
```
校验维度：
  1. 文件类型：后缀名白名单匹配
  2. 文件大小：单文件大小限制
  3. 文件数量：总数量限制
  4. 文件名：特殊字符/长度限制
  5. 重复检查：同名文件是否已存在

校验失败：
  - Toast 提示具体原因
  - 不加入上传队列
  - 示例："文件大小超过 10MB 限制"
```

### 上传过程
```
状态流转：
  [待上传] → [上传中] → [上传成功] / [上传失败]

上传中展示：
  - 进度条（百分比）
  - 文件名 + 大小
  - [取消] 按钮

上传成功：
  - 绿色勾选图标
  - 文件名变为可点击（下载/预览）
  - [删除] 按钮

上传失败：
  - 红色错误图标
  - 失败原因提示
  - [重试] 按钮
```

### 并发控制
```
同时上传数：3-5 个
队列管理：超出排队的显示"等待中"
失败重试：自动重试 2 次，间隔 3s
断点续传：大文件支持（> 10MB）
```

### 预览与操作
| 操作 | 图片 | 文档 | 其他 |
|------|------|------|------|
| 预览 | Y 图片查看器（缩放/旋转） | Y PDF 在线预览 | N |
| 下载 | Y | Y | Y |
| 删除 | Y 二次确认 | Y 二次确认 | Y 二次确认 |
| 重命名 | Y | Y | N |

## PRD 描述模板

```
功能名称：项目附件上传
组件类型：upload（按钮上传）

限制：
  - 文件类型：.pdf, .doc, .docx, .xlsx, .png, .jpg
  - 单文件大小：≤ 20MB
  - 总数量：≤ 10 个
  - 总大小：≤ 100MB

交互：
  1. 点击选择文件或拖拽到区域
  2. 选择后立即校验，不合格 Toast 提示
  3. 上传中显示进度条
  4. 上传失败可重试（最多2次）
  5. 图片类型点击缩略图预览
  6. 删除需二次确认

业务规则：
  BR-001：同名文件上传时提示"文件已存在，是否覆盖？"
  BR-002：项目归档后附件只读，不可新增/删除
  BR-003：删除附件需记录操作日志
```
