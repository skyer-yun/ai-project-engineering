# 图表组件交互模式

> 适用场景：数据可视化、统计报表、趋势分析、对比展示

## 图表类型速查

| 类型 | 适用数据 | 典型场景 | 推荐库 |
|------|---------|---------|--------|
| 折线图 | 时序/趋势 | 销售趋势、用户增长 | ECharts / Chart.js |
| 柱状图 | 对比/排名 | 部门业绩、月度对比 | ECharts / Chart.js |
| 饼图/环形图 | 占比/构成 | 类别占比、预算分配 | ECharts |
| 面积图 | 累积趋势 | 累计用户、流量变化 | ECharts |
| 散点图 | 分布/关联 | 用户分布、相关性分析 | ECharts |
| 雷达图 | 多维评估 | 能力模型、绩效评估 | ECharts |
| 漏斗图 | 转化/流失 | 转化漏斗、招聘流程 | ECharts |
| 热力图 | 密度/频率 | 访问热力、考勤统计 | ECharts |
| 桑基图 | 流向/转移 | 用户流向、资金流向 | ECharts / D3 |
| 仪表盘 | 单指标/目标 | KPI 达成率、设备状态 | ECharts |
| 瀑布图 | 增减/累计 | 利润分析、成本拆解 | ECharts |
| 树图 | 层级/占比 | 资产分类、组织架构 | ECharts |

## 数据映射规则

### 折线图/柱状图
```
数据字段映射：
  X轴（维度）→ 时间/类别字段（必需）
  Y轴（度量）→ 数值字段（必需，可多个=多系列）
  颜色（系列）→ 分组字段（可选）
  大小 → 不适用
```

### 饼图/环形图
```
数据字段映射：
  角度（大小）→ 数值字段（必需）
  颜色（类别）→ 分类字段（必需）
  标签 → 类别名称 + 百分比
  内环（嵌套）→ 二级分类（可选）
```

### 散点图
```
数据字段映射：
  X轴 → 数值字段（必需）
  Y轴 → 数值字段（必需）
  大小 → 权重字段（可选）
  颜色 → 分类字段（可选）
```

## 交互模式

### 基础交互
| 交互 | 行为 | 适用图表 |
|------|------|---------|
| Tooltip 悬浮 | 显示数据点详细信息 | 所有 |
| Legend 点击 | 切换系列显隐 | 多系列图表 |
| 数据点点击 | 触发下钻或联动 | 折线/柱状/饼图 |
| 缩放 | 框选/滚轮缩放时间范围 | 折线/柱状 |
| 平移 | 拖拽查看更多数据 | 折线/柱状 |

### 联动交互
```
图表 → 表格联动：
  点击图表数据点 → 过滤下方表格数据
  示例：点击柱状图某月 → 表格显示该月明细

图表 → 图表联动：
  点击主图数据 → 从图联动显示关联数据
  示例：点击趋势图某天 → 右侧显示该天分类饼图

图例 → 全局过滤：
  点击图例隐藏某系列 → 所有关联图表同步隐藏
  示例：隐藏"线上渠道"→ 趋势图+占比图+明细表同步过滤
```

### 下钻交互
```
层级下钻：
  年 → 季度 → 月 → 周 → 日
  省份 → 城市 → 区县
  类别 → 子类别 → SKU

实现方式：
  1. 点击数据点触发 drilldown 事件
  2. 替换当前图表数据（动画过渡）
  3. 显示面包屑导航：年 > 2025年 > Q2 > 6月
  4. 点击面包屑返回上级
```

## 设计规范

### 尺寸
| 容器 | 推荐宽度 | 推荐高度 | 说明 |
|------|---------|---------|------|
| 全宽卡片 | 100% | 300-400px | Dashboard 主图表 |
| 半宽卡片 | 50% | 280-320px | 双图并排 |
| 小卡片 | 33% | 240-280px | 三图并排 |
| 嵌入表格 | 单元格宽 | 60-80px | 迷你趋势图（sparkline） |

### 配色方案
```
单色系（推荐）：
  主色 5 级渐变，从浅到深
  示例：#BAE0FF → #69B1FF → #1677FF → #0958D9 → #003EB3

多色系（分类）：
  最大 8 色，超出后循环
  推荐：#1677FF #52C41A #FAAD14 #FF4D4F #722ED1 #13C2C2 #EB2F96 #FA8C16

语义色：
  正向/增长：#52C41A（绿色）
  负向/下降：#FF4D4F（红色）
  中性/持平：#8C8C8C（灰色）
```

### 空状态与异常
| 状态 | 展示 | 说明 |
|------|------|------|
| 无数据 | 图表区域 + "暂无数据" 文字 + 空状态图标 | 未选择筛选条件或查询无结果 |
| 加载中 | 骨架屏（图表轮廓闪烁） | 数据请求中 |
| 数据量少 | 正常展示，不留过多空白 | 数据点 < 3 时适当缩小图表 |
| 数据异常 | 错误提示 + 重试按钮 | 接口报错 |

## PRD 描述模板

### Part 7 图表功能描述示例
```
功能名称：销售趋势分析图
组件类型：chart（折线图）

数据映射：
  - X轴：日期（按日/周/月切换）
  - Y轴：销售额（元）、订单量（笔）双Y轴
  - 系列：按渠道分组（线上/线下/全渠道汇总）

交互行为：
  1. 悬浮显示 Tooltip：日期、渠道、销售额、环比变化
  2. 点击图例切换渠道显隐
  3. 点击数据点下钻到该日订单明细表格
  4. 滚轮缩放时间范围（默认近30天）
  5. 右上角切换时间粒度：日/周/月

业务规则：
  BR-001：金额超过100万时Y轴自动切换单位为"万"
  BR-002：环比下降超过20%时数据点显示红色警示标记
  BR-003：空数据日期补零，不跳过

异常处理：
  E-001：接口超时 → 显示缓存数据 + "数据可能非最新"提示
  E-002：数据量 > 365天 → 强制切换为月粒度，提示用户
  E-003：单日数据异常值（偏离均值3σ）→ 标记异常点，悬浮显示原因
```

## 标注内容模板
```
目标选择器：.chart-container 或 [data-chart-id="xxx"]
内容结构：
  1. 图表类型与数据字段映射
  2. 交互行为清单（tooltip/legend/下钻/联动）
  3. 业务规则（编号 BR-XXX）
  4. 异常处理（编号 E-XXX）
  5. 配色方案与尺寸约束
```
