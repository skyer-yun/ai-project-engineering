# 抽屉交互模式

> 适用场景：详情面板、筛选面板、表单编辑、日志查看，不离开当前页面上下文

## 类型

| 类型 | 方向 | 宽度 | 适用场景 |
|------|------|------|---------|
| 标准 | 右侧滑出 | 600px | 详情查看、表单编辑 |
| 窄面板 | 右侧滑出 | 400px | 筛选面板、评论面板 |
| 宽面板 | 右侧滑出 | 800px | 复杂表单、日志详情 |
| 左侧面板 | 左侧滑出 | 400-600px | 导航菜单、配置面板 |

## 交互行为

### 打开与关闭
| 方式 | 行为 |
|------|------|
| 打开 | 遮罩半透明（可选）→ 抽屉从右侧滑入（300ms） |
| 关闭-按钮 | 点击 × / 关闭 → 滑出 |
| 关闭-遮罩 | 点击遮罩区域关闭 |
| 关闭-ESC | ESC 键关闭 |
| 关闭-返回 | 浏览器返回键关闭（移动端） |

### 与列表联动
```
场景：列表页点击行 → 右侧打开详情抽屉

联动行为：
  1. 列表行高亮显示选中状态
  2. 抽屉展示该行详情
  3. 抽屉内"上一条""下一条"可切换
  4. 抽屉内编辑保存后，列表行数据实时更新
  5. 抽屉内删除后，关闭抽屉 + 列表移除该行
```

### 嵌套使用
```
抽屉内打开弹窗：允许（弹窗 z-index 高于抽屉）
抽屉内打开抽屉：允许但需控制宽度（父600 + 子400）
最多嵌套 2 层
```

### 表单编辑
```
打开时：
  - 填充现有数据
  - 标题显示"编辑 XXX"

编辑时：
  - 实时校验同表单弹窗
  - 底部固定操作栏（不受内容滚动影响）

关闭时：
  - 未保存修改 → 二次确认
  - 保存成功 → 关闭抽屉 + Toast + 刷新关联列表
```

## 设计规范

### 尺寸
| 宽度 | 适用 | 内边距 |
|------|------|--------|
| 400px | 筛选/评论/配置 | 16px |
| 600px | 详情/简单表单 | 20px |
| 800px | 复杂表单/日志 | 24px |

### 层级
```
z-index：
  遮罩：1000（可选，有些场景不需要遮罩）
  抽屉：1001
  嵌套抽屉：2001
```

### 动画
```
打开：transform: translateX(100%) → translateX(0)，300ms ease-out
关闭：translateX(0) → translateX(100%)，250ms ease-in
遮罩：opacity 0 → 0.3（可选）
```

### 响应式
```
≥ 768px：抽屉模式（右侧滑出）
< 768px：全屏模式（100% 宽度）
```

## PRD 描述模板

```
功能名称：订单详情抽屉
组件类型：drawer

触发方式：列表页点击订单行

尺寸：600px

内容结构：
  标签页：[基本信息] [商品明细] [物流跟踪] [操作记录]

基本信息标签页字段：
  订单编号/下单时间/订单状态/金额/收货人/电话/地址

底部操作栏（固定）：
  [编辑] [打印面单] [取消订单]  [关闭]

交互：
  1. 打开时列表行高亮
  2. 顶部显示"← 上一条 | 下一条 →"
  3. 编辑模式：字段变为输入框
  4. 未保存关闭二次确认

业务规则：
  BR-001：已发货订单，"取消订单"按钮置灰不可点
  BR-002：物流标签页实时推送物流状态
```
