# 流程流转交互模式

> 适用场景：审批流程、订单流转、工单状态、文档发布、项目管理

## 状态机模型

### 基本流转图
```
                  ┌──[通过]──→ 已审批 ──[发布]──→ 已发布
                  │                              │
  草稿 ──[提交]→ 待审批 ──[驳回]──→ 已驳回       │
                  │              │               │
                  │              └──[修改重提]──→ 待审批
                  │
                  └──[撤回]──→ 草稿

  已发布 ──[下架]──→ 已下架 ──[重新发布]──→ 已发布
  已发布 ──[归档]──→ 已归档
```

### 可视化步骤条
```
流转进度展示（水平步骤条）：
  ●──────────●──────────○──────────○
  提交申请     审批通过     发布上线     归档
  05-17       05-18       待处理       待处理
  张三        李四

流转进度展示（竖直步骤条）：
  ● 提交申请 ──── 05-17 14:30 张三
  │
  ● 审批通过 ──── 05-18 10:15 李四
  │               "同意，预算合理"
  │
  ○ 发布上线 ──── 待处理
  │
  ○ 归档 ──────── 待处理
```

## 状态字段定义

### 状态规范表
| 状态名 | 值 | 颜色 | 图标 | 允许转入 |
|--------|-----|------|------|---------|
| 草稿 | draft | #8C8C8C 灰 | [edit] | 已驳回、已撤回 |
| 待审核 | pending | #FAAD14 橙 | ⏳ | 草稿 |
| 审核通过 | approved | #52C41A 绿 | [pass] | 待审核 |
| 已驳回 | rejected | #FF4D4F 红 | [reject] | 待审核 |
| 已发布 | published | #1677FF 蓝 | [publish] | 审核通过、已下架 |
| 已下架 | offline | #8C8C8C 灰 | [down] | 已发布 |
| 已归档 | archived | #8C8C8C 灰 | [archive] | 已发布 |

### 状态标签颜色映射
```
进行中/待处理：#FAAD14（橙色）+ 实心背景
已完成/成功：  #52C41A（绿色）+ 实心背景
已拒绝/失败：  #FF4D4F（红色）+ 实心背景
草稿/草稿：   #8C8C8C（灰色）+ 浅灰背景
已发布/活跃：  #1677FF（蓝色）+ 浅蓝背景
已关闭/已归档：#8C8C8C（灰色）+ 灰色背景
```

## 操作按钮规则

### 按钮与状态映射
```
按当前状态动态显示操作按钮：

草稿：    [编辑] [提交审核] [删除]
待审核：  [审核通过] [驳回] [撤回]（仅提交人可见）
已通过：  [发布] [退回修改]
已驳回：  [修改重提] [查看驳回原因]
已发布：  [下架] [归档]
已下架：  [重新发布] [归档]
已归档：  [查看]（只读）

规则：
  - 当前状态不可用操作隐藏（非禁用）
  - 无权限操作隐藏（非禁用）
  - 危险操作（删除/驳回）红色按钮 + 二次确认
```

## 交互行为

### 状态变更流程
```
触发状态变更：
  1. 用户点击操作按钮（通过/驳回/发布...）
  2. 弹出确认弹窗（含备注字段）
  3. 确认提交 → 按钮loading
  4. 成功 → Toast提示 + 刷新页面 + 更新状态标签
  5. 失败 → 弹窗内显示错误信息

状态变更后：
  - 状态标签更新颜色和文字
  - 操作按钮组刷新（隐藏/显示）
  - 时间线新增一条状态变更记录
  - 通知相关人（站内信/邮件/推送）
```

### 批量状态变更
```
触发条件：列表页勾选多条记录
操作栏：  [批量通过] [批量驳回] [批量删除]
限制：
  - 只能对相同状态记录批量操作
  - 批量操作二次确认："确定批量通过选中的 N 条记录？"
  - 部分失败时提示成功/失败数量
```

### 状态变更历史
```
时间线展示（与 timeline 组件联动）：
  每次状态变更记录：
  - 变更时间
  - 操作人
  - 旧状态 → 新状态
  - 审批意见/备注
  - 附件（如有）

查看入口：
  - 详情页"流转记录"标签页
  - 列表页行操作"流转记录"
```

## 设计规范

| 属性 | 水平步骤条 | 竖直步骤条 |
|------|-----------|-----------|
| 节点圆点 | 24-32px | 24-32px |
| 节点间距 | 80-120px | 60-80px |
| 连线宽度 | 2px | 2px |
| 标签字号 | 14px | 14px |
| 描述字号 | 12px | 12px |

### 步骤条颜色
```
已完成节点：#1677FF（蓝色实心）
当前节点：  #1677FF（蓝色实心 + 脉冲动画）
待处理节点：#D9D9D9（灰色空心）
失败节点：  #FF4D4F（红色实心）
已完成连线：#1677FF
待完成连线：#E8E8E8
```

### 状态标签
```
小标签（列表内）：Tag 组件，24-28px 高
大标签（详情页）：Badge 组件，32-36px 高
带图标：图标 + 文字（如 [pass] 已通过）
```

## PRD 描述模板

### Part 7 流程流转功能描述示例
```
功能名称：文档发布审批流
组件类型：flow（流程流转）

状态定义：
| 状态 | 值 | 颜色 | 允许操作 | 可转入来源 |
|------|-----|------|---------|-----------|
| 草稿 | draft | 灰色 | 编辑/提交审核/删除 | 驳回/撤回 |
| 待审核 | pending | 橙色 | 通过/驳回/撤回 | 草稿 |
| 已通过 | approved | 绿色 | 发布/退回 | 待审核 |
| 已驳回 | rejected | 红色 | 修改重提 | 待审核 |
| 已发布 | published | 蓝色 | 下架/归档 | 已通过/已下架 |
| 已归档 | archived | 灰色 | 查看(只读) | 已发布 |

操作按钮规则：
  - 草稿：[编辑] [提交审核] [删除]（仅创建人可见）
  - 待审核：[通过] [驳回]（审核人可见）/ [撤回]（创建人可见）
  - 已通过：[发布]（管理员可见）
  - 已发布：[下架] [归档]（管理员可见）

流转记录：
  - 时间线展示所有状态变更
  - 包含操作人、时间、意见

交互行为：
  1. 提交审核 → 弹窗确认 → 通知审核人
  2. 通过/驳回 → 弹窗填写意见 → 变更状态 → 通知创建人
  3. 撤回 → 仅待审核状态可撤回 → 通知已审核人
  4. 批量操作 → 列表页多选后批量通过/驳回

业务规则：
  BR-001：仅创建人可提交/撤回/删除草稿
  BR-002：审核人不能审核自己创建的文档
  BR-003：驳回后修改重提进入新审核轮次
  BR-004：归档后不可修改，只可查看

异常处理：
  E-001：状态变更并发冲突 → 提示"数据已被他人修改，请刷新重试"
  E-002：审核人不存在 → 状态回退 + 通知管理员
  E-003：批量操作部分失败 → 提示成功N条/失败N条 + 失败原因
```

## 标注内容模板
```
目标选择器：.flow-container 或 [data-flow-id="xxx"]
内容结构：
  1. 状态定义表（名称+值+颜色+允许操作+可转入来源）
  2. 操作按钮映射（当前状态→可见按钮）
  3. 流转确认弹窗（字段+校验）
  4. 权限控制（角色→可执行操作）
  5. 业务规则（编号 BR-XXX）
  6. 异常处理（编号 E-XXX）
```
