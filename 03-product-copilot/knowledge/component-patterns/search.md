# 搜索组件交互模式

> 适用场景：全局搜索、站内搜索、表格筛选搜索、文档搜索

## 搜索类型

| 类型 | 位置 | 适用场景 |
|------|------|---------|
| 全局搜索 | 顶部导航栏 | 全站内容搜索 |
| 列表搜索 | 列表页筛选区 | 当前列表数据筛选 |
| 高级搜索 | 独立面板/抽屉 | 多条件组合筛选 |
| 即时搜索 | 输入框内 | 下拉建议实时匹配 |

## 交互行为

### 输入交互
| 交互 | 行为 | 时间 |
|------|------|------|
| 输入 | 防抖触发搜索 | 300ms |
| 聚焦 | 展开搜索建议面板 | 即时 |
| 清空 | 点击 × 清空输入 + 关闭结果 | 即时 |
| Enter | 跳转搜索结果页 | 即时 |
| ESC | 关闭建议面板 | 即时 |

### 搜索建议
```
建议来源（优先级）：
  1. 搜索历史（匹配前缀）
  2. 热门搜索（固定列表）
  3. 最近访问（时间倒序）
  4. 实时匹配结果（输入 ≥ 2 字符后）

建议数量：最多 8 条
```

### 结果展示
```
结果分类（Tab 切换）：
  - 全部（默认）
  - 页面
  - 文档
  - 数据
  - 人员

排序：
  - 相关度（默认）
  - 时间（最新/最早）

分页：
  - 每页 10 条
  - 无限滚动加载更多
```

### 关键词高亮
```
匹配关键词高亮：
  <b style="color:#1677FF">关键词</b>
  高亮色与主题色一致
  大小写不敏感
```

### 空结果
```
无结果时：
  [S] 未找到"xxx"的相关结果
  建议：
  · 检查输入是否有误
  · 尝试使用更简短的关键词
  · 尝试使用同义词
```

## 设计规范

### 搜索框
| 属性 | 全局搜索 | 列表搜索 | 即时搜索 |
|------|---------|---------|---------|
| 宽度 | 400-600px | 240-320px | 100% |
| 高度 | 40px | 32px | 36px |
| 圆角 | 20px（胶囊） | 6px | 8px |
| 图标 | 左侧 [S] | 左侧 [S] | 左侧 [S] |
| 清除 | 右侧 × | 右侧 × | 右侧 × |

### 下拉面板
```
最大高度：400px，超出滚动
投影：0 4px 12px rgba(0,0,0,.12)
圆角：8px
内边距：8px
```

## PRD 描述模板

```
功能名称：全局搜索
组件类型：search（全局搜索）

位置：顶部导航栏居中

搜索范围：
  - 页面标题和内容
  - PRD 文档标题和正文
  - 项目名称和描述
  - 用户姓名、角色

交互：
  1. 点击搜索框展开面板，显示历史/热门
  2. 输入 ≥ 2 字符开始匹配建议
  3. Enter 跳转搜索结果页
  4. 结果分类 Tab 切换
  5. 关键词高亮
  6. 搜索历史保存最近 10 条

业务规则：
  BR-001：搜索结果按权限过滤，不展示无权限内容
  BR-002：搜索历史仅保存当前用户，不跨用户
  BR-003：支持拼音首字母搜索（zhangsan → 张三）
```
