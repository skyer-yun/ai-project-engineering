# 导航交互模式

> 适用场景：系统布局、页面导航、菜单管理、面包屑、标签页

## 导航类型

### 顶部导航

```
┌─────────────────────────────────────────────────────────┐
│  Logo  [首页] [项目管理] [数据分析] [系统设置]   [U] 张三│
└─────────────────────────────────────────────────────────┘
```

## 菜单结构定义

### 菜单项属性
| 属性 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 标题 | string | 是 | 菜单显示名称 |
| 图标 | string | 否 | 左侧图标（推荐带图标） |
| 路径 | string | 是 | 路由路径 |
| 权限 | string | 否 | 权限标识码 |
| 子菜单 | array | 否 | 嵌套子菜单（最多3层） |
| 外链 | boolean | 否 | 是否外部链接 |
| 隐藏 | boolean | 否 | 是否在菜单中隐藏 |
| 徽标 | string/number | 否 | 右侧数字/红点 |
| 排序 | number | 否 | 显示顺序 |

### 多级菜单规范
```
层级限制：最多 3 层
  第1层：一级模块（项目、数据、设置）
  第2层：二级页面（列表、看板、统计）
  第3层：三级功能（特殊子页面）

第1层：仅图标 + 文字，不可点击（有子菜单时）
第2层：缩进显示，可点击跳转
第3层：再次缩进显示，可点击跳转

建议：
  层级过多时考虑拆分模块或使用标签页
  一级菜单数量 ≤ 8 个
  二级菜单数量 ≤ 10 个
```

## 交互行为

### 菜单展开/折叠
| 交互 | 行为 | 说明 |
|------|------|------|
| 点击一级菜单 | 展开/收起子菜单 | 手风琴模式（同时只展开一个） |
| 点击叶节点 | 跳转对应页面 + 高亮 | 路由变化 + 选中态 |
| 侧边栏折叠 | 208px → 64px | 鼠标悬浮一级菜单显示 Popover 子菜单 |
| 折叠态悬浮 | Popover 显示子菜单 | 移出后延迟 200ms 关闭 |
| 折叠/展开按钮 | 底部按钮/双击边线 | 记住用户偏好 |

### 路由与高亮
```
路由匹配规则：
  1. 精确匹配：当前路径 === 菜单路径
  2. 前缀匹配：当前路径以菜单路径开头（子路由高亮父菜单）
  3. 别名匹配：配置的别名路径数组

高亮样式：
  选中菜单：背景色 #E6F4FF + 左侧3px蓝色竖线 + 文字#1677FF
  悬浮菜单：背景色 #F5F5F5
  父级菜单（子菜单选中时）：文字#1677FF
```

### 面包屑生成
```
生成规则：
  1. 根据当前路由自动从菜单树匹配路径
  2. 每级可点击跳转（除最后一级）
  3. 首页始终显示
  4. 详情页追加："列表名称 > 详情"

示例：
  /dashboard → 首页
  /project/list → 首页 > 项目管理 > 项目列表
  /project/detail/123 → 首页 > 项目管理 > 项目列表 > 项目详情
```

### 标签页管理
```
标签页行为：
  - 点击菜单打开新标签（已存在则激活）
  - 右键菜单：关闭当前/关闭其他/关闭全部/关闭右侧
  - 标签过多时左右滚动（< > 按钮）
  - 固定标签不可关闭（首页/仪表盘）
  - 关闭当前标签后激活相邻标签

标签页限制：
  - 最大打开数量：15 个
  - 超出后提示"已打开过多标签，请关闭不需要的"
```

### 权限控制
```
菜单级权限：
  - 无权限菜单不显示（非灰色/禁用）
  - 路由守卫拦截：直接输入URL跳403
  - 按钮级权限：菜单内操作按钮按权限显示/隐藏

角色权限矩阵：
  | 菜单       | 管理员 | 编辑 | 查看 |
  |-----------|--------|------|------|
  | 项目管理   | Y       | Y    | Y    |
  | 系统设置   | Y       | N    | N    |
  | 数据导出   | Y       | Y    | N    |
```

## 设计规范

### 侧边栏尺寸
| 属性 | 展开态 | 折叠态 |
|------|--------|--------|
| 宽度 | 208-220px | 64-80px |
| 菜单项高度 | 40-44px | 48-52px |
| 图标大小 | 16-20px | 20-24px |
| 文字字号 | 14px | 隐藏 |
| 子菜单缩进 | 每层 +24px | - |
| Logo 高度 | 48-56px | 48-56px |

### 顶部栏尺寸
| 属性 | 值 |
|------|---|
| 高度 | 48-64px |
| Logo 宽度 | 120-160px |
| 菜单项间距 | 32-40px |
| 字号 | 14-16px |

### 颜色
```
侧边栏（亮色模式）：
  背景：#FFFFFF
  菜单文字：#333333
  选中背景：#E6F4FF
  选中文字：#1677FF
  选中左边线：#1677FF（3px）
  悬浮背景：#F5F5F5
  分割线：#F0F0F0

侧边栏（暗色模式）：
  背景：#001529
  菜单文字：#FFFFFFB3
  选中背景：#1677FF
  选中文字：#FFFFFF
  悬浮背景：#FFFFFF1A
```

### 移动端适配
```
< 768px：
  - 侧边栏隐藏，改为抽屉式导航
  - 点击汉堡菜单(☰)打开侧边抽屉
  - 点击菜单项跳转 + 自动关闭抽屉
  - 顶部导航保留 Logo + 汉堡菜单 + 用户头像
```

## PRD 描述模板

### Part 7 导航功能描述示例
```
功能名称：系统导航菜单
组件类型：navigation（侧边导航 + 顶部栏）

菜单结构：
| 一级菜单 | 二级菜单 | 路径 | 图标 | 权限 |
|---------|---------|------|------|------|
| 仪表盘 | - | /dashboard | DashboardOutlined | dashboard:view |
| 项目管理 | 项目列表 | /project/list | UnorderedListOutlined | project:list |
|         | 项目看板 | /project/board | AppstoreOutlined | project:board |
|         | 项目归档 | /project/archive | InboxOutlined | project:archive |
| 数据分析 | 销售报表 | /report/sales | BarChartOutlined | report:sales |
|         | 用户分析 | /report/user | PieChartOutlined | report:user |
| 系统设置 | 基本设置 | /settings/basic | SettingOutlined | settings:view |
|         | 用户管理 | /settings/users | TeamOutlined | settings:users |
|         | 角色权限 | /settings/roles | SafetyOutlined | settings:roles |

导航行为：
  1. 侧边栏默认展开，可折叠为图标模式
  2. 手风琴模式：同时只展开一个一级菜单
  3. 路由变化自动匹配菜单高亮
  4. 面包屑自动生成
  5. 标签页：点击菜单打开标签，最多15个

权限控制：
  - 菜单按权限过滤显示
  - 无权限路由跳转403页面
  - 管理员可见所有菜单

业务规则：
  BR-001：侧边栏展开/折叠状态持久化（localStorage）
  BR-002：标签页固定"仪表盘"不可关闭
  BR-003：移动端(<768px)侧边栏改为抽屉模式
  BR-004：菜单变更后实时刷新，不需要重新登录

异常处理：
  E-001：菜单接口失败 → 显示上次缓存菜单 + 提示
  E-002：路由无匹配菜单 → 面包屑只显示当前页标题
  E-003：权限变更后自动刷新菜单（WebSocket推送）
```

## 标注内容模板
```
目标选择器：.navigation-sidebar 或 [data-nav-id="xxx"]
内容结构：
  1. 菜单结构树（层级+路径+图标+权限）
  2. 导航模式（顶部/侧边/混合）
  3. 交互行为（展开/折叠/高亮/标签页）
  4. 权限控制矩阵（角色→菜单可见性）
  5. 业务规则（编号 BR-XXX）
  6. 异常处理（编号 E-XXX）
```
