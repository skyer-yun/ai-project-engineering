# 弹窗交互模式

> 适用场景：确认操作、表单编辑、详情查看、图片预览、批量导入

## 弹窗类型

| 类型 | 尺寸 | 内容 | 操作 |
|------|------|------|------|
| 确认弹窗 | 400px | 标题 + 描述文字 | 确定/取消 |
| 表单弹窗 | 小400/中640/大960px | 表单内容 | 提交/取消 |
| 详情弹窗 | 640-960px | 描述列表/富文本 | 关闭 |
| 预览弹窗 | 80vw × 80vh | 图片/视频/PDF | 关闭/下载/上一张/下一张 |
| 全屏弹窗 | 100vw × 100vh | 复杂表单/多步骤 | 保存/取消 |

## 交互行为

### 打开与关闭
| 方式 | 行为 |
|------|------|
| 打开 | 点击触发按钮 → 遮罩层淡入 → 弹窗从中心缩放弹出（200ms） |
| 关闭-按钮 | 点击 × / 取消 / 确定 → 弹窗缩放消失 → 遮罩淡出 |
| 关闭-遮罩 | 点击遮罩层关闭（确认弹窗除外，防止误操作） |
| 关闭-ESC | 按 ESC 关闭（全屏编辑弹窗除外，防止误关） |
| 关闭-回调 | 关闭前检查是否有未保存修改 → 提示保存 |

### 表单弹窗特殊交互
```
打开时：
  1. 聚焦第一个输入框
  2. 新建模式：表单清空
  3. 编辑模式：填充现有数据

填写时：
  - 实时校验（blur/change）
  - 错误提示在字段下方
  - 必填项未填时提交按钮禁用

提交时：
  1. 全量校验
  2. 校验失败：滚动到第一个错误字段
  3. 校验成功：提交按钮 loading
  4. 成功：关闭弹窗 + Toast 提示
  5. 失败：弹窗内显示错误信息

关闭时：
  - 有修改未保存 → 二次确认："修改未保存，确定关闭？"
  - 无修改 → 直接关闭
```

### 多步骤弹窗
```
┌──────────────────────────────────────┐
│  批量导入                         × │
│──────────────────────────────────────│
│  ① 上传文件  ② 数据预览  ③ 确认导入  │
│      ●─────────○─────────○          │
│──────────────────────────────────────│
│  当前步骤内容                        │
│                                      │
│──────────────────────────────────────│
│  [取消]               [上一步] [下一步]│
└──────────────────────────────────────┘

规则：
  - 每步可独立校验
  - 上一步保留已填数据
  - 最后一步显示"提交"而非"下一步"
  - 不允许跳步
```

## 设计规范

### 尺寸
| 类型 | 宽度 | 最大高度 | 内容区 |
|------|------|---------|--------|
| 小 | 400px | 70vh | 固定 |
| 中 | 640px | 70vh | 可滚动 |
| 大 | 960px | 80vh | 可滚动 |
| 全屏 | 100vw | 100vh | 全部可滚动 |

### 间距
```
标题栏：padding 16-20px，底部 1px 分割线
内容区：padding 20-24px
底部栏：padding 12-16px，顶部 1px 分割线
按钮间距：8-12px
```

### 层级
```
z-index 层级：
  遮罩层：1000
  弹窗：1001
  嵌套弹窗遮罩：2000
  嵌套弹窗：2001
  最多支持 3 层嵌套（不推荐超过 2 层）
```

### 动画
```
打开：scale(0.8) + opacity(0) → scale(1) + opacity(1)，200ms ease-out
关闭：scale(1) + opacity(1) → scale(0.8) + opacity(0)，150ms ease-in
遮罩：opacity(0) → opacity(1)，200ms
```

## PRD 描述模板

```
功能名称：新建项目弹窗
组件类型：modal（表单弹窗）

尺寸：中（640px）

表单字段：
| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|---------|
| 项目名称 | Input | 是 | 2-50字符，不可重复 |
| 负责人 | Select | 是 | 从团队成员选择 |
| 截止日期 | DatePicker | 否 | 不早于今天 |
| 优先级 | Radio | 是 | P0/P1/P2/P3，默认P2 |
| 描述 | TextArea | 否 | 最多500字 |

交互：
  1. 打开时聚焦"项目名称"输入框
  2. 项目名称实时查重（blur触发）
  3. 提交后按钮 loading，成功关闭弹窗 + 刷新列表
  4. 未保存关闭时二次确认

业务规则：
  BR-001：项目名称重复时输入框标红，提示"项目名称已存在"
  BR-002：P0 项目需要额外填写"紧急原因"
  BR-003：创建成功后自动创建一条时间线记录
```
