# 投标文件工作流（N3-N4）

## 概述

本工作流覆盖 N3-N4（投标）阶段，基于招标文件生成完整的投标响应材料，包括技术标和商务标。

## 工作流步骤

### Step 1：招标文件解析

**输入**：
- 招标文件（PDF / Word / 文本）
- 公司资质材料（如有）

**处理**：
1. 读取招标文件内容
2. 提取关键信息：
   - 项目名称、编号
   - 投标截止时间
   - 资质要求
   - 评分标准
   - 技术要求
   - 商务要求
   - 格式要求（页数、字体、排版）
3. 识别废标条款和否决项
4. 生成招标要点摘要

**输出**：
- 招标要点摘要
- 资格自查清单
- 废标风险提示

**依赖**：
- pdf（增强，读取 PDF 格式招标文件）

### Step 2：技术标编写

**输入**：
- 招标要点摘要
- 评分标准
- 技术要求清单
- 公司技术能力资料

**处理**：
1. 对照评分标准逐项编写技术响应
2. 按招标文件要求的格式组织内容
3. 突出技术优势和差异化能力
4. 确保每个评分项都有对应响应
5. 生成技术方案章节（可引用 proposal-workflow）

**输出**：
- 技术标初稿
- 评分项覆盖度检查表

**依赖**：
- technical-proposal-writer（核心）
- knowledge/proposal-templates/（方案模板）

### Step 3：商务标编写

**输入**：
- 招标要点摘要
- 商务要求
- 报价策略

**处理**：
1. 按招标文件要求编写商务部分
2. 报价清单（如需）
3. 项目实施计划
4. 团队组织方案
5. 服务承诺

**输出**：
- 商务标初稿

**依赖**：
- xlsx（增强，报价清单表格）

### Step 4：格式化与自检

**输入**：
- 技术标初稿
- 商务标初稿
- 招标文件格式要求

**处理**：
1. 按招标文件格式要求排版
2. 逐项检查评分项覆盖度
3. 检查废标条款合规性
4. 检查页数、字体、目录等格式要求
5. 交叉引用一致性检查

**输出**：
- 格式化自检报告
- 待修改清单

### Step 5：配套演示（可选）

**触发条件**：
- 招标文件要求述标/答辩
- 用户需要准备述标材料

**处理**：
1. 基于技术标核心内容制作演示 PPT
2. 准备述标大纲和关键话术
3. 预准备可能的质询问题及回答

**输出**：
- 述标 PPT（.pptx）
- 述标大纲（.md）
- 质询预备清单

**依赖**：
- pptx（增强）
- demo-presentation-workflow

## 技术标标准结构

```
一、项目理解
  1.1 项目背景
  1.2 需求理解
  1.3 建设目标

二、总体方案
  2.1 设计原则
  2.2 系统架构
  2.3 技术路线
  2.4 功能设计

三、技术优势
  3.1 核心技术能力
  3.2 差异化方案
  3.3 创新点

四、项目实施
  4.1 实施方法论
  4.2 阶段划分与计划
  4.3 质量保障措施

五、团队组织
  5.1 项目团队架构
  5.2 核心人员简历
  5.3 职责分工

六、服务保障
  6.1 培训方案
  6.2 售后服务
  6.3 应急响应

七、风险控制
  7.1 风险识别
  7.2 应对措施
```

## 商务标标准结构

```
一、投标函
二、法定代表人授权书
三、投标报价表
四、资质证明文件
五、业绩证明
六、服务承诺书
七、项目实施计划
```

## 产物清单

| 产物 | 格式 | 必选/可选 | 说明 |
|------|------|----------|------|
| 招标要点摘要 | .md | 必选 | 从招标文件提取的关键信息 |
| 资格自查清单 | .md | 必选 | 资质/条件自查 |
| 技术标 | .docx | 必选 | 技术响应文档 |
| 商务标 | .docx | 必选 | 商务响应文档 |
| 报价清单 | .xlsx / .md | 可选 | 详细报价表 |
| 格式化自检报告 | .md | 必选 | 格式合规检查结果 |
| 述标 PPT | .pptx | 可选 | 述标演示材料 |

## 产物归档

```
项目文档/{客户名}-{项目名}/01-需求/
  ├── {日期}-招标要点摘要.md
  ├── {日期}-技术标-v{版本}.docx
  ├── {日期}-商务标-v{版本}.docx
  └── {日期}-述标PPT-v{版本}.pptx（可选）
```

## 回退与异常

| 异常 | 处理 |
|------|------|
| 招标文件无法读取 | 提示用户转存为文本格式提供 |
| 废标条款无法满足 | 明确标注风险 + 评估是否继续 |
| 技术能力不匹配评分项 | 标注弱项 + 提供最大化得分建议 |
| 时间紧迫 | 优先技术标核心章节 + 简化非关键项 |
| 格式要求特殊 | 按要求调整 + 标注不确定的格式点 |
