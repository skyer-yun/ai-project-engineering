# 客户演示工作流（N3-N4）

## 概述

本工作流覆盖 N3-N4（演示）阶段，为客户交流、方案汇报、述标答辩等场景准备演示材料。

## 工作流步骤

### Step 1：演示规划

**输入**：
- 演示目的（方案汇报/产品演示/述标答辩/客户交流）
- 目标听众（决策层/技术层/业务层）
- 可用时间
- 已有材料（技术方案/PRD/产品功能说明）

**处理**：
1. 确定演示类型和风格
2. 规划演示结构（开场→核心内容→互动→结尾）
3. 确定核心信息点（不超过 5 个）
4. 分配每部分时间

**输出**：
- 演示规划文档（含结构大纲、时间分配、核心信息点）

### Step 2：PPT 制作

**输入**：
- 演示规划文档
- 已有方案/产品材料

**处理**：
1. 选择 PPT 风格模板（商务/科技/简约）
2. 按结构大纲逐页设计
3. 插入架构图、流程图等可视化内容
4. 添加数据图表支撑论点
5. 制作动画和过渡效果（可选）

**输出**：
- 演示 PPT（.pptx）

**依赖**：
- pptx（增强，缺失则输出 .md 大纲）

**PPT 页数建议**：

| 演示时长 | 建议页数 | 说明 |
|----------|----------|------|
| 15 分钟 | 10-15 页 | 快速汇报，聚焦核心 |
| 30 分钟 | 20-30 页 | 标准方案汇报 |
| 60 分钟 | 30-50 页 | 详细演示/述标 |
| 90+ 分钟 | 按需 | 工作坊/培训 |

### Step 3：配套材料

**输入**：
- 演示规划文档
- 已制作的 PPT

**处理**：
1. 制作演示大纲/讲稿（备注每页要点）
2. 准备 Q&A 预备清单（可能的问题 + 回答要点）
3. 如需 Demo，规划 Demo 演示流程
4. 如需讲义，制作精简版摘要

**输出**：
- 演示大纲（.md）
- Q&A 预备清单（.md）
- 讲义（可选，.docx / .md）

## PPT 标准结构（方案汇报）

```
1. 封面（项目名称、汇报人、日期）
2. 目录
3. 项目背景
   - 行业现状
   - 客户痛点
   - 建设目标
4. 方案概述
   - 总体架构图
   - 核心能力
   - 技术路线
5. 核心功能（3-5 个重点）
   - 功能展示
   - 价值说明
   - 差异化优势
6. 技术优势
   - 架构优势
   - 技术选型
   - 性能指标
7. 实施计划
   - 阶段划分
   - 里程碑
   - 团队配置
8. 服务保障
   - 质量保障
   - 培训方案
   - 售后服务
9. 案例展示（如有）
10. 总结与展望
11. Q&A
12. 联系方式
```

## PPT 标准结构（述标答辩）

```
1. 封面
2. 公司简介
3. 项目理解
   - 需求理解
   - 建设目标
4. 解决方案
   - 总体架构
   - 功能设计
   - 技术路线
5. 实施方案
   - 实施方法论
   - 项目计划
   - 团队配置
6. 项目优势
   - 技术优势
   - 经验优势
   - 服务优势
7. 成功案例
8. 服务承诺
9. 报价概述（如需）
10. 总结
11. Q&A
```

## 产物清单

| 产物 | 格式 | 必选/可选 | 说明 |
|------|------|----------|------|
| 演示规划文档 | .md | 必选 | 结构、时间、核心信息点 |
| 演示 PPT | .pptx / .md | 必选 | 演示文稿 |
| 演示大纲 | .md | 必选 | 每页要点 + 讲稿 |
| Q&A 预备清单 | .md | 可选 | 可能的问题 + 回答要点 |
| 讲义 | .docx / .md | 可选 | 精简版摘要 |

## 产物归档

```
项目文档/{客户名}-{项目名}/01-需求/
  ├── {日期}-演示规划.md
  ├── {日期}-演示PPT-v{版本}.pptx
  ├── {日期}-演示大纲.md
  └── {日期}-QA预备清单.md（可选）
```

## 回退与异常

| 异常 | 处理 |
|------|------|
| pptx 技能缺失 | 输出 .md 大纲 + 每页内容描述 |
| 方案材料不足 | 先完成 proposal-workflow 再制作 PPT |
| 时间极度紧张 | 优先制作核心 5-10 页 + 大纲 |
| 听众层级不明确 | 准备两个版本（决策层精简版 + 技术层详细版） |
