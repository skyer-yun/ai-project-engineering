# 方案模板库

## 概述

本目录包含售前阶段常用的方案模板结构，供 proposal-workflow 使用。

## 模板列表

### 1. 技术方案（标准 11 章）

适用于：信息化项目建设、系统开发、平台搭建等项目的技术方案。

| 章节 | 标题 | 核心内容 |
|------|------|----------|
| 第 1 章 | 项目概述 | 背景、目标、范围、术语 |
| 第 2 章 | 需求理解 | 业务需求、功能需求、非功能需求、优先级 |
| 第 3 章 | 总体架构设计 | 设计原则、系统架构图、技术架构、数据架构、网络架构 |
| 第 4 章 | 功能设计 | 模块划分、详细设计、业务流程、页面/接口 |
| 第 5 章 | 技术选型 | 选型原则、前后端技术栈、数据库、中间件、对比表 |
| 第 6 章 | 数据设计 | 数据模型、数据流转、数据安全、备份恢复 |
| 第 7 章 | 安全设计 | 安全架构、认证授权、数据安全、网络安全、合规 |
| 第 8 章 | 部署方案 | 部署架构、环境规划、部署策略、容灾 |
| 第 9 章 | 项目实施计划 | 方法论、阶段划分、里程碑、资源需求 |
| 第 10 章 | 风险与应对 | 风险识别、评估、应对措施、监控机制 |
| 第 11 章 | 服务与保障 | 项目团队、质量保障、培训、售后、验收标准 |

**页数参考**：40-80 页

### 2. 解决方案（标准 7 章）

适用于：面向客户的高层方案、行业解决方案、产品解决方案。

| 章节 | 标题 | 核心内容 |
|------|------|----------|
| 第 1 章 | 项目背景与目标 | 行业趋势、客户痛点、建设目标 |
| 第 2 章 | 行业现状与痛点 | 行业分析、痛点梳理、需求提炼 |
| 第 3 章 | 解决方案概述 | 方案理念、总体架构、核心能力 |
| 第 4 章 | 核心能力 | 3-5 个核心能力展示、功能亮点 |
| 第 5 章 | 实施路径 | 实施方法论、阶段规划、预期成果 |
| 第 6 章 | 预期效果 | 量化效果、ROI 分析、标杆案例 |
| 第 7 章 | 服务保障 | 团队介绍、服务承诺、成功案例 |

**页数参考**：20-40 页

### 3. 架构设计（标准 8 章）

适用于：系统架构设计、技术架构评审、技术选型论证。

| 章节 | 标题 | 核心内容 |
|------|------|----------|
| 第 1 章 | 架构概述 | 背景、目标、约束、范围 |
| 第 2 章 | 架构原则 | 设计原则、设计模式、规范约束 |
| 第 3 章 | 系统架构 | 系统上下文、子系统划分、交互关系 |
| 第 4 章 | 应用架构 | 应用分层、服务划分、API 设计 |
| 第 5 章 | 数据架构 | 数据模型、存储方案、数据治理 |
| 第 6 章 | 技术架构 | 技术栈选型、框架选型、工具链 |
| 第 7 章 | 安全架构 | 安全策略、认证授权、数据保护 |
| 第 8 章 | 部署架构 | 部署拓扑、环境规划、CI/CD、监控 |

**页数参考**：30-60 页

## 模板使用建议

### 按场景选择

| 场景 | 推荐模板 | 说明 |
|------|----------|------|
| 正式投标 | 技术方案 11 章 | 最完整，覆盖评审要点 |
| 客户初步交流 | 解决方案 7 章 | 高层视角，聚焦价值 |
| 技术评审会 | 架构设计 8 章 | 技术深度，架构完整 |
| 方案更新/迭代 | 基于已有方案调整 | 保留结构，更新内容 |

### 按行业调整

不同行业在模板基础上有额外要求：

| 行业 | 额外章节/调整 |
|------|---------------|
| 政务 | 增加信创适配、等级保护、数据共享 |
| 金融 | 增加合规要求、风控设计、审计日志 |
| 教育 | 增加教学模式、数据治理、校园集成 |
| 企业 | 增加组织架构适配、流程引擎、数据打通 |

## 模板定制

如需新增行业模板，在本目录下创建 `{行业名}-技术方案.md`，包含：
- 行业特有章节
- 行业术语表
- 行业合规要求清单
- 行业典型架构参考
