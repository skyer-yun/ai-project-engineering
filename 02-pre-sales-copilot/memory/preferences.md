# 用户偏好模板

## 使用说明

本文件记录用户的售前工作偏好，pre-sales-copilot 启动时加载。用户表达偏好时自动更新。

## 偏好项

### 语言与表达

- 方案语言：中文 / 英文 / 双语
- 技术术语：中文为主保留英文 / 全英文 / 全中文
- 表达风格：正式商务 / 简洁技术 / 平衡
- 详细程度：详细展开 / 精炼要点 / 按需调整

### 方案偏好

- 默认方案类型：技术方案（11章）/ 解决方案（7章）/ 架构设计（8章）
- 架构图格式：Mermaid / PlantUML / DrawIO
- 方案页数偏好：精简（<30页）/ 标准（30-60页）/ 详细（60+页）
- 技术选型倾向：（如偏好开源 / 商业 / 混合）

### 行业偏好

- 主要服务行业：（如政务 / 金融 / 教育 / 企业 / 多行业）
- 行业术语习惯：（记录用户常用的行业表达）

### 工作习惯

- 方案编写流程：先框架后填充 / 逐章推进 / 一次性输出
- 审查频率：每章确认 / 完成后统一审查 / 按需
- 中间产物保留：保留所有中间版本 / 仅保留最终版

### 输出偏好

- 默认输出格式：.docx / .md / 按场景选择
- 文件命名习惯：（如 {日期}-{类型}-{版本}.docx）
- 归档位置：（如 项目文档/{客户名}-{项目名}/）

### 客户沟通

- 演示材料风格：商务正式 / 科技现代 / 简约清新
- PPT 详细程度：关键词+图表 / 完整句子 / 讲稿式

## 记录格式

```markdown
### {偏好类型}
- {偏好项}：{值}
- 更新时间：{YYYY-MM-DD}
- 来源：用户明确指定 / 行为推断
```

## 示例

```markdown
### 语言与表达
- 方案语言：中文为主
- 技术术语：中文为主保留英文
- 表达风格：平衡
- 更新时间：2026-05-22
- 来源：用户明确指定

### 方案偏好
- 默认方案类型：技术方案（11章）
- 架构图格式：Mermaid
- 更新时间：2026-05-22
- 来源：默认值
```
