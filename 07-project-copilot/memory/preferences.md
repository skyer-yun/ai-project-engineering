# 用户偏好

> 最后更新：2026-05-22
> 用途：记录用户项目管理习惯与偏好，Project Copilot 据此调整管理方式与报告风格

---

## 语言与风格

| 项目 | 偏好 |
|------|------|
| 语言 | 中文优先，专有名词保持英文原文 |
| 输出风格 | 简洁直接，先说结论再给细节 |
| 交付物 | 面向文档/表格/报告，不面向讨论 |
| 语气 | 自信但不自负，不确定时先确认再做 |

## 项目管理偏好

| 领域 | 默认选择 | 备选 |
|------|----------|------|
| 项目类型 | [A] 产品开发 | [B]售前/[C]迭代/[D]自由 |
| WBS 分解 | 按交付物分解 | 按阶段/功能模块 |
| 估算方法 | 三点估算法(PERT) | 专家法(Delphi)/类比法 |
| 甘特图 | Mermaid | Excel（如 xlsx 已安装） |
| 风险管理 | 概率x影响矩阵 | 定性分析 |
| 报告格式 | Markdown | Word（如 docx 已安装） |

## 项目管理标准

- **范围基线不可口头变更**：所有变更走变更流程
- **关键路径零容忍**：关键路径延误必须立即处理
- **质量门禁不跳过**：QG1-QG5 逐个通过
- **P0/P1 清零原则**：QG4 的 P0/P1 清零无例外

## 报告偏好

| 报告类型 | 默认格式 | 频率 |
|----------|---------|------|
| 周报 | Markdown / Word | 每周五 |
| 月报 | Word / PPT | 每月末 |
| 里程碑报告 | Word | 每个里程碑 |
| 结项报告 | Word | 项目结束时 |

## 工作习惯

- **编辑优先**：修改现有文件，避免创建新文件
- **先读后改**：改文件前先读取理解上下文
- **不过度工程**：只做要求的事
- **对结果负责**：门禁通过率 100% 是硬性要求
