## 一、提示词工程原则

### 1.1 核心原则

| 原则 | 说明 | 示例 |
|------|------|------|
| 意图清晰 | 明确告诉AI要做什么、输出什么 | 「生成Spring Boot Controller代码」而非「帮我写代码」 |
| 上下文完整 | 提供必要的背景信息和约束条件 | 包含项目技术栈、命名规范、响应格式 |
| 格式明确 | 指定期望的输出格式 | Markdown表格、JSON、Mermaid图表 |
| 示例驱动 | 提供Few-shot示例提升输出质量 | 给出正确输出的样例 |
| 边界约束 | 明确什么不能做 | 「不要编造数据」「使用项目已有组件」 |

### 1.2 提示词结构标准

```
## 角色定义
你是一个{角色}，{能力描述}。

## 任务
{任务描述}

## 输入
{输入数据/上下文}

## 输出格式
{输出格式要求}

## 约束条件
{约束列表}
```

### 1.3 命名规范

提示词ID格式：PROMPT-{角色}-{功能}-{版本}，如 PROMPT-PM-RESEARCH-V1

变量占位符：{{变量名}}

## 二、产品经理提示词模板

### 2.1 PROMPT-PM-RESEARCH-V1 需求调研报告生成

角色：资深产品经理，擅长从杂乱的客户资料中提炼结构化需求。

输入：客户原始资料（访谈录音转录/会议纪要/业务文档/竞品资料）+ 项目背景

输出格式：需求调研报告，包含项目背景、业务现状分析（Mermaid流程图）、痛点问题、期望目标、业务场景清单、干系人分析、功能需求初步清单、非功能需求、术语表、待确认问题清单

约束：所有内容必须从输入资料中提取，不确定的内容标注「待确认」

### 2.2 PROMPT-PM-FEATURELIST-V1 功能清单生成

角色：资深产品经理，擅长需求拆解和优先级分析。

输出：功能全景图（Mermaid mindmap）+ 功能清单表 + 优先级分析(P0/P1/P2) + 依赖关系图 + MVP范围建议 + 迭代规划建议

### 2.3 PROMPT-PM-PRD-V1 PRD章节生成

角色：资深产品经理，擅长编写规范、完整的PRD文档。

输出：按PRD规范模板输出对应章节内容。功能模块详细说明包含：功能描述、输入项表、输出项表、数据流说明、业务规则、状态定义、异常处理。

## 三、设计师提示词模板

### 3.1 PROMPT-DESIGN-PROTOTYPE-V1 原型设计生成

输出：页面结构（ASCII布局图）+ 组件清单 + 交互流程（Mermaid状态图）+ 交互规则 + 状态设计 + 设计说明

### 3.2 PROMPT-DESIGN-TOKENS-V1 Design Tokens生成

输出：YAML格式的完整Design Tokens定义（色彩系统/字体系统/间距系统/圆角系统/阴影系统/断点系统/动画系统）

### 3.3 PROMPT-DESIGN-COMPONENT-V1 组件设计规范生成

输出：组件概述 + 组件状态表 + 组件变体表 + 尺寸规格 + 组件结构图 + 交互规则 + 无障碍设计 + 代码示例

## 四、开发工程师提示词模板

### 4.1 PROMPT-DEV-CODE-V1 代码生成

角色：资深Java开发工程师，严格遵守项目编码规范。

输入：接口定义 + 数据库表结构(DDL) + 业务规则

输出：Controller代码 + Service代码 + 单元测试代码（含完整注释）

约束：统一Result响应格式、MyBatis-Plus、金额Long类型（分）

### 4.2 PROMPT-DEV-REVIEW-V1 代码审查

输出：审查概要 + 问题清单（严重/一般/优化建议）+ 安全审查 + 性能审查 + 审查结论

## 五、测试工程师提示词模板

### 5.1 PROMPT-TEST-CASE-V1 测试用例生成

输出：功能概述 + 测试用例清单 + 测试数据设计（正常/边界/异常）+ 覆盖分析 + 状态转换测试

### 5.2 PROMPT-TEST-API-V1 接口测试脚本生成

支持：Postman Collection / pytest 脚本

### 5.3 PROMPT-TEST-PERFORMANCE-V1 性能测试脚本生成

输出：JMeter命令 + 线程组配置 + 参数化配置 + 断言配置 + 监控指标

## 六、架构师提示词模板

### 6.1 PROMPT-ARCH-DESIGN-V1 架构设计建议

输出：技术选型建议表 + 系统架构图(Mermaid) + 微服务划分 + 数据库设计建议 + 缓存策略 + 高可用设计 + 容量预估

## 七、运维工程师提示词模板

### 7.1 PROMPT-OPS-DEPLOY-V1 部署脚本生成

输出：Dockerfile + Docker Compose + K8s Deployment + CI/CD配置
