## 第四部分：组件规范

### 4.1 按钮组件

按钮类型：Primary / Default / Text / Danger

按钮尺寸：Large(48px) / Middle(40px) / Small(32px)

按钮状态：Normal / Hover / Active / Disabled / Loading

### 4.2 表单组件

输入框规范：高度40px、内边距0 12px、字号14px、圆角8px

### 4.3 卡片组件

卡片结构：头部48px + 内容区域 + 底部操作48px(可选)

## 第五部分：页面布局规范

### 5.1 C端小程序布局

首页：导航栏44px + Banner 160px + 业态入口100px + 活动/优惠/资讯模块 + 底部Tab 50px

### 5.2 G端管理后台布局

侧边栏200px + 内容区域(flex:1)
表格规范：表头高度56px、行高56px、表头背景#FAFAFA、斑马纹

### 5.3 数据大屏布局

基于3840x2160设计稿，使用rem单位自适应

## 第六部分：交互规范

### 6.1 反馈机制

- Toast提示：成功(2s自动消失) / 错误(手动关闭) / 加载(操作完成消失)
- 模态框：确认弹窗 / 表单弹窗 / 信息展示

### 6.2 加载状态

页面加载(全屏加载动画) / 列表加载(骨架屏) / 下拉刷新 / 上拉加载 / 按钮加载(Spinner)

### 6.3 空状态

无订单/无优惠券/搜索无结果，各有对应插图、文案和操作按钮
