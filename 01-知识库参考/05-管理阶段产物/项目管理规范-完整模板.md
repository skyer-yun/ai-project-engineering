## 二、项目管理框架

5阶段模型：启动 → 规划 → 执行 → 监控 → 收尾

项目组织架构：项目指导委员会 → 项目经理 → 产品组/开发组/测试组/运维组

## 三、WBS工作分解规范

分解原则：100%覆盖、互斥原则、粒度适中(8-80小时)、名词命名、不超过4层

蒲阳生活项目WBS示例（5个一级分解、逐层展开至工作包级别）

## 四、工作量估算规范

4种方法：专家法(Delphi)±30% / 类比法±20% / 三点法(PERT)±15% / 功能点法±10%

蒲阳生活项目总估算：664人天（后端308 + 前端198 + 测试128 + 设计41）

## 五、进度管理规范

9个Sprint规划（Sprint 0-9，共28周），含甘特图规范、进度报告模板

## 六、风险管理规范

8项典型风险及应对策略，风险等级矩阵（高/中/低概率 x 高/中/低影响）

风险应对策略：规避、转移、减轻、接受

## 七、变更管理规范

6步变更流程：变更申请 → 变更评估 → 变更审批 → 变更实施 → 变更验证 → 变更关闭

## 八、质量管理规范

6项质量指标 + 评审机制 + 缺陷管理（S1致命/S2严重/S3一般/S4轻微）

## 九、沟通管理规范

6类沟通：每日站会、周例会、迭代评审、需求评审、客户汇报、技术分享

## 十、文档管理规范

17类文档清单、命名规范、版本控制

## 十一、验收标准清单

10项检查：项目计划、需求覆盖、进度偏差(<10%)、缺陷关闭、代码审查、文档完整、变更管理、风险管理、沟通记录、知识转移

文档版本：V1.0
