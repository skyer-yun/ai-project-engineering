## 使用说明（必读）

1. **定位**：本清单是 PRD 中验收标准的**结构化台账**——测试用例从这里派生，客户验收按此逐项签收。它是「需求 → 测试」的直通桥，避免测试阶段重读 PRD 产生理解偏差。
2. **AC 编号**：每条验收标准分配 `AC-NNN`，全局唯一。溯源链：`AC-NNN → REQ-NNN → SRC-NNN`。
3. **可测试性**：每条标准必须可客观判定（给定输入/操作 → 可观察的结果）。写不出来的标准说明 PRD 该条目不合格，回 PRD 修改。
4. **写法**：推荐 Given-When-Then（GWT）三段式，字段量化不写形容词。
