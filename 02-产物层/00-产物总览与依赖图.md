## 三、产物依赖图

```
D-Discover
  ├── 需求分析报告 ────────┐
  └── 干系人清单 ──────────┤
                           ▼
                        QG-D
                           │
                           ▼
S-Spec
  ├── 技术方案 ────────────┐
  ├── PRD ─────────────────┤
  ├── UI-UX 设计 ──────────┤
  ├── 架构设计 ←── PRD     │
  │   └── ADR              │
  └── 详细设计 ←── 架构    │
                           ▼
                        QG-S
                           │
                           ▼
B-Build
  ├── 源代码 ←── 详设 + OpenAPI
  ├── 单元测试 ←── 源代码
  ├── 接口文档 ←── 详设
  └── 联调报告 ←── 源代码 + 接口文档
                           ▼
                        QG-B
                           │
                           ▼
S-Ship
  ├── 测试策略 ←── PRD + 详设
  ├── 测试用例 ←── 测试策略
  ├── 测试报告 ←── 测试用例 + 源代码
  ├── 部署文档 ←── 架构 + 运维需求
  ├── 验收报告 ←── PRD + 测试报告 + 客户
  ├── 培训材料 ←── PRD + UI-UX + 源代码
  └── 运维手册 ←── 部署文档 + 监控
                           ▼
                        QG-Ship
                           │
                           ▼
L-Learn
  ├── 项目复盘报告 ←── 全程契约链 + QG 历史 + Loop 度量
  └── 项目档案 ←── 全部产物归档
```

## 四、存储位置约定

| 类型 | 存储位置 |
|------|---------|
| 文档（方案/PRD/设计/报告） | `项目文档/{项目}/{阶段}/` |
| 源代码 | Git |
| 交接契约 | `项目文档/{项目}/_handoffs/` |
| 项目档案 | `项目文档/{项目}/_archive/` |
| 经验入库 | 体系知识库（跨项目） |
