## 三、产物依赖图

```
需求（D）
  ├── 需求调研记录（SRC-NNN 素材台账）
  │     └── 需求清单（REQ-NNN）─── 每条 REQ 引用 ≥1 个 SRC
  ├── 需求分析报告 ←── 需求清单（功能总表引用 REQ 编号）
  ├── 干系人清单 ──────────┐
  └── 需求确认书 ←── 需求清单 + 需求分析报告（基线冻结，客户签）
                           ▼
                        QG-需求
                           │
                           ▼
设计（S）
  ├── 产品方案 ←── 需求清单（覆盖矩阵 REQ↔F 编号）──┐
  ├── 原型四件套 ←── 产品方案（F 编号）+ 需求清单    │
  │     ├── 页面树（页面 ID）                       │
  │     ├── 高保真原型包（pages/**）                 │
  │     ├── 标注数据（ANN-NNN → REQ-NNN）           │
  │     └── 原型说明（需求↔页面覆盖矩阵）            │
  ├── PRD ←── 原型四件套（prototype_ref 反向引用）   │
  ├── 验收标准清单 ←── PRD + 需求清单（AC→REQ）      │
  ├── 技术方案 ────────────┐
  ├── UI-UX 设计 ←── 原型 ─┤
  ├── 架构设计 ←── PRD     │
  │   └── ADR              │
  └── 详细设计 ←── 架构    │
                           ▼
                        QG-设计
                           │
                           ▼
开发（B）
  ├── 源代码 ←── 详设 + OpenAPI
  ├── 单元测试 ←── 源代码
  ├── 接口文档 ←── 详设
  └── 联调报告 ←── 源代码 + 接口文档
                           ▼
                        QG-开发
                           │
                           ▼
交付（Ship）
  ├── 测试策略 ←── PRD + 验收标准清单 + 详设
  ├── 测试用例 ←── 测试策略 + 验收标准清单（AC-NNN）
  ├── 测试报告 ←── 测试用例 + 源代码
  ├── 部署文档 ←── 架构 + 运维需求
  ├── 验收报告 ←── 验收标准清单（AC 签收）+ 测试报告 + 客户
  ├── 培训材料 ←── PRD + 原型 + UI-UX + 源代码
  └── 运维手册 ←── 部署文档 + 监控
                           ▼
                        QG-交付
                           │
                           ▼
复盘（L）
  ├── 项目复盘报告 ←── 全程契约链 + QG 历史 + Loop 度量
  └── 项目档案 ←── 全部产物归档
```

> **追溯主链**：`SRC-NNN（素材）→ REQ-NNN（需求）→ F 编号（方案项）→ 页面 ID + ANN-NNN（原型）→ PRD → AC-NNN（验收标准）→ 测试用例`。任一环节断链即对应 QG 检查项不通过。

|------|---------|

| 项目档案 | `项目文档/{项目}/_archive/` |
