# 用户偏好

> 最后更新：2026-05-22
> 用途：记录用户交付工作习惯与偏好，Delivery Copilot 据此调整输出风格与部署策略

---

## 语言与风格

| 项目 | 偏好 |
|------|------|
| 语言 | 中文优先，专有名词保持英文原文 |
| 输出风格 | 简洁直接，先说结论再给细节 |
| 交付物 | 面向文档/方案，不面向讨论 |
| 语气 | 自信但不自负，不确定时先确认再做 |

## 部署偏好

| 领域 | 默认选择 | 备选 |
|------|----------|------|
| 部署模式 | Docker Compose | K8s（大规模）/ 私有化（政企） |
| 发布策略 | 滚动更新 | 蓝绿（核心系统）/ 全量（内部系统） |
| 文档格式 | Word (.docx) | Markdown（无 docx 时） |
| 培训材料 | PPT (.pptx) | Markdown（无 pptx 时） |
| 配置管理 | 环境变量 + .env 文件 | ConfigMap（K8s） |

## 文档偏好

| 文档类型 | 默认格式 | 读者 |
|----------|---------|------|
| 用户手册 | Word (.docx) | 业务操作人员 |
| 运维手册 | Word (.docx) | 系统管理员 |
| 培训材料 | PPT (.pptx) | 全体用户 |
| 验收报告 | Word (.docx) | 客户/管理层 |
| API 文档 | Markdown | 开发人员 |
| 快速入门 | Word (.docx) | 新用户 |

## 交付标准

- **测试未通过不上线**：P0/P1 必须清零
- **部署必有回滚方案**：每次部署必须准备回滚
- **验收按 PRD 标准**：严格按 PRD Part 11 执行
- **文档面向最终用户**：用户手册面向非技术人员
- **运维手册可操作**：每个步骤可复现可验证

## 工作习惯

- **编辑优先**：修改现有文件，避免创建新文件
- **先读后改**：改文件前先读取理解上下文
- **不过度工程**：只做要求的事
- **对结果负责**：部署成功率 100% 是硬性要求
