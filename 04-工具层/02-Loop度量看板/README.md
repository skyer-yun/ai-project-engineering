## 45 条 KPI 来源

> 旧版（v1.0）按 6 工种分 38 条；v1.1 重组为按 **5 逻辑角色** 分 45 条，每条带「阶段 + QG」双标签。工种 ↔ 角色映射详见 [01-标准层/01-五阶段定义.md](../../01-标准层/01-五阶段定义.md)。

| 角色 | KPI 数 | 主要阶段 | 代表指标 |
|------|--------|---------|---------|
| 需求规范师（Spec-Writer） | 9 | D / S | 需求覆盖率 / 干系人签字完整度 / PRD 12 部分完整度 / AC 可测试率 |
| 构建师（Builder） | 10 | S / B | 核心代码单测覆盖 / Lint Critical / Plan Mode 遵守率 / Atomic Commit |
| 审查师（Reviewer） | 8 | 跨阶段 | 需求评审通过率 / 代码审查覆盖率 / QG 一次通过率 / 缺陷逃逸率 |
| 交付师（Shipper） | 9 | Ship | 用例通过率 / 一次部署成功率 / 客户满意度 / 培训考核通过率 |
| 统筹师（Keeper） | 9 | 全程 / L | 计划偏差率 / 关键路径零延误 / 复盘改进项闭环率 / 经验沉淀入库 |

每条 KPI 字段：`{id, name, desc, target, type, direction, stage, qg, role, collect_method}`

看板按目标自动着色：
- 绿色 = 达标
- 橙色 = 临界
- 红色 = 未达标

每张 KPI 卡片显示**阶段徽章**（D/S/B/Ship/L，颜色编码）+ **QG 徽章**（点击跳转 QG checklist）。

## 快速上手

### 1. 打开看板

双击 `02-Loop度量看板.html`，浏览器（Chrome/Edge/Firefox）直接打开，无网络依赖。

首次打开会自动生成 1 个「示例项目（参考）」DEMO-001，预填本月随机达标数据。

### 2. 新增项目

右上角「+ 新增项目」→ 填写编码、名称、阶段、状态。

### 3. 录入 KPI

- 切换「项目」「时间周期（YYYY-MM）」
- 点击任一 KPI 卡片 → 弹窗编辑数值 + 备注
- 颜色实时变化（绿/橙/红）

### 4. 多项目横向对比

工具栏「对比模式」切换为「多项目横向对比」→ 每张 KPI 卡片变为表格，列出所有项目的当期数值。

### 5. 时间趋势

切到任一角色 Tab，底部自动渲染**达标率趋势图**（SVG 折线 + 面积），随历史周期数累积。

### 6. 数据备份/迁移

- **导出 CSV**：右上角「导出 CSV」→ 文件名 `loop-dashboard-{周期}-{时间戳}.csv`，含 BOM 兼容 Excel 中文。
- **导入 CSV**：右上角「导入」选择 CSV → 合并到现有数据（不覆盖，按 项目+周期+KPI 合并）。

## 数据存储

- **位置**：浏览器 `localStorage`（key: `loop_dashboard_v1`）
- **特性**：刷新不丢失；清浏览器数据会丢失
- **建议**：每周/每月定期「导出 CSV」备份；项目结项时归档到 `项目文档/{项目}/04-管理阶段/loop-kpi-{周期}.csv`

## FAQ

**Q: 数据能否多端同步？**
A: 本工具纯本地存储，不支持多端同步。如需多人共享，导出 CSV 通过项目 wiki / Git 仓库协作。

**Q: 如何自定义 KPI？**
A: 编辑 HTML 内 `KPI_GROUPS` 常量，按现有结构增删条目。`id` 必须全局唯一。

**Q: 浏览器兼容性？**
A: 原生 HTML + CSS + JS（无 CDN、无框架），支持 Chrome 80+ / Edge / Firefox / Safari。IE 不支持。

**Q: 看板能否嵌入 Confluence/飞书？**
A: HTML 文件可直接以附件形式上传，或嵌入 iframe。CSV 数据可粘贴到飞书表格协作。
