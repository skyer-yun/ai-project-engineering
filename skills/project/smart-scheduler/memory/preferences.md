# 排期偏好设置

## 输出格式
- 默认：Markdown 排期表 + Mermaid 甘特图
- 可选：HTML 交互式甘特图（需 gantt-visualizer）

## 排期粒度
- 默认：天（适用于 1-6 个月项目）
- 可选：周（>6 个月项目）/ 半天（<1 个月项目）

## 资源模型
- 默认产能：1 人 = 8h/天
- 默认效率系数：0.8（考虑会议、沟通开销）
- 默认工作日：周一至周五

## 缓冲策略
- 项目缓冲：关键路径 15%
- 接驳缓冲：汇入路径 50%
- 资源缓冲：1 天

## 方案输出
- 默认输出 2 个方案：均衡方案 + 最短工期方案
- 偏好方案：均衡方案（优先保证资源健康）
