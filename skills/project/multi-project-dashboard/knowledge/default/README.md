# 多项目看板知识库

## 看板布局设计

### 整体结构

```
+------------------------------------------------------------------+
|                        顶部汇总栏                                   |
|  [项目总数] [进行中] [预警] [延期] [平均健康分] [需关注]            |
+------------------------------------------------------------------+
|  筛选栏：[全部] [进行中] [预警] [延期]  |  搜索：[________]         |
+------------------------------------------------------------------+
|                                                                    |
|  +--项目卡片--+  +--项目卡片--+  +--项目卡片--+  +--项目卡片--+    |
|  | 项目A      |  | 项目B      |  | 项目C      |  | 项目D      |    |
|  | 进度 75%   |  | 进度 40%   |  | 进度 90%   |  | 进度 20%   |    |
|  | 健康 85    |  | 健康 62    |  | 健康 91    |  | 健康 --    |    |
|  | 风险: 低   |  | 风险: 高   |  | 风险: 低   |  | 风险: --   |    |
|  +------------+  +------------+  +------------+  +------------+    |
|                                                                    |
+------------------------------------------------------------------+
```

### 响应式断点

| 屏幕宽度 | 布局 | 每行卡片数 |
|----------|------|-----------|
| >= 1440px | 桌面宽屏 | 4 列 |
| 1024-1439px | 桌面标准 | 3 列 |
| 768-1023px | 平板 | 2 列 |
| < 768px | 手机 | 1 列 |

## 项目卡片信息结构

### 必选信息

| 字段 | 位置 | 说明 |
|------|------|------|
| 项目名称 | 卡片标题 | 加粗显示 |
| 状态色条 | 卡片顶部 | 绿/黄/红/灰 4px 色条 |
| 进度百分比 | 进度条 | 带数字的进度条 |
| 健康分数 | 右上角 | 0-100 数字 |
| 风险等级 | 标签 | 低/中/高/极高 |
| 当前阶段 | 副标题 | 需求/设计/开发/测试/交付 |

### 可选信息

| 字段 | 位置 | 条件 |
|------|------|------|
| 项目经理 | 底部 | 始终显示 |
| 起止日期 | 底部 | 始终显示 |
| 关键风险 | 展开区 | 展开后显示 |
| 资源负载 | 展开区 | 展开后显示 |
| 里程碑列表 | 展开区 | 展开后显示 |

---

## 状态颜色映射

### 项目整体状态

| 状态 | 颜色 | 色值 | 判定条件 |
|------|------|------|----------|
| 正常 | 绿色 | #52c41a | 健康分 >= 80，无高风险 |
| 预警 | 黄色 | #faad14 | 健康分 60-79 或存在中风险 |
| 告警 | 红色 | #f5222d | 健康分 < 60 或存在高/极高风险 |
| 未开始 | 灰色 | #d9d9d9 | 项目尚未启动 |

### 进度条颜色

| 进度范围 | 颜色 | 说明 |
|----------|------|------|
| >= 计划进度 | 项目主色 | 进度正常 |
| < 计划进度 10% 以内 | 黄色 | 轻微滞后 |
| < 计划进度 10% 以上 | 红色 | 严重滞后 |

## 图表类型选择

| 展示需求 | 推荐图表 | 实现方式 |
|----------|----------|----------|
| 项目状态分布 | 环形图 | CSS/SVG 内联 |
| 进度对比 | 横向柱状图 | CSS/SVG 内联 |
| 健康趋势 | 折线图 | SVG 内联 |
| 资源负载 | 柱状图 | CSS/SVG 内联 |
| 里程碑时间线 | 时间线图 | CSS 内联 |

**原则**：所有图表使用 CSS 或 SVG 内联实现，不依赖第三方图表库。

## HTML 模板参考

### 技术栈约束
- 纯 HTML5 + CSS3 + 原生 JavaScript
- 不依赖任何外部 CSS/JS 框架
- 不依赖 CDN 资源
- 字体使用系统字体栈

### CSS 变量定义

```css
:root {
  --color-success: #52c41a;
  --color-warning: #faad14;
  --color-danger: #f5222d;
  --color-default: #d9d9d9;
  --color-primary: #1890ff;
  --color-bg: #f5f5f5;
  --color-card: #ffffff;
  --color-text: #333333;
  --color-text-secondary: #666666;
  --shadow-card: 0 2px 8px rgba(0,0,0,0.1);
  --radius: 8px;
}
```

### 打印样式

```css
@media print {
  .filter-bar, .search-box { display: none; }
  .project-card { break-inside: avoid; }
  body { background: white; }
}
```
