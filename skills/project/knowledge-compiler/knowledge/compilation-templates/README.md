```

    （同上结构）

## 二、行业模板沉淀模板

### 文档结构

```
[行业名称]行业方案模板

一、行业背景
  1.1 行业概述
      - 行业规模和发展趋势
      - 信息化成熟度评估
      - 政策法规要求
  1.2 典型痛点
      | 痛点编号 | 痛点描述 | 影响程度 | 出现频率 |
      |----------|----------|----------|----------|
      | P01 | 数据孤岛，系统间无法互通 | 高 | 90% |
      | P02 | 业务流程纸质化，效率低 | 高 | 80% |
      | P03 | ... | ... | ... |
  1.3 需求特征
      - 共性需求（所有客户都需要）
      - 个性需求（部分客户需要）
      - 合规需求（监管强制要求）

二、方案框架
  2.1 方案总体架构
      - 架构图占位符
      - 核心模块说明
  2.2 方案章节结构
      | 章节 | 标题 | 核心内容 | 注意事项 |
      |------|------|----------|----------|
      | 1    | 项目概述 | 背景/目标/范围 | 突出政策合规性 |
      | 2    | 需求分析 | 现状/痛点/需求 | 用客户语言描述 |
      | ...  | ...  | ...      | ... |
  2.3 关键方案模块
      - 模块1：[名称]（解决的问题 / 技术方案 / 关键指标）
      - 模块2：[名称]（同上）

三、技术选型参考
  | 技术领域 | 推荐方案 | 备选方案 | 选型理由 | 不推荐方案 |
  |----------|----------|----------|----------|------------|
  | 前端框架 | Vue3+Element Plus | React+Ant Design | 政企生态成熟 | ... |
  | 后端框架 | Spring Boot | ... | Java生态主流 | ... |
  | 数据库   | PostgreSQL | MySQL | ... | ... |
  | ... | ... | ... | ... | ... |

四、注意事项
  4.1 合规要求
      - 数据安全法/个人信息保护法要求
      - 等保合规要求
      - 行业监管要求
  4.2 技术风险
      - 常见技术风险及应对方案
  4.3 实施风险
      - 常见实施风险及应对方案
  4.4 验收要点
      - 行业特有的验收标准和流程

五、参考案例
  5.1 案例一：（脱敏描述）
      - 客户背景
      - 解决方案概述
      - 实施效果（量化数据）
  5.2 案例二：（同上）
```

## 三、知识库更新规范

### 更新类型

| 类型 | 触发条件 | 审批要求 | 回顾周期 |
|------|----------|----------|----------|
| 新增 | 新行业/新技术/新模板 | 自审即可 | 6个月 |
| 更新 | 内容补充/修正/版本升级 | 自审即可 | 12个月 |
| 归档 | 超过2年未使用/技术已过时 | 标记为「待归档」 | 不再回顾 |
| 删除 | 内容错误/已完全过时 | 确认后删除 | - |

### 知识条目格式

```
---
title: [标题]
category: [行业模板|技术模板|管理模板|工具模板]
tags: [标签1, 标签2, 标签3]
source: [来源项目，脱敏]
date: YYYY-MM-DD
status: [active|review|archived]
review_date: YYYY-MM-DD
---

## 四、度量数据模板

### 度量指标定义

| 指标 | 计算公式 | 数据来源 | 行业基线 | 采集频率 |
|------|----------|----------|----------|----------|
| 工期偏差 | (实际-计划)/计划 x 100% | 甘特图/WBS | +/-15% | 项目结束时 |
| 成本偏差 | (实际-计划)/计划 x 100% | 预算表 | +/-10% | 项目结束时 |
| 缺陷密度 | 缺陷总数/KLOC | 缺陷跟踪系统 | <5/KLOC | 测试阶段 |
| 人均产出 | 功能点数/人月数 | 需求文档/排期 | 行业参考 | 项目结束时 |
| 需求变更率 | 变更数/总需求数 x 100% | 变更记录 | <20% | 项目结束时 |
| 缺陷修复率 | 已修复/总缺陷 x 100% | 缺陷跟踪系统 | >95% | 测试阶段 |
| 客户满意度 | 满意度评分/5 | 满意度调查 | >4/5 | 验收阶段 |
| 代码审查覆盖率 | 已审查代码/总代码 x 100% | 代码审查工具 | >80% | 开发阶段 |
| 测试用例覆盖率 | 已执行/总用例 x 100% | 测试管理工具 | >95% | 测试阶段 |
| 自动化测试率 | 自动化用例/总用例 x 100% | 测试工具 | >30% | 测试阶段 |

### 评价标准

| 评级 | 工期偏差 | 成本偏差 | 缺陷密度 | 满意度 |
|------|----------|----------|----------|--------|
| 优 | <= 5% | <= 5% | < 2/KLOC | >= 4.5/5 |
| 良 | <= 15% | <= 10% | < 5/KLOC | >= 4.0/5 |
| 差 | > 15% | > 10% | >= 5/KLOC | < 4.0/5 |
