# knowledge-compiler 触发配置

## 触发关键词

| 关键词 | 匹配规则 | 说明 |
|--------|----------|------|
| 知识沉淀 | 完全匹配 / 包含 | 项目知识沉淀 |
| 项目总结 | 完全匹配 / 包含 | 项目经验总结 |
| 经验总结 | 完全匹配 / 包含 | 经验提炼 |
| 模板沉淀 | 完全匹配 / 包含 | 行业模板沉淀 |
| 知识管理 | 完全匹配 / 包含 | 知识库管理 |
| 结项总结 | 完全匹配 / 包含 | 项目结项总结 |
| 复盘 | 完全匹配 / 包含 | 项目复盘 |
| 经验提取 | 包含匹配 | 经验提取 |
| 度量分析 | 包含匹配 | 项目度量 |

## 触发优先级

1. 明确提到「知识沉淀」「模板沉淀」→ 高优先级触发（全套知识沉淀流程）
2. 明确提到「项目总结」「结项总结」→ 高优先级触发（经验总结 + 度量分析）
3. 包含「经验总结」「复盘」→ 中优先级触发（侧重经验提炼）
4. 包含「知识管理」「度量分析」→ 低优先级触发，需确认范围

## 去触发规则

以下场景不应触发本技能：
- 仅写项目周报/月报（非总结性质）→ 走 07-project-copilot
- 纯文档整理（非知识提炼）→ 走 docx 原生路由
- 会议纪要编写 → 走 docx 原生路由
