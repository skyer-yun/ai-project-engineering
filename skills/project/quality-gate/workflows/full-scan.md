# Full Scan Workflow

> 全量门禁扫描流程

## Stage 1: 检测项目阶段

```
扫描项目目录 → 检测已有产物：
  01-需求/ 有产物 → 至少过了 N1-N2
  02-产品/ 有产物 → 至少过了 N4
  03-设计/ 有产物 → 至少过了 N5-N6
  04-开发/ 有产物 → 至少过了 N7-N8
  05-测试/ 有产物 → 至少过了 N10-N11
  06-交付/ 有产物 → 至少过了 N13-N14

推断当前阶段 → 确定哪些门禁需要检查
```

## Stage 2: 顺序执行门禁

```
FOR each applicable gate (QG1 → QG2 → ... → QG5):
  1. 执行 single-gate-check 流程
  2. 记录结果
  3. IF FAIL → 可选择：停止扫描 / 继续扫描下一个
```


## Stage 4: 建议与下一步

```
输出：
1. 当前阶段判定
2. 需要立即修复的阻塞项
3. 建议的下一步行动
4. 预计通过时间（如可估算）
```
