# 持续优化知识库

## 过程改进框架（PDCA）

### PDCA 四阶段

| 阶段 | 英文 | 核心活动 | 产出物 |
|------|------|----------|--------|
| Plan | 计划 | 识别问题、分析根因、制定改进计划 | 改进计划书 |
| Do | 执行 | 试点实施、收集数据、记录过程 | 试点报告 |
| Check | 检查 | 对比目标、评估效果、识别偏差 | 效果评估报告 |
| Act | 处理 | 标准化成功经验、推广实施、持续监控 | 标准化文档 |

### 改进周期建议

| 改进类型 | 周期 | 验证频率 |
|----------|------|----------|
| 流程优化 | 1-3 个月 | 每 2 周 |
| 工具引入 | 2-4 个月 | 每月 |
| 能力提升 | 3-6 个月 | 每月 |
| 组织变革 | 6-12 个月 | 每季度 |

## 度量指标体系

### 工期偏差指标

| 指标 | 计算公式 | 健康范围 | 告警阈值 |
|------|----------|----------|----------|
| 工期偏差率 | (实际-计划)/计划 | +/- 10% | > 20% |
| 阶段偏差率 | 各阶段同上 | +/- 15% | > 25% |
| 里程碑准时率 | 准时达成/总里程碑 | > 90% | < 75% |
| 关键路径偏差 | 实际-计划（天） | +/- 5 天 | > 10 天 |

### 成本偏差指标

| 指标 | 计算公式 | 健康范围 | 告警阈值 |
|------|----------|----------|----------|
| 成本偏差率 | (实际-预算)/预算 | +/- 10% | > 20% |
| 人均日产出 | 功能点/人日 | 按行业基准 | < 基准 70% |
| 返工成本比 | 返工成本/总成本 | < 10% | > 20% |
| 需求变更成本 | 变更处理成本/总成本 | < 15% | > 25% |

### 质量指标

| 指标 | 计算公式 | 健康范围 | 告警阈值 |
|------|----------|----------|----------|
| 缺陷密度 | 缺陷数/千行代码 | < 5 | > 15 |
| 缺陷修复率 | 已修复/总缺陷 | > 95% | < 85% |
| 测试覆盖率 | 已覆盖/总路径 | > 80% | < 60% |
| 验收一次通过率 | 一次通过/总验收 | > 85% | < 70% |

### 效率指标

| 指标 | 计算公式 | 健康范围 | 告警阈值 |
|------|----------|----------|----------|
| 需求吞吐量 | 完成需求/迭代周期 | 按团队基线 | < 基准 70% |
| 交付周期 | 需求提出到上线天数 | < 30 天 | > 60 天 |
| 资源利用率 | 实际/可用工时 | 70%-85% | > 95% 或 < 60% |
| 会议效率比 | 有效决策时间/总会议时间 | > 60% | < 40% |

## 改进方案模板

### 方案结构

```
# 过程改进方案

## 一、改进背景
- 问题描述 / 数据支撑 / 影响范围

## 二、根因分析
- 5-Why 分析 / 鱼骨图 / 帕累托分析

## 三、改进目标
- 量化目标（从 X 降到 Y）
- 预期收益

## 四、实施计划（PDCA）
### Plan
- 具体步骤 / 资源需求 / 时间安排
### Do
- 试点范围 / 执行方式
### Check
- 验证指标 / 检查频率 / 成功标准
### Act
- 推广计划 / 标准化措施

## 五、ROI 估算
- 实施成本 / 预期收益 / 回收周期
```

## ROI 计算方法

### 基本公式

```
ROI = (收益 - 成本) / 成本 x 100%
回收周期 = 成本 / 月均收益
```

### 成本估算

| 成本类型 | 估算方法 | 说明 |
|----------|----------|------|
| 人力成本 | 参与人数 x 投入天数 x 日均成本 | 直接投入人员 |
| 工具成本 | 采购费用 / 年摊销 | 需要新工具时 |
| 培训成本 | 参训人数 x 培训天数 x 日均成本 | 能力提升类 |
| 机会成本 | 投入期间减少的产出 | 间接成本 |

### 收益估算

| 收益类型 | 估算方法 | 说明 |
|----------|----------|------|
| 工期缩短 | 节省天数 x 日均人力成本 | 直接收益 |
| 质量提升 | 减少缺陷数 x 缺陷修复成本 | 直接收益 |
| 返工减少 | 减少返工工时 x 日均成本 | 直接收益 |
| 客户满意度 | 提升续约率 x 项目金额 | 间接收益 |
