# 风险监控工作流

## 步骤 1：数据采集

**目标**：获取项目运行状态的最新数据。

**采集维度**：
- **进度数据**：任务完成率、里程碑达成情况、关键路径偏差
- **质量数据**：缺陷数量/密度、测试通过率、返工率
- **资源数据**：人员利用率、资源变更记录、加班统计
- **范围数据**：需求变更次数、变更影响范围、范围蔓延比例

**数据来源**：07-project-copilot 提供的项目状态数据

**输出**：标准化的项目状态快照

---

## 步骤 2：指标计算

**目标**：基于采集数据计算关键绩效指标。

**核心指标**：

| 指标 | 公式 | 健康范围 |
|------|------|----------|
| SPI（进度绩效指数） | EV / PV | 0.95 - 1.05 |
| CPI（成本绩效指数） | EV / AC | 0.95 - 1.05 |
| 缺陷密度 | 缺陷数 / 功能点数 | < 0.5 |
| 资源利用率 | 实际工时 / 计划工时 | 0.7 - 0.9 |
| 需求变更率 | 变更数 / 基线需求数 | < 15% |

**输出**：指标计算结果表

---

## 步骤 3：阈值检测

**目标**：对比预设阈值，识别异常指标。

**检测规则**：
1. 逐项对比指标值与阈值区间
2. 标记偏离项（黄色预警 / 红色告警）
3. 检查趋势方向（连续恶化 / 稳定 / 改善）
4. 识别指标间的关联异常（如 SPI 低 + 变更率高 = 范围蔓延风险）

**输出**：异常指标清单 + 趋势标记

---

## 步骤 4：风险定级

**目标**：综合评定风险等级。

**定级方法**：基于「概率-影响」矩阵

| 等级 | 判定条件 | 响应要求 |
|------|----------|----------|
| 极高 | 多项红色告警 + 关键路径受阻 | 立即升级，24h 内制定应急方案 |
| 高 | 单项红色或多项黄色持续恶化 | 3 天内制定应对方案 |
| 中 | 单项黄色偏离，趋势稳定 | 纳入观察清单，定期检查 |
| 低 | 指标正常或轻微波动 | 记录备案，无需特殊处理 |

**输出**：风险定级报告 + 概率-影响矩阵图

---

## 步骤 5：预警通知

**目标**：输出结构化预警报告和应对建议。

**报告结构**：
1. **执行摘要**：总体健康评分 + 风险等级 + 关键发现
2. **指标详情**：各指标当前值/趋势/阈值对比
3. **风险清单**：已识别风险列表（等级/描述/影响范围）
4. **应对建议**：针对高风险项的具体应对措施
5. **升级路径**：需要升级的事项和升级对象
6. **跟踪事项**：上次预警的闭环状态更新

**输出格式**：Markdown 报告 + 风险矩阵可视化
