# 培训材料模板库

## 一、培训方案模板

### 方案结构

```
1. 培训概述
   1.1 培训背景
   1.2 培训目标
       - 知识目标：了解 XX 系统的整体架构和 N 个核心功能模块
       - 技能目标：能够独立完成 XX 日常业务操作，操作正确率 >= 95%
       - 态度目标：认可系统价值，积极配合上线使用
   1.3 培训范围
       - 系统范围：本次培训覆盖的功能模块清单
       - 排除范围：不在本次培训范围内的高级/管理功能

2. 培训计划
   2.1 培训阶段
       | 阶段 | 内容 | 时长 | 形式 | 对象 |
       |------|------|------|------|------|
       | 基础培训 | 系统概述+核心功能 | 2h | 讲授+演示 | 全体 |
       | 专项培训 | 按角色分组深入 | 2h | 实操 | 分组 |
       | 实操演练 | 模拟业务场景 | 2h | 练习+考核 | 操作人员 |
       | 管理培训 | 系统管理+运维 | 1h | 讲授 | 管理员 |
   2.2 培训日程
   2.3 场地与环境要求

3. 培训内容
   3.1 内容模块清单
       | 编号 | 模块名称 | 时长 | 形式 | 学习目标 |
       |------|----------|------|------|----------|
       | M01 | 系统概述 | 20min | 讲授 | 了解系统定位和核心价值 |
       | M02 | 快速入门 | 30min | 演示 | 掌握登录和基本导航 |
       | M03 | 功能模块A | 40min | 演示+实操 | 独立完成A模块操作 |
       | ... | ... | ... | ... | ... |
   3.2 模块依赖关系
   3.3 讲师分工（如有）

4. 培训考核
   4.1 考核形式：笔试（选择题+判断题）+ 实操考核
   4.2 考核内容：覆盖全部核心功能模块
   4.3 通过标准：总分 >= 80 分（满分 100 分）
   4.4 补考机制：未通过者可在 X 天后补考一次
   4.5 考核结果应用：通过考核方可获得系统使用权限

5. 培训保障
   5.1 培训环境准备（练习环境、测试数据）
   5.2 培训材料清单
   5.3 培训后支持方式（FAQ、视频教程、技术支持）
```

## 四、考核题库模板

### 选择题模板

```
题目编号：C-001
题目类型：单选题
所属模块：M01-系统概述
难度：基础

题目：
以下关于 XX 系统的描述，哪一项是正确的？

A. XX 系统仅用于数据查询，不支持数据录入
B. XX 系统支持多个业务部门的协同办公
C. XX 系统只能在公司内网访问
D. XX 系统不需要登录即可使用

正确答案：B

解析：
XX 系统是一个面向多部门的综合业务管理平台，支持数据查询、录入、
审批等全流程操作。系统支持内网和外网访问（通过 VPN），使用前需
要使用分配的账号密码登录。
```

### 判断题模板

```
题目编号：J-001
题目类型：判断题
所属模块：M03-功能模块A
难度：基础

题目：
提交业务数据后，如果发现填写错误，可以随时自行修改已提交的数据。

正确答案：错误

解析：
已提交进入审批流程的数据不能直接修改。如果需要修改，需要先在
系统中发起「撤回」操作，撤回成功后才能重新编辑提交。已经审批
通过的数据，需要联系管理员处理。
```

### 实操题模板

```
题目编号：P-001
题目类型：实操题
所属模块：M03-功能模块A
难度：中等
分值：20分

题目场景：
业务部门收到一个新的项目需求，需要在系统中完成以下操作：
1. 创建一条新的项目记录
2. 填写项目基本信息（项目名称/负责人/开始日期/预算金额）
3. 上传项目需求文档
4. 提交审批

操作要求：
- 项目名称：「2026年XX升级项目」
- 负责人：选择当前登录用户
- 开始日期：今天的日期
- 预算金额：500,000
- 需求文档：使用提供的示例文件

预期结果：
1. 成功创建项目记录
2. 所有必填字段填写完整
3. 文件上传成功
4. 提交后状态变为「待审批」

评分标准：
| 步骤 | 操作 | 分值 |
|------|------|------|
| 1    | 正确进入创建页面 | 3分 |
| 2    | 填写项目名称 | 3分 |
| 3    | 选择负责人 | 3分 |
| 4    | 填写日期和金额 | 3分 |
| 5    | 上传文件 | 4分 |
| 6    | 成功提交 | 4分 |
```
