# user-trainer 触发配置

## 触发关键词

| 关键词 | 匹配规则 | 说明 |
|--------|----------|------|
| 培训材料 | 完全匹配 / 包含 | 通用培训材料生成 |
| 操作手册 | 完全匹配 / 包含 | 操作手册编写 |
| 用户培训 | 完全匹配 / 包含 | 用户培训场景 |
| 培训PPT | 包含匹配 | 培训课件制作 |
| 考核题 | 完全匹配 / 包含 | 考核题库生成 |
| 使用手册 | 完全匹配 / 包含 | 使用手册编写 |
| 用户手册 | 完全匹配 / 包含 | 用户手册编写 |
| 培训方案 | 完全匹配 / 包含 | 培训方案设计 |
| 操作指南 | 完全匹配 / 包含 | 操作指南编写 |
| 培训课件 | 完全匹配 / 包含 | 培训课件设计 |

## 触发优先级

1. 明确提到「培训方案」「培训材料」→ 高优先级触发（全套培训材料）
2. 明确提到「操作手册」「用户手册」→ 中优先级触发（侧重手册编写）
3. 明确提到「培训PPT」「培训课件」→ 中优先级触发（侧重课件设计）
4. 明确提到「考核题」→ 中优先级触发（侧重题库生成）
5. 包含「使用手册」「操作指南」→ 低优先级触发，需确认范围

## 去触发规则

以下场景不应触发本技能：
- 纯技术文档编写（API文档/架构文档）→ 走 docx 原生路由
- 纯 PPT 制作（非培训类）→ 走 pptx 原生路由
- 内部培训讨论（不涉及材料生成）
