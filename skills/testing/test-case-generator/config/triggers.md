# 意图触发映射

> 优先使用 LLM 语义理解，本文件仅作兜底参考

## 工作流触发

| 关键词 | 工作流 | 优先级 |
|--------|--------|--------|
| 功能用例 / 测试用例 / 写用例 / 测试设计 / 用例生成 | functional-test-case | 高 |
| 接口测试 / API用例 / 接口用例 / API测试 | api-test-case | 高 |
| 覆盖率分析 / 覆盖检查 / 遗漏分析 / 覆盖率 / 追溯矩阵 | test-coverage-analysis | 高 |

## 测试类型识别

| 关键词 | 测试类型 | 说明 |
|--------|---------|------|
| 功能测试 / 冒烟测试 / 回归测试 | functional | 功能验证 |
| 接口测试 / API测试 / 集成测试 | api | 接口验证 |
| 性能测试 / 压力测试 / 负载测试 | performance | 性能指标（不在本技能范围，建议使用性能测试技能） |
| 安全测试 / 渗透测试 | security | 安全检查（不在本技能范围） |

## 匹配规则

```
1. 精确匹配 → 直接触发对应工作流
2. 包含匹配 → 按优先级匹配第一个命中项
3. 无法匹配 → 默认 functional-test-case + 询问确认
```
