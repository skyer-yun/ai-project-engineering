# performance-tester 触发配置

## 触发关键词

| 关键词 | 匹配规则 | 说明 |
|--------|----------|------|
| 性能测试 | 完全匹配 / 包含 | 通用性能测试场景 |
| 压力测试 | 完全匹配 / 包含 | 压力测试场景 |
| 负载测试 | 完全匹配 / 包含 | 负载测试场景 |
| JMeter | 工具名称匹配 | 指定 JMeter 工具 |
| 并发测试 | 完全匹配 / 包含 | 并发能力测试 |
| 压测 | 简称匹配 | 性能测试简称 |
| 容量规划 | 完全匹配 / 包含 | 容量规划场景 |
| 性能瓶颈 | 包含匹配 | 瓶颈分析场景 |
| TPS | 指标名称匹配 | 吞吐量测试 |
| 响应时间 | 包含匹配 | RT 测试 |

## 触发优先级

1. 明确提到工具名称（JMeter / Gatling / Locust）→ 直接触发
2. 包含「性能测试」「压力测试」「负载测试」→ 高优先级触发
3. 包含「压测」「并发」「TPS」→ 中优先级触发
4. 包含「容量」「瓶颈」「响应时间」→ 低优先级触发，需确认

## 去触发规则

以下场景不应触发本技能：
- 仅为功能测试（不涉及性能指标）
- 单元测试 / 集成测试讨论
- 代码性能优化（非压测场景）
