# Triggers - solution-architect

## 方案类型识别

### 技术方案（Technical Proposal）
- 写方案
- 技术方案
- 建设方案
- 技术建设方案
- 投标技术方案
- 技术投标文件
- 应标方案

### 解决方案（Solution Proposal）
- 解决方案
- 业务方案
- 产品方案
- 整体方案
- 解决客户痛点
- 方案建议书

### 架构设计方案（Architecture Design Proposal）
- 架构设计方案
- 系统架构方案
- 技术架构设计
- 架构设计文档
- 系统设计说明

## 触发规则

1. **精确匹配**：关键词直接命中对应方案类型
2. **上下文推断**：提到"招标/投标/应标"倾向技术方案；提到"客户/决策/汇报"倾向解决方案；提到"研发/设计/模块"倾向架构设计
3. **模糊匹配**：仅说"写方案"时，询问用户确认方案类型
4. **默认降级**：无法确定类型时，默认推荐技术方案（使用最广）
