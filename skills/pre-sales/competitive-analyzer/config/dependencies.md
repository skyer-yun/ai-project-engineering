# Dependencies - competitive-analyzer

## 核心依赖（Core）

| 技能 | 用途 | 必要性 |
|------|------|--------|
| `web-access` | 联网获取竞品信息、用户评价、行业数据 | 必须，未安装降级为基于已有知识分析 |

## 增强依赖（Enhanced）

| 技能 | 用途 | 效果 |
|------|------|------|
| `brainstorming` | 多角度分析、策略发散 | 提升分析的深度和策略的全面性 |
| `docx` | 报告输出为 .docx 格式 | 输出正式文档 |

## 依赖检测逻辑

```
IF web-access 可用:
  分析模式 = 联网调研模式（获取最新竞品信息）
ELSE:
  分析模式 = 基于知识模式（结果标注"基于已有知识，建议联网获取最新数据"）
  提示: 安装 web-access 可获得更准确的竞品分析

IF brainstorming 可用:
  策略建议阶段使用发散-收敛方法
  生成更多角度的分析结论
ELSE:
  直接给出分析结论和策略建议

IF docx 可用:
  输出格式 = .docx
ELSE:
  输出格式 = Markdown
```

## 依赖对分析质量的影响

| 依赖状态 | 信息准确性 | 分析深度 | 输出质量 |
|----------|------------|----------|----------|
| 全部可用 | 高（实时数据） | 高（多角度） | 高（.docx） |
| 仅有 web-access | 高 | 中 | 中（Markdown） |
| 仅基础知识 | 中低 | 中 | 中（Markdown） |
| 无任何依赖 | 低 | 低 | 低（Markdown） |
