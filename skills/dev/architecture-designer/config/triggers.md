# Triggers - architecture-designer

## 触发关键词

### 主要触发词
- 架构设计
- 系统架构
- 架构方案
- 技术架构
- 架构文档

### 辅助触发词
- 从PRD生成架构
- 需求转架构
- 系统设计
- 模块设计
- 技术选型方案
- 架构评审材料
- 架构设计说明书

## 触发规则

1. **精确匹配**：关键词直接触发架构设计流程
2. **上下文推断**：已有 PRD 内容时，"设计"/"架构"可触发
3. **组合触发**：PRD + 架构/设计 组合触发
4. **避免误触发**：纯方案编写不触发（由 solution-architect 处理）

## 与其他技能的边界

| 关键词 | 所属技能 | 判断依据 |
|--------|----------|----------|
| 架构设计 | architecture-designer | 从 PRD 生成架构文档 |
| 架构设计方案 | solution-architect | 8章方案文档（面向外部） |
| 系统架构 + 方案 | 视上下文 | 面向研发用本技能，面向客户用 solution-architect |

## 关键词权重

| 关键词 | 权重 | 说明 |
|--------|------|------|
| 架构设计 | 1.0 | 直接触发 |
| 系统架构 | 0.9 | 高概率触发 |
| 架构方案 | 0.8 | 需要区分是内部设计还是外部方案 |
| 系统设计 | 0.7 | 需要上下文确认 |
| 技术选型 | 0.6 | 可能只是选型讨论 |
