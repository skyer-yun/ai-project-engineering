# Dependencies - architecture-designer

## 核心依赖（Core）

无。本技能可独立运行，基于内置知识和模板生成架构设计文档。

## 增强依赖（Enhanced）

| 技能 | 用途 | 效果 |
|------|------|------|
| `brainstorming` | 架构模式多方案发散对比 | 提升架构选择的全面性 |
| `web-access` | 查询技术选型最新信息 | 增强技术选型的时效性 |

## 依赖检测逻辑

```
本技能无核心依赖，开箱即用。

IF brainstorming 可用:
  在架构模式选择阶段使用发散-收敛方法
  生成 2-3 个候选方案对比后推荐
ELSE:
  基于经验直接推荐最佳方案

IF web-access 可用:
  技术选型时查询最新版本和社区信息
  获取最新的架构模式最佳实践
ELSE:
  基于已有知识库推荐
```

## 依赖影响

| 场景 | 有增强依赖 | 无增强依赖 |
|------|------------|------------|
| 架构模式选择 | 多方案对比后推荐 | 直接推荐最佳方案 |
| 技术选型 | 查询最新信息 | 基于内置知识 |
| 架构图 | 无影响 | 无影响 |
| 文档输出 | 无影响 | 无影响 |
